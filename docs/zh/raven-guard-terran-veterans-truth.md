# 四十二号门之战

这场战役只在军书里面记载过，没有在小说里被直接描写过，所以很多人没看过军书不清楚，也就导致了谣言漫天飞。还有一点，**战锤的军书是从世界观内帝国学者和史官的视角写的**，并不是一个完全客观的第三方叙事模式。如同现实的史书一样，内容会有遗漏，也会包括一些作者本人的猜测。在分析这类伪史书内容的时候，一定要考虑到不可靠叙述者这个问题，去认真分辨哪些内容是作者的猜测，哪些是帝国的宣传，哪部分内容比较可信。

军书确实有不少部分提及科拉克斯对他手下的泰拉裔有着恶意，但是在分析这些片段的时候，必须考虑到军书是以史书的模式撰写的，而就像真实的史书一样，写书的人不可能知道历史人物当时的真正想法，只能予以猜测。而小说则是以事件参与者的模式来描述这些事件的，总体而言，在分析角色的想法方面看小说更可靠的。但是小说中并没有任何科拉克斯区别对待泰拉裔的环节，所以我将这一部分归根于军书叙述方式的问题。

这场作战本质是刚晋升战帅的荷鲁斯在向兄弟们立威，而科拉克斯是被他针对最狠的一位，根本没有什么故意送自己人去死。

再者，一场速胜可以向荷鲁斯的兄弟原体们证明帝皇决定擢升荷鲁斯的正确性。—出自HH3黑皮书

当时一共有四个军团在场，除了影月苍狼和暗鸦守卫意外还有钢铁勇士和太空野狼以及他们的原体。在这么多擅长正面进攻的军团都在场的情况下，荷鲁斯的计划是让暗鸦守卫在前面冲锋。荷鲁斯带了十九军团这么久，怎么可能不知道他们的优势，科拉克斯作为少数不喜欢他的原体，他这么做就是故意为了故意恶心科拉克斯，不然为什么放着擅长攻城的铁勇和擅长近战的狼团不用，要一群刺客上去冲锋。根本不是科拉克斯自己把泰拉裔放上去送死，而是荷鲁斯为了打压他要求他的军团去送死。

几周内快速成功征服星团外围的几个世界后，战帅发起了一场与他的兄弟原体间的会议。他计划的一部分包括了让暗鸦守卫顶着四十二号门守卫的武器发起正面进攻。科拉克斯反驳了这个他认为浪费了物资和他战士生命的计划，并以他自己的战略应对。暗鸦之主提议由他的军团通过一系列的佯攻来吸引敌方势力，给其他三个军团机会镇压仍留在城墙上防守的敌人。做为回应，佩图拉博指责科拉克斯是在试图逃避战斗，对于一位阿斯塔特原体而言这是一种几乎渎职的罪状。两人差点大打出手，只是因为黎曼·鲁斯的介入才止于干戈。狼王劝告科拉克斯听从于帝皇最器重的原体。鲁斯劝科拉克斯忍住他的苦楚，但是不要熄灭它，在后面的战斗中燃烧自己的怒火。离开了会议之后，科拉克斯在四十二号门前集结了他的暗鸦守卫。出于对他们行为模式的理解，科拉克斯把许多以泰拉裔为主的连队部署为先锋，特别是那些由看起来对战帅的计划最热衷的连长们带领的连队。此后的进攻被称为整个军团最黑暗的时刻，但是，悲剧性的，这个称谓在几年后就被伊斯特万五号上的惨剧代替。在战斗的高峰时刻，进攻连队损失惨重，攻势被敌军的压倒性火力压制。科拉克斯本人带来了凄凉的希望，身先士卒，他的战吼激励着他的军团，直到城墙被攻破，四十二号门被夺取。亲手杀死无明之王的荣耀被身为战帅的荷鲁斯夺取，而在它们被处决时，这些异形对民众的控制也解除了。阿库姆-索托斯星系被解放了，而战帅也取得了他的战果。但是损失也十分惨重，不止有数以百万计的宿主受到了身体和心灵上严重的伤害，数以千计的暗鸦守卫，大部分泰拉裔，也在这段破碎的城墙前献上了生命。—出自HH3黑皮书

在场几人中，科拉克斯是当时少数不喜欢荷鲁斯的原体。而科拉克斯和佩图拉博关系也不好，佩图拉博一直鄙视暗鸦守卫的战术，之前也给他们使过绊子，不过没成功就是了，所以他在这里针对科拉克斯也不奇怪。鲁斯是在场唯一一个和科拉克斯关系好的，但是他也知道他们无法改变荷鲁斯的决定，所以只能选择当和事佬劝他冷静。

科拉克斯自己提出的战术比荷鲁斯靠谱多了，毕竟正常情况下谁会让一帮刺客在前面冲锋。他是在认真维护自己军团的利益，阻止无谓的牺牲，但是最后只能妥协。他选择让泰拉裔当先锋是因为他们更熟悉也更适配荷鲁斯的战术，而且特意挑的是愿意冲锋的连队当头阵。战斗中，他更是自己带领军团冲在前面近战。如果真是要去让泰拉裔送死，他根本不需要先提一个更好的战略，差点和佩图拉博打起来，然后再身先士卒冲在最前面，他直接答应荷鲁斯的战术就行了。

不过在泰拉裔的眼中可能就不一样了。科拉克斯一向不善于表达，也无法理解人类的感情。在荷鲁斯麾下时，荷鲁斯就对他们不好，所以他们是渴望自己原体的关注的，但是科拉克斯对所有人是一视同仁的冷淡。这里他大概就真的什么都不解释就把泰拉老兵全拨去当先锋了，他有自己的考量但是他们不知道啊。虽然他们知道这是荷鲁斯的战术，而荷鲁斯以前让他们去送死的事情没少做，但是他们因此对科拉克斯有怨也很正常。泰拉裔和科拉克斯的很多问题其实都可以归功于他不张嘴，而泰拉裔对父亲这个角色有有着比较高的情感需求。

军团的人数大幅下降，只留下八万人处于原体的统领下，使他们成为最小的阿斯塔特军团。科拉克斯将自己和军团移除了他兄弟的指挥，并痛苦的发誓再也不会与战帅一同出战。四十二号门之战最后的后果仍在徘徊。此战之后，那些曾在原体回归前长期处于荷鲁斯指挥下的一线军官不在了，而战帅也很难再对暗鸦之主的军团产生影响。这些泰拉裔许多都加入了战士结社，随着他们的死亡，这些无形的团体也在暗鸦守卫中消失了。批判者们声称科拉克斯通过故意把泰拉裔派到伤亡最惨重的先锋，巩固了自己的权利并为军团塑造了一条更符合他本人观念的未来之路，为自己的军团做了一件好事。结果就是，这个军团大体幸免于其他军团中战士结社传播的暴乱。—出自HH3黑皮书

这段大概就是科拉克斯故意让泰拉裔送死谣言的源头了。但是，如我在上面所说，这里是一个伪史书的模式，这一段也很明显的标明了，这是科拉克斯的批判者的观点。综合其他证据，科拉克斯不可能是故意的，除非以上所有行为，包括提起更好的战术、差点和佩图拉博打一架、自己在最前面冲锋、事后和荷鲁斯决裂并给了他一拳都是在做戏。这场戏还会需要好几个兄弟的配合。以科拉克斯的人机本质在为人处事中不会使用这种阴谋，他也不可能真的取得这么多兄弟的帮助演戏。所以，说科拉克斯在四十二号门故意让泰拉裔去送死是无稽之谈。

我曾因为荷鲁斯窃取暗鸦守卫的胜利打了他。那一刻一定时常于战帅的脑海浮现。我一定会找到机会让他重新体验当时的耻辱。—出自《暗鸦之主》第七章

# 远征舰队

很多人似乎认为，最顽固的这批旧十九军团派是直接被科拉克斯无情流放了，扔到偏远星区自生自灭。流放一词的涵义是为了惩罚犯人将其驱逐，但是科拉克斯将这些人送走的行为没有任何惩罚的意味，还为他们提供了足够的支持和完成任务的自主性，甚至送走的不只有泰拉裔。与其说这些人是被流放，应该说是被降职外派。在把这些人外派之前，科拉克斯已经给了他们足够的机会学习他的理念并融入战团。将这些人送走是为了缓解军团中的矛盾，也是为了减少荷鲁斯通过这些军官对军团施加影响。并且，他给装备、给舰队给的非常慷慨。如果真是要他们自生自灭不会送舰队的。

和大部分军团一样，暗鸦守卫有小的单位被分离出去，在他处服役。少数军士，大部分来自旧时军团的泰拉裔，被分派到了帝国的边缘，有些处于独立的“游掠”舰队中，有些附属于行商浪人或者其他“孤狼”组织。—出自HH3黑皮书

很多军团本来就会将小部分人外派，而且暗鸦守卫外派的也不止有泰拉裔。他们都是有明确的任务的，也有着来自军团的支持。将一群有叛变风险的前军官带领舰队独立执行任务已经是非常仁慈了，虽然被降级外派确实有惩罚的意味，但是这和流放还是有本质上的区别。而且，这些人要是留在军团内部只会增加不确定性，提高各部之间的矛盾，还可能会成为荷鲁斯控制暗鸦守卫的工具。

实际上，除了法尔带领的舰队，没有一批被外派的人用到了“流放”这个词（法尔被流放大概也是自己要求的），而且被外派的不止是泰拉裔也有拯救星裔。从科拉克斯的角度而言，他真的就是因为这些人无法与军团大体和谐相处所以把他们外派工作了而已。他很难理解正常人类的思维，自己的脑回路也很清奇而且很少主动开口解释，所以在有些泰拉裔看来他就是把那些人流放了。但是无论如何，每一支被送出去的舰队都装备精良，补给问题也考虑了，科拉克斯也信任他们。谁家流放还送舰队啊

## 噬人鲨

噬人鲨战团的前身是由前军团长阿尔卡斯·法尔带领的游掠舰队（没有实锤但也差不多了，具体分析看）。这是最早离开军团本体的舰队，也是唯一一支纸面上被放逐的舰队，虽然这大概是法尔自己要求的，而不是科拉克斯主动的。他们本质上也和其他被外派的舰队一样，有着来自母团的装备支持和明确的任务。一万年来，他们也一直忠于科拉克斯与帝皇，游荡于帝国的边缘完成着原体留给他们的使命。虽然40k的鲨鱼确实寒酸，但是也能看出来他们老底很厚，一万年前科拉克斯给了他们很多好东西。

其中一支舰队由军团的前总指挥官，阴影之主阿尔卡斯·法尔统领，是科拉克斯接手暗鸦守卫时亲自下的命令。阴影之主和他舰队的下场无人知晓，而科拉克斯似乎一直没有尝试召回他们这一点意味着他们是算在军团主体外的独立单位。—出自HH3黑皮书

40k的鲨鱼确实很穷，但是在没有母星的情况下在帝国边缘征战多年，这是无可避免的。科拉克斯在送他们走的时候就考虑到了补给问题，虽然鲨鱼对这个条款的理解大概和他的本意不同，也为他们提供了很多精良的装备，到一万年后依然是他们的底气。这包括鲨鱼舰队的战舰、武器、动力甲和其他圣物。法尔的舰队，虽然被流放，但仍然有着来自科拉克斯的很多支持。难道终结者是什么很便宜的东西吗

## 灰烬之爪

灰烬之爪是一支在四十二号门战役之后被外派的大型舰队，其中包含了许多在四十二号门中活下来的先锋们，都是军团内的刺头，有泰拉裔也有拯救星裔。这些人如果留在军团内只会加剧军团内部的分裂，特别是一些亲荷鲁斯派的军官，于是科拉克斯将他们外派。从表面来看，这支部队与他们的原体结缘颇深。但实际上，哪怕他们在变节以后，依旧尊敬了科拉克斯，也在一万年来逐渐践行了他的理念。

有关灰爪的记载大部分来自40k鲨鱼的小说《系外黑域》和HH6黑皮书里面一小段。黑皮书里面的部分是圣血天使在内战结束后去诺斯特拉莫星系的报告，如同军书很多其他部分一样，是以伪史料的风格撰写，甚至本身就包含互相矛盾的信息。由于是以外部势力的角度书写，并不是了解灰烬之爪看法最好的资料。想要了解灰烬之爪对科拉克斯的想法可以去看小说，或者依据其他内容分析。

渡鸦之主的弃子研究大远征的学者们经常会将四十二号门之战称为科瓦斯·科拉克斯希望能够净化军团内泰拉裔污点的火堆。但是，如果这是他的意愿，那这件事并没有成功，因为在科拉克斯部署的前锋中，有不少人活了下来。他们中包括了内拉特·基林，灰烬之爪大连残酷高效的执政官。他的游击战略让他的老兵们幸存于战火中。十八大连“灰烬之爪”有几千个幸存者，绝大部分泰拉裔，而他们中许多人对暗鸦之主对他们生命和忠诚的蔑视表示了愤怒。战后，这些战士被集结起来，却不是和其他军团的战士一样被授予他们应得的荣耀。渡鸦之主将大部分旧十九军团的老兵，和一些行为不符合原体期待的拯救星裔组成了远征舰队。这些舰队被派到了银河的西北边缘，被探险家称为“食尸鬼星系”的位置，将帝皇的光辉带到银河边缘的黑暗，远离年轻的帝国和渡鸦之主忧郁的视线。—出自HH6黑皮书

这一段大概就是关于灰爪大部分谣言的来源了，关键是这一段里面吃书的就不少，而且还是从圣血天使视角写的。ba和鸦卫本来就没太多交流，而且这里很多内容和其他内容不符。比如说将大部分老兵送走这一段，其他所有记载都是到了HH还有将近一半的泰拉裔。而且四十二号门鸦卫的损失本质是荷鲁斯的问题。同一本书仅仅两页后就有着完全不同的记载：

有关灰烬之爪舰队更全面的调查显示，他们于002.M31开启远征，而总指挥是执政官卡尔乌斯（Calvus），一位以对科拉克斯的忠诚闻名的拯救星裔幸存者。执政官卡尔乌斯后来的命运无人知晓，但是当灰烬之爪于011.M31返航时他大概已经去世。这艘舰队最初拥有着十三艘本舰、许多小型舰船、和从阿库姆-索托斯的幸存者中选出的大约4000名阿斯塔特战士。哪怕经历了九年远征的消耗，这支舰队依然是一支不容小觑的势力。—出自HH6黑皮书

这段也说了，这里才是帝国学者们全面调查后的结果。灰爪到002才被送出去，而基林根本不是他们一开始的指挥官。四十二号门过后好几年这些人才被送出去，而且是给了十三艘大型战舰外加很多小型护卫舰好好送出去的。这也体现了科拉克斯对他们的信任，这些人根本没有闹那么僵。谁家弃子被流放还送舰队？十三艘主舰和二十艘护卫舰是什么很便宜的东西吗？这些战舰直到40k依然被灰爪保留，而在40k更是显得家底雄厚，这也许也是也他们可以存活这么久的原因之一。

以此来看，灰烬之爪和科拉克斯的关系根本没有那么差，而他们变节的原因大概可以归功于食尸鬼星系信号太差：

为了在歼灭星球表面上午夜领主的行动中获得他们的协助，我们尝试建立联络，但是被对方生硬的驳回，仅有一条从仅语音频道传来的信息，来自一位自称基林的执政官：“帝皇将我们交付给一个想要我们死去并被遗忘的暴君；现在暗鸦之主已死，我们不愿再让奴隶的镣铐落到我们的脖颈上，不论是叛徒战帅还是失败的帝国。“—出自HH6黑皮书

这里基林将话说的很死：他认为科拉克斯已死，他们也没有留在帝国的原因了，而他们更不想去加入荷鲁斯。这里基林口中的“暴君”有两个可能的人选，可能是指荷鲁斯也可能是指科拉克斯。但是这段最明显的意义就是，灰爪只是对科拉克斯忠诚，而不是对帝国忠诚，所以他们在他们认为科拉克斯死后选择了变节。他们更不会选择荷鲁斯。荷鲁斯对他麾下的十九军团本来也没多好，将他们视为自己军团的附属品和消耗品。

第二个出处来自影月苍狼幸存的资料片段。他们的资料库大部分已毁于泰拉的战火和某些过于激进的忠诚书记官手中。在这些书册里，“灰烬之爪”一词出现了几次，似乎是一种战帅喜欢的计策，让一支部队作为牺牲品留在开放区域吸引敌人的全部火力，同时由其他势力从侧面包围。大远征中的许多行动都包含了这些带着“灰烬之爪”这个附加头衔的部队，表明这个单位获得了在计策中作为牺牲品的“荣耀”。—出自HH6黑皮书

“灰烬之爪”这个名字甚至来源于他们作为荷鲁斯的牺牲品的过往，也证实了荷鲁斯真的对十九军团不好，这也是为什么鸦卫没有人去投荷鲁斯的原因。他们再因为四十二号门的事讨厌科拉克斯，可是这归根结底是荷鲁斯的问题，他们更恨荷鲁斯。单凭这一点就不会有暗鸦守卫去投奔荷鲁斯。

如果当初他们知道科拉克斯没死，大概不会做出这样的决定，但是变节这种事情是没有轻易的回头路的。40k的灰爪对回归帝国有着一定的向往，而他们的“忠于兄弟”的理念大概就来自于他们30k时期单对科拉克斯的忠诚。实际上，40k灰爪的现状比起旧十九军团更像科拉克斯麾下的暗鸦守卫，比如说灰爪和母星平民的相处方式。他们甚至在有意的复刻着拯救星。灰爪的堡垒“失落鹰巢”和拯救星上的鸦塔就很像，而鸦塔顶端科拉克斯个人的房间就叫“鹰巢”，连同鸦塔里面养鸟的习惯（30k并没有记载鸦塔里面有鸟，但是40k是有的）。甚至有些灰爪的姓和30k一些拯救星裔是一样的，比如说战团长聂哈特·涅夫就用了30k涅夫兄弟的姓氏，而第三章出场的拉玛·西克斯的姓氏和30k的药剂师文森特·西克斯一样。我甚至怀疑灰爪走的时候带上了鸦塔的设计图纸和拯救星裔的名单，就是为了以后复刻

40k灰爪很清楚自己的处境，也很清楚帝国的现状，他们想要的是回到科拉克斯身边而不是回归帝国。灰爪如果要回归也必须是科拉克斯亲自上场赦免他们。从变节以来，他们其实一直奉行着科拉克斯的理念，符合科拉克斯期待中军团的样子，这是他们在离开军团前没做到的，变节后却做到了。

从这些内容可以看出，哪怕和科拉克斯闹的最僵的旧十九军团派，本质都是尊敬他的，更不会去投荷鲁斯。科拉克斯一直没有亏待过这些人，从最开始的教导到最后无奈让他们远离军团主体，他从没有放弃过他们，也没有对他们区别对待。不过不张嘴的遇上心思拧巴的，泰拉裔对科拉克斯确实有着很多误解。科拉克斯回归的时间很晚，荷鲁斯带他的军团的时间都比他带自己的军团的时间长，能够做到这个程度，HH期间没出大批叛徒已经做的非常不错了。

说到这些人的作风问题，其实指的是旧十九军团完全不顾己方其他势力伤亡的打法，将下属以及奴仆当奴隶，以及和荷鲁斯保持联系的行为。这一点上他们真的不无辜。就这样还屡教不改的结果是送了舰队送了神器去远征真的是仁慈的不能再仁慈了。被外派的大部分都是军官，他们才有机会欺负手下的普通兵和奴仆，所以把一大波军官降职成大头兵然后外派也算是对这种行为的一种惩罚了。从普通泰拉裔的视角来看，可能类似于新老板把恶心的前组长给降职外派了，还把恶心的前老板（荷鲁斯）给揍了。这不是天大的好事吗？
