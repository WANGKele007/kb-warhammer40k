帝国如此庞大，诸多星球间的距离如此巨大。即便是简单的通信通常也是不可能的。尽管有着猖獗的混乱与错误，错综复杂的帝国组织仍努力维持着不断增长的糟糕秩序。

 他们决定着人类命运。

# ***泰拉元老院***

 这十二个人以帝皇之名统治着帝国。正是他们将帝国的舰队派去战争并掌管着几近无穷的军队。他们的职责就是诠释帝皇的沉默意志，依靠他强大的精神来指引他们的思想并激励他们的行动。有九个席位几乎是神圣不可更改的，例如内政部主管、导航贵族的父新星使节以及机械修会的铸造统领；其他位置则由各类最高官员占据。

 地球之主，无所不能。

# ***泰拉政务院***

泰拉政务院是帝国的中央官僚组织而其自身并非一个真正的机构。它由许多自治部门组成，接受泰拉元老院的命令，将其传递给其下不同的部门去执行命令。

 他们转动着统治的车轮。

# ***内政部***

泰拉政务院中最大的组织，内政部自身划分为了许多部门。他们的职责是管理帝国，而正是他们在进行征税、管理、记录与存档。履行职责就足够了；理解既不需要也不欢迎。

 帝国信仰的传播者。

# ***帝国国教***

帝国国教——通常称为教会——在整个帝国传播着帝国教。教会不是泰拉政务院的一部分而是一个完全独立的帝国机构，拥有着众多自己的子团体，最著名的是其军事单位（战斗修女会）、正统训练孤儿院（忠嗣学院）、以及通常伴随帝国勘探舰船的传教士（银河传教团）。

 永不沉睡的眼睛。

# ***审判庭***

一个高度机密的组织，审判庭不受除了它自己与帝皇以外的权力约束。审判庭的唯一使命是负责保护人类。审判官被授权调查对人类的任何潜在威胁并采取任何他们认为适当的措施来消灭危险。只要目的正当，可以不择手段。

 航道开辟者，第三眼携带者。

# ***导航贵族***

导航贵族，又称导航者家族，由父新星领导各处的所有导航员组成了这个建立于泰拉的组织。少数被认可的变异人种之一，导航者用他的第三眼驾驶着人类星舰穿越翻腾疯狂的亚空间。

 火星之主与万机之神的信徒。

# ***机械修会***

机械修会的科技神甫是古老知识与神秘技术的守护者。正是他们维护着帝皇的黄金王座并管理着用武器、护甲、军火、重要星际飞船与战争机器供应帝国军械库的铸造世界。火星祭司团包含有许多分支部门，包括其自己的舰队与军事单位。全都追随机械教——对万机之神的崇拜——并用复杂的祷文组装并维护其宝贵的机器。不像许多其他的主要修会组织，机械修会的总部不在泰拉上，而是在所有铸造世界的起源与最伟大的地方，红色行星火星。

 他们的声音穿透黑暗并跨越星辰。

# ***星语庭***

星语庭的职能是征募、识别并归类灵能者，然后训练那些被认为有价值的人。为此，星语庭被划分为两个主要组织：黑船联盟与灵能学院；星语庭院长管理着两者。星语庭将灵能者分为许多等级，可接受的等级被输送于各个角色以服务帝国。那些没能通过一系列严酷测试的人会经过最后一步前去履行其他更不好的职务。

 他们维持着帝皇的引导之光。

# ***星炬庭***

星炬庭训练灵能者为维持星炬提供原始灵能力量，灵能导引信标使导航者能够驾驶穿越亚空间。这项工作需要至少一万名灵能者的合唱团，而这个角色会迅速摧毁他们。然而总是会有更多的人受训以接替他们的位置。

 描绘地图的手。

# ***行商浪人***

获得许可并装备精良前去探索银河系以及之外未标明的地区，行商浪人是帝皇通向未知的使者。他掌握着在追寻喂养帝国贪婪欲望的信息、领土、外星神器与原料中谈判、交换、征服或是完全摧毁的全部权力。

 以祂之名统治。

# ***行星总督***

每个行星都被地方领导者所统治着。就像是古代的封建地主，他们必须为星界军提供士兵、维持秩序、执行所有的帝国敕令以及向内政部支付所有的赋税，其中最重要的是灵能者的赋税。只要达到指标，一位行星总督能用任何他选择的方式来统治他的世界。

 伟大审判之书的看守人。

# ***法务部***

泰拉政务院的仲裁官与法官在帝国内执法。他们以绝对而无情的方式维持着秩序。对法律文字的严格遵守是至上的，而他们则培育狂热。

 无所畏惧，死亡天使。

# ***阿斯塔特修会***

阿斯塔特修会，通常称为星际战士，是所有人类战士中最强大与令人畏惧的。大约有一千个战团，每一个都由一千位战士组成。每个都保持着自己的特性与传统，教会亦有自主权。虽然数量稀少，阿斯塔特修会是被训练以快速部署并在任何地方战斗的高机动突击部队。

 帝皇之锤，帝国卫队。

# ***星界军***

星界军是帝国最大的作战部队。它依靠庞大数量的士兵、装甲战斗坦克与火炮来粉碎敌人，通过消耗和毁灭性火力的运用来碾碎他们。星界军的供给由军务部——内政部的军需与补给部门提供。

 往返于星辰，携带着巨炮。

# ***帝国舰队***

帝国内的所有船舶都属于帝国舰队的管辖范围，除了由阿斯塔特修会与少数其他修会组织运行的以外。舰队较大的部分是海军，护送货物穿越银河系并在任何入侵或叛乱中充当防御第一线的战舰。帝国海军舰队由战列舰、巡洋舰、护航分舰队、运输船、信使船、轨道防御设施以及无数的巡逻舰组成。他们是巨大、遮蔽星辰的军队，带着帝皇的战争穿越星辰。

 黑暗中的匕首，沉默的回答。

# ***刺客庭***

刺客庭是一个重要、不为人知的帝国工具。组成这个神秘机构的不同圣殿全都被秘密所掩盖着。每个受训的无双杀手会无形打击并不遗余力地完成其致命任务。只有泰拉元老院才能批准部署一名刺客。

 光荣的家族，来自古夜的保卫者。

# ***帝国骑士***

由一位贵族驾驶员操纵，帝国骑士是个巨人般的装甲步行者。这些骄傲而高贵的战士中的许多人能追溯其血统到泰拉。千年间，每个驾驶员家族都已宣下效忠的誓言——帝国骑士将奉献于泰拉的黄金王座，以及火星机械修会的机械教骑士。那些因失败、惩罚或流放而抛弃其家族的骑士会作为自由之刃接受新的纹章。

 帝皇的警卫，帝国圣所的保护者。

# ***禁军***

禁军，或称禁卫卫队，其职责是守卫帝国皇宫与帝皇的身体。他们有一万名强者，每个都是基因设计的超人能在决斗中轻易战胜一位星际战士。禁军担任帝皇的个人警卫，只对人类之主与其自己的领袖负责。有时会看见他们离开泰拉，只有在极端需要他们时才离开其岗位。
