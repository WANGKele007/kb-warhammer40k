# **第一节： 眠（DRAUMR）– 梦间酣时***

*“DRAUMR”来自古诺尔斯语，是英语单词 dream 的词源

比约恩像没有四肢的鲸鱼一样在水中游动，在结霜的大片浮冰下屈伸躯体，他像山岳一样古老，他像被自身压碎的岩石一样疲倦。他在记忆凝结的无垠冰海洋里漂荡，像被潮楼驱赶的冰群一样起伏、碰撞。

如此多的战斗。

如此多的兄弟。

大多数记忆已如沉积物般沉入世界之海最昏暗的深海，沉入连声音都无法抵达的海渊。然而，有些时候，脆弱的回忆如从黑暗中破出的气泡，浮上水面。

他就在那里，在芬里斯的冰原上飞奔，一缕缕呼吸化作雾气，仰头看见一颗星星从黑暗的天穹上滑落。*

*应指“天外来客”豪瑟尔来到芬里斯，而非鲁斯来到芬里斯，详见《普焚》

蓝色苍顶下的金字塔。

皇宫的废墟躺在漆黑的夜幕之下，浑身尘土的战士如幽灵一般短命。

须臾生，刹那灭，万般种种终消逝。

比约恩的一些记忆甚至不属于他自己。

他们是从无尽的杀戮中偷来的礼物——从死者的咽喉中夺来，混合着鲜血一起被拾起。他们是锯链剑撕咬时溅出的血雾——一小滴血珠在战斗中溅射到了他的嘴唇上。还有一滴热血在他抽刀时溅到了他赤裸的指节上，当他擦拭獠牙上的唾液时，这滴热血又抹在了他的嘴上。

他是一名童工领班，生活在一颗星球恶臭的深坑型贫民窟里。他胡乱抓起一块堆石混凝土（rockcrete*）的碎片以抵御逼近的工头。那些人用言语奚落他，空气中弥漫着厚重的饥饿气息。他孤身一人，直到有一只手握住了他的手腕。一道阴影出现在他身侧。

*疑似Rock-Filled Concrete的缩写。该技术广泛应用于大体积混凝土工程领域。

你终归不再形单影只。

他是一名深坑斗士，他的双手被拆得露出骨头，而刺刀又了取代骨头。在沙坑对岸，一个巨大的阴影若隐若现。当他迈步向前时，斜射而下的聚光在他的身上燃起白色的火焰，嗡鸣的锯链拔高声音开始尖啸。

他行走在那些该死的意识的癫狂迷宫之中。而这记忆迷宫并不属于某个人。

每一步都在考验理智（sanity*）的边界。

*哲学层面，sanity详指“荒谬中的清醒”、“拥有存在的意义/完整的人性”、“健康的逻辑+健全的情感”

这些时刻持续了数个世纪。

期间一定存在某种模式。

一种意义。

稻草。一座黑暗中的指引之光，如同港口的灯塔，指引着长船安全地穿越大海，驶向安全之地。

比约恩还记得，他在年轻时听过的一个故事：一名来自芬里斯的汉子，在一场命定的（wyrd*）暴风雪中迷路，最终跌跌撞撞回到家中，却发现已经过去了一百年。小时候，他曾好奇，身为那个汉子会是一种怎么样的感受——漂泊一生，归家后发现曾经熟悉的一切都已不再。

*常见翻译是“命线”。原意：盎格鲁·撒克逊或挪威语境下的命运

记忆翻涌起伏。

这是一枚双面硬币。而他也知道成为被留下的家人是怎样的感受。在雪中搜寻踪迹，不顾一切地*期待着一种迹象、一具躯壳，或是一个结局。

*desperate for：desperate同时具有绝望和不顾一切双重含义。

他了解那些充满等待却毫无音讯的漫长岁月。希望日渐破碎，如石磨碾压谷物一般消磨着人心。比约恩明白，看着纪念日*堆积，一个世纪接一个世纪地堆积，就像高山群峰上的积雪缓慢而不可阻挡（inexorable*）地滑入冰河之中，是一种怎样的感受。

*结合军书背景，可能指鲁斯离开之日*双重含义：不可阻挡的；不为人情所动的

鲁斯离开时落下的雪，已顺着狼牙堡向下滑落，如今正从冰川的中心脱落，最终要跌入世界之海的冰蓝色水体中。

比约恩深知，鲁斯一定会回来，就像他深知自己会呼吸。但漫长的等待已经掏空了他——将那位原体的回响抛回给世界。有时他会在梦中回首，鲁斯的影子就在那里，近到可以触碰。

近到他能感受到鲁斯的手压在自己肩上的重量。

近到他能狼王的呼吸拂过他的耳畔，低声说着别人永远听不到的话语。

彼时的比约恩既不古老，也并没有残破之躯。

在自己的梦中，他是完整的。

肌肉、灵魂、骨骼，这些来自先祖的馈赠，在久远的过去被鲁斯的狼群重塑。基因锻造，铁砧锤炼，黑铁百炼成钢，肉体愈益坚韧。

他的身躯布满伤痕与缝合，这是他在无数的战斗中英勇作战赢得的伤痕和印记——但他的身体依旧强壮，没有伤口，更没有残缺。

他的身体本身就是一件奇迹！
