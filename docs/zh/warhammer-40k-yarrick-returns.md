曾几何时，所有人都以为亚瑞克政委死了。现在，我们终于要揭晓在他震惊地重返哈米基多顿战场之前究竟发生了什么。

那些还记得上次兽人入侵阿米吉多顿的人或许会记得，碎骨者 加兹库尔·斯拉卡试图开启新一轮战争，于是他远征星际，决心发动伟大的Waaagh！，寻找一场更加激烈的战斗。亚瑞克率领一支黑色圣堂武士部队紧随其后。舰队一路追击着末日巨兽，它辗转于各个星区之间，建造着一种违背帝国预言的奇异装置。最终，他们在伊卡利亚星球上追上了加兹库尔的军队，却发现这颗星球本身正承受着他疯狂造物的巨大威力而崩裂变形——一座由摇摇欲坠的机械堆砌而成的巨山，划破夜空，迸发出道道绿色的闪电。 

降临伊卡利亚的末日浩劫将加兹库尔困在了岩石嶙峋的台地上，四周被交战的军队包围。亚里克伺机而动——他集结了一支由残破舰船组成的舰队，其中包括一艘芬里斯突击巡洋舰，直插兽人舰队的咽喉要道。他将一支经验丰富的突击队直接送到了巨兽的家门口。足以摧毁千军万马的猛烈炮火轰鸣着袭向加兹库尔，扬起一阵浓烟。巨兽发出咆哮，虽身负重伤却依然桀骜不驯。太空野狼召唤出的风暴霜冻将它庞大的身躯拖入深渊，却在加兹库尔的猛烈冲锋中轰然破碎，发出如同枪响般的巨响。亚瑞克起身迎战宿敌，挥舞着巨大的利爪，锋利的爪尖正中加兹库尔的胸膛。然而，他的敌人曾经历过更惨烈的打击（跟少狼主一换一），战争老大一把抓住政委，如同铁钳般捏碎了他的骨头，将他举起面对自己。

一记惊天动地的头槌落下，鲜血染红了巨兽的脸庞。他将亚瑞克重重摔在地上，举起一只铁靴，准备将他最大的敌人彻底碾成肉泥，却突然停了下来，脸上浮现出一抹邪恶的笑容。再次获胜后，他退了出去，而星球也在垂死挣扎中颤抖。 在混乱和溃散的帝国军队中，没有人看到身着黑色盔甲的芬里斯野狼祭司的身影带走了传说中的政委的残躯。他的残兵报告了他的死讯，不久之后，泰拉星球上响起了亡魂之钟。然而，出乎所有人意料的是，哈米吉多顿老人竟然活了下来。亚瑞克躺在太空野狼突击巡洋舰的医疗舱里。虽然他再次死里逃生，但他再也无法回到从前——他重建的头骨永远疼痛难忍，断肢靠着机械支架支撑，即使以他的年龄而言，他的皮肤也异常苍白。 太空野狼的骷髅头盔祭司告诉他，哈米吉多顿仍然需要他，所以他们决定前往哈米吉多顿。唯一的问题是，他们能否及时赶到，还是瓦兹达卡·古茨梅克的疾风战队（speedWaaagh！）会在亚里瑞克再次踏上这颗被诅咒的星球之前，就将这颗星球摧毁殆尽。

在《哈米吉多顿之战：亚瑞克归来》中，政委登陆星球后将会发生什么？这是《战锤40K》的最新扩展包。本书即将发售，同时还将推出一系列星界军增援部队，帮助亚瑞克从兽人手中夺回星球。在此期间，您还可以通过Warhammer+上的动画《老独眼》了解兽人一方的故事。
