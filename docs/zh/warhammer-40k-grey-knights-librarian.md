# **智库**

所有灰骑士新兵都拥有某种潜在的灵能天赋。正因如此他们才被选中加入战团。他们天生的力量随后会在训练与战斗中不断磨砺，直至成为强力的武器。但很少有战斗兄弟能自由驾驭这种力量。对多数人而言，谨慎的练习与监督只让他们能将自身能力与战斗兄弟协调一致。不过，那些被证明心智力量远超战友的战士，将继续跻身战团智库的行列。

灰骑士智库拥有钢铁般的意志。他们必须如此，因为他们比战友更易招致亚空间的危险。大多数灰骑士会精通一道咒语以发挥强大效果，而智库的学识则渊博得多。一个人的心智越是深入亚空间，其光芒便越是耀眼，会如灯塔般吸引潜伏其中的掠食邪恶。哪怕凝神时有最轻微的动摇，甚至一瞬间的精神衰弱，都会把自己的身魂奉给那些异界猎手，堕入彼岸的永恒诅咒。

在战场上，智库常运用力量支援他们的战斗兄弟，将他们召唤到战场各处，将他们遮蔽于庇护阴影，或是为他们注入力量。而他们也同样能造成巨大破坏，打开一道翻腾漩涡撕裂恶魔的凡体，或以一发诡秘闪电惩击他们的敌人。

除了能够释放奥术力量外，所有灰骑士都擅长抵抗敌人的邪恶能量。智库则拥有更强的防御能力，能挡开混沌的险恶影响，仿佛那不过是些污浊空气。

鲜有什么能难倒一名智库，因为至圣所中记载着全帝国已知的每一种魔符与咒语，而智库正是从这些典籍中汲取学识——尽管其中绝大多数召咏都过过危险且不稳定，无法付诸使用。

虽然智库为灰骑士打击部队贡献良多，但他最重要的任务却是在泰坦要塞修道院的高墙之内履行。正是在这里，智库会教给新兵所有灰骑士都必须知晓的奥秘：六篇拒斥圣颂、七词生死真言、八首战斗之歌、九种构成所有训导基础的可怖力量，且远不止于此。

智库的教导是一个极为严苛的过程，许多有志者都无法从中幸存。可即便智库被要求表现冷酷，他们的行为中也无甚残忍，亦无恶意。这种对弱者的淘汰仅仅是一种必要——为使灰骑士保持不可腐化，其心智与意志必须同身体一般坚强。

少数智库能有幸活到身体无法再承受征战之苦的年岁。这样的战士会被完全移出战团的战斗名单，退隐到至圣所迷宫般的回廊中，担负起守护密室之责。唯有这些古者知晓完整的记载目录，因为其中深埋着某些连大导师都不知情的秘密。这类奥秘绝不允许逃出至圣所的监禁，因为始终存在这样的担忧：即使是灰骑士的某些成员，也无法免疫它们的诱惑。
