之前一段时间，每个人都觉得亚瑞克已经死了。而现在，我们会告诉你他在阿米吉多顿的惊世回归之前到底经历了什么。

那些记得上一次兽人入侵阿米吉多顿的人或许还记得，碎骨者·萨拉卡试图开启战争的新阶段，穿越群星，决心发动那场“大Waaagh！”并寻找一场更痛快的厮杀。亚里克斯率领一支黑色圣堂部队紧随其后，穷追不舍。

这支舰队一路追击着这头“阿米吉多顿之兽”穿行于各个星区，而他则建造了一座连帝国鸟卜仪都无法勘测的神秘装置。最终，他们在伊卡利亚世界上追上了碎骨者的兽群，却赫然发现整颗星球正因他那疯狂造物所释放出的巨大能量而崩塌——那是一座由破铜烂铁堆砌而成的山峰，撕裂天空，迸射出绿色的闪电。

伊卡利亚世界上释放出的末日般的能量将碎骨者困在了一座岩石台地之上，四周尽是交战中的军队。亚瑞克果断出手——他集结起自己那支饱受重创的舰队（其中包括一艘芬里斯的打击巡洋舰），直插兽人舰队的咽喉。他亲率一支精锐突击部队，直接登陆到“野兽”的面前。

一阵足以摧毁整支军队的猛烈炮火轰向碎骨者，激起滚滚浓烟。这头“野兽”发出咆哮，虽已受伤，却依然桀骜不屈。太空野狼施展出一场风暴寒霜之术，将碎骨者那庞大的身躯压倒在地，然而当碎骨者发起冲锋时，那股寒霜之力却如枪响般瞬间崩碎。

亚瑞克起身迎战他的宿敌，挥动巨大的机械爪，以锋锐如剃刀的爪刃正中碎骨者的胸膛。然而，他的宿敌曾经历过远比如今更重的创伤，这位战争头目以铁钳般的巨掌攥住了政委，将他举至面前，亚瑞克的骨头在紧握中如枯枝般碎裂。

一记山崩地裂的头槌轰然落下，猩红的鲜血如喷涌的羽饰染红了“野兽”的面庞。他将亚瑞克猛摔在地，抬起覆着铁甲的巨足，正欲将这毕生大敌彻底碾碎——却在最后一刻停住，露出一个狰狞的笑容。又一次赢得胜利的他，在星球濒临毁灭的剧烈震颤中抽身离去。

在那场帝国军队四散奔逃的混乱中，无人注意到一位身着黑色盔甲的芬里斯牧师悄悄带走了这位传奇政委仅存的残躯。

他溃逃的部队上报了他的死讯，不久后，“失落大钟”在泰拉上敲响。然而，这位“阿米吉多顿的老爷子”却以万分之一的几率奇迹般地活了下来。亚瑞克躺在一艘太空野狼打击巡洋舰的医疗舱中。尽管他再一次逃过了死神之手，却再也无法恢复如初——他那经过再造的头骨永远隐隐作痛，断裂的肢体由一副义体骨架支撑着，而他的肤色，即便对于一个年迈之人而言，也显得异乎寻常的苍白。

那位头戴颅骨头盔的太空野狼牧师告诉他，阿米吉多顿仍需要他，因此他们必须前往那里。唯一的问题是，他们能否及时赶到。否则瓦兹达卡·古茨梅克的“飚速Waaagh！”会在亚瑞克再次踏上这颗受诅咒的星球之前，就已将其彻底蹂躏。
