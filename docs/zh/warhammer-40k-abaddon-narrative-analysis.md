# **阿巴顿：混沌之选**

# **作者：Aaron Dembski-Bowden**

# **翻译：飞天德**

译者B站：

# ** 于耻辱与阴影中重塑，重获自由。当众生皆向王座俯首，他于黑金之中重生。兄弟们，当众生皆孤立无援。**

# ** 囚徒被带到我们面前时，我分不清他是尚有尊严、不愿做徒劳挣扎，还是根本无力反抗。他的盔甲曾是其覆灭战团标志性的庄严白色，如今已沦为锈蚀的炮铜灰色。昔日陶钢装甲上引以为傲的荣誉徽章与战功令牌，如今只剩伤痕与焦痕作为唯一的“装饰 ”。我本可以说命运待他不公，但这是谎言 —— 对他不公的是我们，对他的战团不公的是我们，对他们试图保护的民众不公的是我们。****这与命运毫无关系。**** 我的红字战士将他掷在泥泞中，任务完成后，他们转向我，面罩对准我，等待命令。****“他敢动就杀了他。 ” 我无声地灵能传讯给他们。**** 这些早已无法伪装生命迹象的亡灵，以缓慢如幽灵的动作，将华丽的爆弹枪对准匍匐的俘虏。油污般的暴雨猛烈抽打着我们所有人，从兄弟们带角的头盔和我那灰烬般死寂仆从的赫尔塔兰胸甲上嘶嘶滑落。**

# **“让我来。 ” 莱奥尔说。他头盔的嘴部是陶钢铸就的狰狞**

# ** **

# **獠牙。这头盔曾是红色，如今已化为纯黑。“让我执行判决。 ”**** 近些年，莱奥尔养成了在盔甲上刻下击杀标记的习惯。手中没有武器时，他的双手会不受控制地抽搐，令人不安。**** 指挥官未作回应，莱奥尔便上前一步，将链锯斧带齿的刃口抵在俘虏的脖颈上。**** “埃泽凯尔，请让我获得这份荣耀。 ” 我从他心中只感受到忠诚而愤怒的崇敬，如同无形的刺痛迷雾般散发出来。**** 囚徒抬头 —— 目光桀骜不驯，却难掩对我兄弟说出的名字的惊讶。但我们是埃泽卡里翁黑暗议会的成员，唯有我们有权直呼战帅之名。**** 泰勒马库斯站在我身旁，双臂交叉于胸甲前注视着一切。他的思维对我封闭，我也乐于如此。上次我试图杀他已是九年前，而他上次对我拔刀相向也过了七年。**

# **“兄弟，稍安勿躁。” 他对莱奥尔说，“这人或许还有用。”**

# ** 泰勒马库斯的声音是我听过最美的 —— 足以动摇灵魂、净化良知，温柔却不显软弱，坚定却无傲慢。即便通讯器的干扰杂音，也无法玷污其流畅的语调。**** “卡扬。” 战帅开口。我闻声转头，看向阿巴顿—— 我们之中唯有他在暴雨中未戴头盔，暴露面容。像我们这样拥有第六感的人，很难长时间直视他。****“埃泽凯尔。 ” 我回应着，已然移开目光。****“你有何建议？ ”**

# ** **

# ** 他知道我已厌倦这场战争。我曾不止一次威胁要率领舰队脱离军团，先行狩猎其他猎物。只因战帅的请求，我才留在前线与他们并肩作战。**** “如果你想让我从他的内脏中窥探命运，兄弟，我建议你去问白先知或哭泣少女。 ”**** 我冒险再次瞥向他。落日余晖中，他的眼睛闪烁着不健康的琥珀色光芒，枯槁皮肤下布满蛛网般的血管，涌动着滋养他不朽肉体的力量。****我听到他的剑开始向我低语，才意识到自己看得太久了。**** 我立刻转回目光看向囚徒。这位杂血战团的连长，在死亡逼近时瑟瑟发抖 —— 他的一颗心脏已经停跳，身上的血腥味浓烈至极，即便暴雨与寒风也无法掩盖。他的呼吸在被割伤的喉咙里发出嘶哑的声响。**** “我无需从他的垂死挣扎中寻求预言。 ” 阿巴顿告诉我，亲自走上前，将荷鲁斯爪弯曲的镰刀状刃口搭在囚徒的肩膀上， “你为何不反抗就束手就擒？ ”****这位连长抬起头，对着这柄曾斩杀原体的武器，啐了一口。**** 莱奥尔发出沉闷阴暗的笑声，泰勒马库斯的笑声则悦耳动听，让人忍不住随之发笑。就连我，也为这位战士最后的反抗之举露出一丝微笑。暴雨冲刷掉精钢刃口上带着酸味的唾液。**** 唯有阿巴顿表面上不为所动，但我能感受到他心中一闪而过、毫不掩饰的愉悦。他蹲下身，盔甲关节发出刺耳的磨合声响，面**

# ** **

# **对囚徒。**** “这能抚平你的耻辱吗？ ” 他问连长，声音残酷却温柔，近乎……和善，“这小小的恶意爆发，这微不足道的反抗，能减轻你未尽职责便死去的耻辱吗？能为我们屠戮亵渎的一千名你的兄弟复仇吗？能为你守护这颗星球的失败正名吗？ ”**** 连长再次啐了一口，这次直接啐在战帅脸上。阿巴顿微笑着任由唾液顺着脸颊滑落。**** “兄弟们，这就是我们缺席时，人类帝国孕育出的杂种、被洗脑的崽子们 —— 这就是我们的‘继承者 ’。 ”**** 更多人发出哄笑。连长的反抗固然真诚，但他选错了炫耀骄傲的对象。**** “ 曾经， ” 战帅对他说，“我们是天使。我们不受帝国法律约束，而是凌驾于法律之上；我们不是人类的守护者，而是人类的主宰。 ”**** 连长吸进最后一口气，准备进行第三次、也是最后一次啐击。但阿巴顿没给他机会。战帅以近乎怜爱的缓慢动作，将一根利爪刺入星际战士的胸膛，如同温柔的抚摸，缓缓剖开他的心脏、肺腑、肌肉与脊椎。**** “听到那尖叫声了吗？ ” 他轻声说，“你逐渐模糊的感官边缘传来的嘶吼？诸神来接你了，英雄。他们来取你的灵魂了。”**** 阿巴顿收回利爪，在垂死的战士额头上落下一吻 —— 如同青铜时代的军阀为选定的战士赐福。**

# ** “安息吧，勇敢的人类勇士。毫无价值的一生即将终结，你将在灵魂之海中获得应有的‘奖赏 ’。 ”**

# ** 他站起身，失去支撑的连长尸体瘫倒在泥泞中。但战帅转身前，却犹豫了一瞬。**

# **“卡扬。 ” 他对我说。**

# **“兄弟。 ”**

# **“你能找到吞噬这位战士灵魂的恶魔吗？ ”**

# **他知道我能做到，他是在问我愿不愿意。**

# **“我会办妥。 ” 我告诉他。**

# ** “多谢。将恶魔束缚在他的尸体中，与其他‘杂血种 ’一同丢弃。 ”**
