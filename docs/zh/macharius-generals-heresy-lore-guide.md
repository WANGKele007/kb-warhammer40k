# **马卡里乌斯诸将**

率领马卡里乌斯军团的将领们背景极为多样，但都怀有宏大野心。马卡里乌斯亲自从帝国最能干、最狡黠的军阀中遴选他们，其中数人曾与他直接交战。内务部许多官员质疑马卡里乌斯此举，询问这些昔日敌手是否危险。"他们当然危险，他们是狼，"马卡里乌斯留下名言，"但他们是我的狼。"远征期间，马卡里乌斯常利用将领间的竞争关系为己谋利，通过设定挑战让他们角逐荣光，从而激发出更大潜力。

塞扬努斯统领第二军团。他身形魁梧，以鲜红发色著称，嗓音洪亮甚至能压过宏炮轰鸣。塞扬努斯喜欢身先士卒率军作战，士兵们都赞颂他的无所畏惧。在奥洛克兰，塞扬努斯与持有诅咒歌刃的祖尔凡缝合族交战，负伤导致余生行走不便。帝国史书记载，在远征抵达帝国疆域外最远的世界马卡里亚之极时，他只比马卡里乌斯晚上一秒踏足该地。时间证明了他对太阳领主本人及对帝国的忠诚，远超马卡里乌斯麾下所有将领。

著名的决斗家塔尔卡指挥第三军团。这位肤色黝黑、身形精瘦的将领满布无数决斗伤痕，是个恪守古怪荣誉观的军人，对轻慢之事动辄愠怒，倘若自觉荣誉受辱则立马要求亲自决斗。塔尔卡的部队深入太平星域未勘测区域，然而不幸的是第三军团的前锋侦察队发现了恶名昭彰的阿德兰提斯五号。该人类世界拥有超凡科技，竟将帝国军队阻滞两年之久。史书载录，最终马卡里乌斯下令改变一颗彗星轨道撞向该星球，如今该地已荡然无存，令机械修会痛惜不已。然而审判庭对阿德兰提斯五号的覆灭知晓截然不同的版本。无论真相如何，第三军团兵力损失逾95%，塔尔卡自此终生心魔缠身。

第四军团由尊贵的莱山德统率。这位出身古老世家的苍白贵胄，因世代累积的基因增强而拥有骇人巨力。莱山德坚信许多星系隐藏于银色区域的银雾之中；然而，在他与部下同格里森的恐怖虚空幽魂激战后，他建议或许让某些真相永远埋葬才是上策。荣誉感最终导致了他的堕落——当意识到远征期间征服的星球正遭受何等残酷的榨取时，这份荣誉感将他引向了异端之路，并在太阳领主逝世后与帝国为敌。

马卡里乌斯麾下将领中最强大的竞争对手是第五军团领袖博尔根·克拉苏。他体型宽厚近乎身高，右眼与嘴唇间那道狰狞伤疤永久扭曲了他的面容，显出一副乖戾的怒容。他以热衷战利品、惯于夺取超过应得份额而闻名，但对部下却格外慷慨。第五军团在向边缘地带推进前，攻占了许多最终组成伊克斯次星区的世界。正是克拉苏说服了赫罗姆的欧格林人加入帝国卫队，许诺他们能吃多少就供应多少口粮。这或许是个欠考虑的承诺，但他随后在沃尔科斯战场对抗险恶的伊卡尼尔保护领及其恐怖剥皮犬时，将大部分欧格林人消耗殆尽。马卡里乌斯死后，在马卡里乌斯之乱的黑暗岁月里，克拉苏被证明是帝国的真正忠诚者，并最终被国教封为圣徒。

狂热信徒阿里安统领第六军团。这位信念严苛、不惜焚尽一切阻碍者的将领，以其完全冷酷的行径而恶名昭著。他认为自己与部属在远征期间的一切作为皆属正当，因为任何反抗帝国亦即反抗帝皇者皆为异端。阿里安负责攻打了后来构成安多斯克次星区的诸多世界。据说其甜言蜜语式的雄辩曾说降众多摇摆星球的民众——至少是暂时的，第六军团最初征服的许多世界在马卡里乌斯之乱期间爆发了激烈叛乱，叛乱期间，阿里安无视帝国命令，屡屡仅因自认为的亵渎之举便将整个世界付之一炬。在他去世许久后，阿里安仍然因为其虔诚被国教封圣。

居鲁士是一位身躯巍峨的巨人，长着一双令人不安的、冰蓝色锐利眼眸，他统领第七军团。居鲁士以其卓越的时机把握能力和攻击的绝对精准性而闻名。在与卡尔明扭曲的奥尔诺斯族在作战期间，据信他洞悉了有关艾兹尼斯深渊本质的某些黑暗真相。此后他很快开始进行未经授命的远征，是马卡里乌斯麾下唯一曾深入翡翠帷幕未知深处的将领。他在对抗索斯神秘学者的战斗中赢得了巨大荣耀，但最终却在马卡里乌斯之乱期间成为了帝国最大的祸害之一。历经数十年战事，帝国最终终结了马卡里乌斯之乱。居鲁士据称在一次与阿斯塔特的大规模舰队交战中阵亡，但关于他如何在战斗中逃脱的传言始终不绝。数名在该星区活动的审判官曾追查此类传言，但无一找到可信证据。

# **马卡里乌斯之乱**

当马卡里安的太阳尚未沉入太阳领主墓冢之时，他麾下的将领们便爆发了激烈争论。数人自认是马卡里乌斯的明确继任者，而塞扬努斯将军则严正指出：随着远征正式结束，无人能对太阳领主之位拥有任何"权利"。刀剑出鞘，鲜血飞溅，若非下属强行拉开争斗的将军们，伤亡恐难避免。

未待争端真正解决，征服领土爆发起义的消息已传至马卡里安。部分星球听闻马卡里乌斯死讯后，认定帝国过于衰弱而无法维持统治，选择叛乱独立。内务部随即下令，命令将军们担任其攻占领土的临时指挥。尽管马卡里乌斯的将领皆具战术才华，但他们终究不是马卡里乌斯。庞杂的职责使其不堪重负，他们很快发现无力维系曾经征服的广袤疆域。事实上，多数人决定统治各自的军事帝国并互相征伐，其中数人更是蓄意曲解泰拉的命令来为自己正名。

各个战斗群的军官们也认定自己已为帝国奉献一切，理应获得回报，随即以武力抢占了自己的领地。帝国绝不容忍此等叛乱，开始调遣星际战士打击小队进入该区域，命令他们镇压战事、处决叛首、恢复秩序。参与的阿斯塔特日益增多，最终有上百个战团介入马卡里乌斯之乱。该区域持续数十年的冲突后，泰拉高领主最终派遣新晋战帅梭伦不惜一切代价恢复秩序。历时近七十年，马卡里乌斯之乱方告终结，马卡里乌斯征服的领土终获正式平定。

## **余波**

"我踏足过太多世界的尘埃，已无法悉数回忆。但我确实记得我们离开每个世界时的模样：臣服或化为灰烬。"

——《战场回思》，圣塞扬努斯著

马卡里乌斯远征最初为帝国征服了逾千世界，这一惊人数字自帝国创立的大远征以来未有能及者。马卡里乌斯大军与诸世界守军付出的代价极为惨重，据说无法计数的死者达数十亿之巨。

更有传言称某些世界曾遭灭绝令清洗，但此类记录严密封存，常被彻底销毁。马卡里乌斯之乱持续的数十年间，更多世界脱离了帝国掌控。部分世界（尤以边缘星域为甚）偶有叛乱成功，但更多世界则被战火彻底夷为废墟。远征的残酷速决及随后多年的叛乱，在马卡里乌斯及其部队夺取的疆域内滋生了诸多不满。

一些世界的统治阶层，通常是拒绝放弃昔日绝对权威的贵族家族，拒不遵从帝国律法。许多人集结所能、遁入星海求生，藏匿于未标记世界及古老小行星带与空间站中，始终警惕着马卡里乌斯的蜂拥大军，以及后来镇压马卡里乌斯之乱的部队。所有此类逃亡者皆被定为"缺席异端"，其幸存者至今仍是帝国之敌。

当然，并非所有归顺者皆心甘情愿。若干世界至今仍暗涌着积怨，有人固守与国教教义相悖的秘密仪式与前帝国信条，仅表面容忍帝国统治；有人屈膝只为生存，若可重获先祖时代的自由，他们会欣然坐视帝国焚毁。

## **忠诚的嘉赏**

远征军深入银河西部边疆的征伐如此深远，据内务部估算，最终需从太阳领主夺取的疆域中设立四到五个完整星区。尽管马卡里乌斯之乱的长年动荡带来诸多困难，内务部仍立即着手重建马卡里乌斯收复领土内各世界的基础设施。随着首个由远征征服世界组成的星区正式建立，塞扬努斯将军被册封为马卡里安星区总督，重建工作愈发体系化。 

 无论是对马卡里乌斯还是对帝国的忠诚，塞扬努斯将军都从未遭受严重质疑——即便太阳领主麾下其他数名将领相继叛变。他将重建马卡里安星区诸世界视作一系列延伸战役，并据此调配资源。内务部与国教的各类新下属机构被部署至此，以确保马卡里安诸世界的恰当治理及未来对帝国的服从。国教专门成立了新的战斗修女修会"神圣之璃修会"，以监视马卡里安星区的高贵族裔，并引导任何可能误入歧途的顽固贵族。 

 在马卡里乌斯之乱期间，经过"银白寿衣修会"一系列辉煌但惨烈的战役，幸存下来的受勋染血修女们决定组建新的次级修会以守护星区。塞扬努斯总督对战斗修女会的成就深为赞赏，遂下令在圣伊西多尔安息地为新修会修建修道院。"焦蔽面纱修会"自此恪尽职守地监察着整个星区的异端活动。 

 星区总督塞扬努斯被赐予尤为长久的寿命（尽管并非总是欢愉），因为在帝国战争中失去了众多子嗣。他将茜瑟丽丝次星区以其一位爱女之名命名，这位帝国卫队上校在马卡里乌斯之乱初期与违令者的战斗中阵亡。尽管生前坚拒，塞扬努斯在离世后不久被追封为圣徒，如今在马卡里安星区内被正式尊称为圣塞扬努斯。

## **战争遗产**

尽管马卡里安星区本身繁荣昌盛，但马卡里乌斯的所有征服却并非如此。因维苏斯星区位于马卡里安星区的边缘方向，在马卡里乌斯之乱后从未完全恢复。其治下世界经常未能完成征税配额，即便处决多名渎职总督也未能改善此状况。奥斯特里亚星区位于茜瑟丽丝次星区的自转方向，虽然拥有若干高产世界，但M41.760年镇压兽人Waaagh！的战争令该星区大片区域化为废墟。戈尔戈诺斯星区与勒尔尼安星区亦属这位伟大圣徒收复的疆域，但所有星区在与以其名命名的星区荣光相较时皆黯然失色，至少马卡里安星区的公民如此宣称。
