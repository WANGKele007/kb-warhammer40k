順便補充一個東西，不少人看資料應該都會看到「屍體澱粉是精煉鉕 ( promethium ) 的副產物」這個說法，老實說我不確定來源還是哪裡提到過

 看過我之前專欄提供的資料就知道屍體澱粉加了啥官方本來就沒寫，事實上鉕是真的能提煉出食品的，來源同樣是出自【Caves of Ice，2004】：

 【鉕生產過程中所產生的副產品為製造種類繁多的日常必需品提供了原材料，從染料、塑膠和藥典到構成某些荒涼鑄造世界勞動階級主要食物的合成蛋白棒，無所不包。】

 另外其他小說裡也有出現過星際戰士為了活命喝下鉕的場景，所以你說鉕能吃也沒問題，但就如我開頭說的，官方就沒寫屍體澱粉加了啥，屍體澱粉主要也不是吃是消耗屍體，你真要說他搞不好不只鉕，屍體都能加了還有啥不能加的，但跟鉕沒啥直接關係。
