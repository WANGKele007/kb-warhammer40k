# **命运丝缕**

再次踏上坚实的土地，的确是一件奇事，巴斯特·申思忖道。当他睁开眼睛，看到的是沉闷单调的泥土和岩石，而不是那片翻涌着无尽疯狂与毁灭的万花筒时，当真不可思议。

“命运将我们引向了这里，”他转向图特·海窟特说道。这是他相识最久、最值得信赖的同伴，他曾在此人身边直面过疯狂与湮灭。“穿越时间与空间，渡过非物质界的无尽潮汐后，我们终于来到这个交汇点。”

申与他的分灵之刃被抛回现实，已经是九天前的事了。他们终于脱离了那个梦魇般的维度，而他们被困在那里……究竟有多久了？术士自己也说不准，仿佛有永恒那么久。他一度以为折磨永无休止，万变魔君伊克斯克拉玛希农永远不会厌倦玩弄他的心智与灵魂，永远不会厌倦用更精巧的酷刑来惩戒他的狂妄。

然而，某种力量干预了这一切。申摆脱了那个可怕的命运。至少，暂时如此。

“可为何偏偏是现在？为何偏偏是这颗可悲的星球？”

海窟特沉默不语。他已有一万年不曾开口，今后也不会再开口了。这位战士曾遭阿里曼的红字咒语诅咒，如今不过是一捧尘埃与一套古老装甲的结合体，装甲里面浸透着巫术能量。他的终结者装甲上满是数百年征战的划痕与磨损，仍然泛着奇异的微光。千子军团的精锐战士“圣甲虫秘社”的符文荣誉印记，在装甲表面微微闪烁。

“你说得对，老朋友，”申沉默片刻后，点了点头，“我还需要了解更多。关于这颗星球，关于银河现在的局势。这些低等生命只能提供些愚昧虫豸的聒噪。”

他说着，抬起战靴轻轻碰了碰脚边的尸体。在他的灵能探查将这名卫兵的大脑烧至沸腾之前，他已经从对方恐惧的意识里撬出了一些零散的记忆。那些记忆不过是些半成形的死亡与毁灭的影像：如果不是地处要害，这颗名叫警戒星的行星本该毫不起眼；一个被撕成两半的银河；异形大军如蝗虫般压境，而帝国为了守护他们的圣地，将数十亿生命掷入战争的熔炉。

不过，让他体会最深的，还是那个凡人的剧痛与恐惧，以及那股几乎从内部把他蛀空的腐烂。

申仔细看了看这具尸体。死者眼眶深陷，眼珠发黄，面骨和肋骨古怪地向外鼓胀，仿佛有什么东西正在从里面把它们撑开。死者右手的血肉已经和甲壳甲的手套融为一体，几根像是几丁质的尖刺刺穿皮肤，像弯曲的指甲一样伸了出来。

“权当死亡是对你的仁慈吧。”术士低语道。

他一眼便看出这是超自然力量在起作用，因为那具仍在搏动的残破躯体正在散发着巫术的恶臭。在这之前，当他们深入神殿区时，已经杀过二十多个同样遭到感染的变异体。那些怪物的心智早已被蔓延至整个躯体的疾病吞噬殆尽，带着自杀式的偏执冲向圣甲虫秘社终结者。哪怕正被后者有条不紊地切成碎片，它们还在试图用粗陋的临时武器劈砍、敲打着千子军团坚不可摧的装甲。

熵与腐朽的气味弥漫于这些地下墓穴之中。远处，申听到了一阵骇人而痛苦的齐声哀嚎。墙壁上覆盖着一层滑溜溜的黄绿色黏液，大量肥硕的蛆虫在地板上爬动。

“这些迹象都是瘟神仆从的手笔。”申低声说，面甲遮住了他嫌恶的冷笑。

也许，这就是强大的奸奇饶他一命的原因？侍奉造命主的他与纳垢腐烂的奴仆之间，从来就没有半分好感可言。申与他的同僚追寻启迪、积累知识，而那些跪拜瘟神之徒只想用污秽淹没银河，从死者腐烂的尸骸中孕育出畸形的孽物。

 “走吧，”他迈步向前，带着崭新的决心，“让我们亲眼看看，瘟疫之父为警戒星准备了什么。”

分灵之刃沿着弯曲的石阶拾级而上，一缕昏黄的日光从上方渗漏而下，照亮他们的身形。石阶尽头是另一段更缓的阶梯，向下通往一片宽阔的露天圆形庭院。四周矗立着古代英雄的巨型雕像，有的双手紧攥巨剑的剑柄，有的高举镌刻着帝国徽记的巨盾。他们头顶的天空像一道溃烂流脓的伤口，病态的惨绿色雾霾笼罩在肃穆的巨像上，也笼罩在那些被集中的炮火击倒的雕像残骸之间，这些残骸乱糟糟地纠缠在一起。

极远处，重炮轰鸣不停，带着擂鼓般的狂怒。申分辨不出那些炮声属于帝国忠诚派还是异形入侵者，这并不重要。眼下，战火已掠过此地，只留下满目疮痍。

雷声又滚了过来，这次近了很多。那是沉重的战靴踩踏石板的声音，还有一段不成调子的挽歌，听得申牙根发酸。

“隐蔽。”他下了令，同时朝周围的雕像示意。那些巨大的凹洞足以轻松容纳终结者装甲高耸的身形。圣甲虫秘社不紧不慢地隐入凹洞，自身也化作雕像，与头顶的石雕守卫一样沉默。

申隐藏在门洞的阴影中，隔着庭院望向对面。他随手一拢，暗影就如同斗篷般裹住全身。

片刻后，几道庞大的身影从回廊另一侧走到阳光下。每个人的体型都与一名圣甲虫秘社成员相当，锈迹斑斑的终结者装甲上涂满了各种难以名状的污秽之物，头盔与臂铠怪异地扭曲变形，仿佛血肉与陶钢已经融为一体。其中一个长着一对不断抽搐的昆虫前肢；另一个的头盔上顶着一根巨大的、发霉的犄角，像是猎手甲虫的角。他们带着肆无忌惮的自信踏入庭院，仍在用低沉的喉音唱着悲哀的歌，嗓子眼像是被脓痰堵住了。他们是凋零霸主终结者，死亡守卫的精锐。

看来瘟神在警戒星上确实有重大图谋，申暗自思忖。那么眼前这些人就是极有价值的猎物，是可能照亮他命运之路的情报来源。他要撕开这些蛮汉的胸膛，从他们腐烂的内脏中撬出无数的秘密。

“动手！”这位至尊术士发出心灵感应，让他的命令同时传入麾下每一名战士的意识深处。

圣甲虫秘社整齐划一地跨出了阴影，边推进边射击。尖啸的次元火爆弹飞过庭院，砸在凋零霸主们的铠甲上。但纳垢的神选勇士在猛攻之下几乎没有后退，他们毫不在意地扛住攻击，好似不可阻挡的战车般碾了上来。

阿蒙霍特普的掠魂炮发出狂暴的咆哮，在复合爆弹枪的轰鸣中也听得一清二楚。即便交火声震耳欲聋，申仍能分辨出阿蒙霍特普富有节奏的连发规律，他每一轮射出的弹药数都是九的倍数，那是奸奇的圣数。他的射击在领头那名死亡守卫的胸甲上拉出一道弹痕线，黑褐色的脓汁溅得到处都是。

紧接着，两队终结者撞在了一起。凋零霸主们打得从容而精准，斧头和刀刃像剁肉刀一样抡起又落下，试图以毁灭性的一击砸穿对手的装甲。相比之下，圣甲虫秘社的战士几乎算得上优雅。终结者装甲根本不是为近身决斗设计的，但他们手中的动力镰状剑却舞出了精妙的轨迹，既格开了死亡守卫那些更重的兵刃，又多次命中这些纳垢信徒的装甲板。

安卡倒了下去。一名死亡守卫挥着巨大的钉头锤和连枷，一记重击砸碎了他的胸甲。那东西与其说是一件实用的武器，不如说是一颗握在手里的破碎球。这颗铁球渗出恶臭的浓烟，烧灼着申的肺部，让他满嘴泛酸。

“够了。”申低语道，随即从阴影中踏出。他高高举起力场法杖，以太能量涌入杖尖的水晶魔眼。咒语自他唇间流出，法杖向着庭院对面猛然挥落。

霎那间，一道次元火流扫过庭院，炽烈的多彩火焰将凋零霸主们尽数吞没。离他最近的那个死亡守卫被烈焰风暴掀飞，重重地砸落在地，地砖在他装甲的恐怖重量下碎裂四溅。

空气中弥漫着熔融金属与焦肉的气味。申横握法杖，踏过火毯向前迈进。死亡守卫看向他，他微微一笑。没错，他已经太久没能在瘟神那些无知的仆从身上施展自己的法术了。

死亡守卫的爆弹呼啸而来，却被申下意识张开的灵能护盾弹开。

 “腐朽之力的奴仆们，我的道路不会在此终结，”他说着，又掷出一道贪婪的火焰。“给我跪下，认清你们必将毁灭的事实吧。”

# **分灵之刃**

千子术士巴斯克·申的故事既诡异又骇人。数千年来，申一直效命于预言密教，解读亚空间变幻不定的潮流，想要预言出种种可能的未来。这些可能性并非不可改变，完全可以导向对赤红马格努斯子嗣有利的方向。红字仪式举行时，申就在场。准确地说，他就是当年与叛逆的阿泽克·阿里曼一同试图以黑暗巫术治愈饱受变异折磨的兄弟们的术士之一。就在那决定命运的一刻，千子军团的大部分战士都被诅咒，化作禁锢在动力甲内部的无魂空壳，永世充当奸奇的奴仆。他们的病症虽然被治愈，人性的一切痕迹却被尽数夺走。在那场浩劫之后的数个世纪里，申一直潜心钻研预言与占卜，试图在可能性织成的那张网里，找出一条既能重振军团荣光、又能让自己跻身最高权力阶层的道路。

申的执念是如此之深，他常常心甘情愿地献祭数千无辜者的灵魂，只为从预兆中获取最微弱的一点灵光。他与他麾下一支由圣甲虫秘社终结者组成的精锐杀戮小队“分灵之刃”曾发动过多场星系级战争，仅仅是为了让他能够走在尸横遍野的战场上，在死者身上施行肝卜仪式。他们曾闯入太空死灵霸主和埃尔达先知的内殿圣所，寻找被遗忘的圣物和记录古代预言的典籍。他们还犯下过最骇人听闻的堕落与屠杀之举，只为召唤至高天的精魂，让申与奸奇最强大的仆从进行交谈，再从它们的口中撬出秘密。

与这样的存在打交道，无异于招致惩罚，但巴斯克·申早已越过了理性的界限，一心想要扭曲命运之线为己所用。当申试图召唤绰号“守望者”的万变魔君伊克斯克拉玛希农，打算将这头大魔束缚于自己的意志时，他才真正明白了自己所作所为的代价。这场仪式以一万名在永不熄灭的火刑柱上饱受折磨的忠诚派战士的灵魂为能量，却仍不足以压制伊克斯克拉玛希农的力量。那魔物挣脱了束缚，屠杀了申的数百名奴仆，并击败了这位术士和他的分灵之刃。然而，伊克斯克拉玛希农并没有仅仅杀死这个胆敢挑战自己的凡人，而是转而试图将他逼疯，以惩罚他的狂妄。他将术士及其护卫猛地掷过时间和空间，把他们从现实的时间流中扯出，抛入亚空间的潮汐。数个世纪后，历经无数难以名状的痛苦与折磨的分灵之刃，又被看似毫无规律地抛回了物质界。为了寻找自己得以解脱的原因，也为了探明奸奇的意志，申又一次投身于占卜中，只为洞悉自己真正的命运。

申的护卫们都是圣甲虫秘社的成员，他们曾是千子军团最顶尖的战士，后被阿里曼的红字所摧残。尽管他们早已失去了血肉之躯，申仍然会跟这些魁梧的终结者交谈，仿佛他们还是自己当年认识的战士。当申追忆着昔日的荣光与曾经的手下败将时，圣甲虫秘社的战士只以沉默回应，但当战斗召唤他们时，他们依然会动用生前全部的战斗技艺保护这位术士。

图特·海窟特是千子军团陨落前便深得马格努斯青睐的老兵，他曾在大远征时期与原体并肩作战，也曾亲历过璀璨的首都世界普罗斯佩罗的陷落。昔日那段荣耀历史的回响早已沉寂，但这名终结者依旧是一股势不可挡的致命力量，他手持喷吐火舌的复合爆弹枪，挥舞镰状剑杀入敌阵。

阿蒙霍特普是这支杀戮小队里的重武器专家，手持一门巨大的掠魂炮。与同袍一样，这位魁梧的战士不会流露任何激情或情感，但他确实有个古怪之处：他的一举一动都被数字九，即奸奇的圣数所支配。因此，他会打出节奏分明的连射，倾泻熔化灵魂的狱火弹。而他的每一个步伐、每一个动作，同样以这个数字为准。

图特摩斯周身燃烧着地狱烈焰，高举镰状剑猛冲入阵，将分灵之刃的敌人劈为两半。这位红字战士的冲锋狂暴至极，简直让人以为他的终结者装甲内有一个活生生的、会呼吸的存在——若非每当战斗的威胁一消退，图特摩斯便又如雕像般默默伫立，环绕他的诡异辉光也随之消散。

**Fractal Blades：**分灵之刃

**Basteq Shen：**巴斯特·申，“Basteq”来源于古埃及的猫女神巴斯特（Bastet），“Shen”在古埃及文化中有一个明确的对应物：寓意着永恒和保护的申环（Shen Ring）。

**Amonhep：**阿蒙霍特普，来源于法老名阿蒙霍特普（Amenhotep）。

**Thotek H’kett：**图特·海窟特，“Thotek”来源于古埃及的智慧神图特（Thoth），“H’kett”来源于古埃及的蛙女神海窟特（Heket）。

**Thotmas：**图特摩斯，来源于法老名图特摩斯（Thutmose）。

**Ankhu：**安卡，来源于古埃及最著名的符号之一：生命之符安卡（Ankh）。
