省流：經過改造可以給人類穿，但實際案例太少了。

 我們分成三個部份說明，什麼是戰鬥服、怎樣的人能穿戰鬥服、有沒有非鈦星人的穿戰鬥服 ( battlesuit ) ，第一和第二個問題我們先看十版軍書的內容：

 戰鬥服其實除了比較常見的XV8之外，更大型的KV128或是更小型接近動力盔甲的匿蹤用XV25甚至戰機駕駛員用的XV02都算，軍書裡也寫了火氏族的戰士服役4個鈦星年 ( 大概298個泰拉日 ) 後並通過第一次的火之試煉 ( Trial By Fire ) 晉升為沙司’烏 ( Shas'ui，Shas是火氏族，'ui算是老兵 ) 才有機會被考慮分派駕駛戰鬥服。

 我們來看看有沒有實際例子，目前有明確是非鈦星人穿戰鬥服的例子只有一例，出自小說【Broken Sword】：

 他們的領袖來到我面前，藉著噴射背包白熱的氣流緩緩降落。他輕盈著陸，氣流隨即停止。

 「幸會，人類之子，」他說道，我抬起頭，跪在地上的我視角中他顯得很得高大，如果我是一個較弱小的生物會感到恐懼，但我並非如此然而接下來發生的事卻讓我大吃一驚。

 動力服的胸甲裂開，隨著鉸鏈寬寬地向兩側擺動，露出了裡面的駕駛者，不同於我們的戰甲，他的肢體並沒有填滿盔甲的四肢，而是坐在一處空間內，他是在「操縱」這套裝甲而非「穿戴」它。

 此時這套動力服體積龐大的原因顯而易見了，從裡面走出來站在我面前的並非鈦星人，而是一個人類。

 「我是Gue’vesa Dal’yth O’Va’Dem。」他身材高大，五官高貴，目光堅定而沉穩，他穿著閃亮的白色貼身甲片，高聳的護喉遮住了他的下半張臉，額頭上烙印著帶有裝飾的人類帝國審判庭「I」字標誌。

 「我曾是審判官路西安．范．迪恩 ( Lucien van Deem )，如果你願意可以使用那個名字，我已經很久沒和星際修士交談過了，」他說。

 另外還有兩個例子比較尷尬，沒有駕駛但是有進到駕駛艙內，在【Farsight: Empire of Lies】裡有個生化系 ( Biomancy ) 的人類靈能者，但她是把自己變成鈦星人然後坐進Ob'lotai的駕駛艙內，具體如下：

 維科拉．赫拉特笨拙地坐在 Ob’lotai 5-0 的控制座艙內，對於在阿薩斯．莫洛克鬧鬼廢墟中持續肆虐的戰鬥，感到同樣程度的恐懼與著迷，鈦星人冷靜精確的戰爭機器正向下方城市中混亂與毀滅的漩渦合圍。

 戰火正烈，那是歐克蠻人與某種即便在帝皇審判庭中也僅被低聲耳語的存在之間的衝突——那種敵人讓維科拉感到胸口憋悶，彷彿快要窒息。

 她在 XV88 廣域型戰鬥服裡很安全，她對自己說道。

 事實上，她比大多數人都安全，她躲在一個鈦星人外交官的軀體裡，而這具軀體又躲在一個裝甲座艙內——這是一套比帝國無畏機甲先進十倍的戰鬥服，實際上，保護她的是那個令人感到病態早熟的種族所能提供的、最頂尖的尖端戰爭科技。

 隨著 Ob’lotai 5-0 盡力傳達外界的戰況，資訊六角視窗在她面前閃過，方正的鈦族字母更新訊息在各處閃爍滾動，速度快到讓她無法翻譯。

 在她左側，一個巨大的戰鬥服全息縮影正踏步前行，自從這台 XV88 被空運到指定戰區後，它便一直保持同步動作。

 另一個例子是出自【Shadowsun: The Patient Hunter】，其中有一段是影陽叫克魯特人【坐進】XV8戰甲中讓AI操控，但隊伍中有個火氏族的戰士提出抗議，整段如下：

 「進去戰鬥服，」影陽說道，「所有人都進去。」

 「追曉者、靜石，儘管你們現在的身分是火刃 ( Fireblade )，但我預設你們應該對 XV8 很熟悉吧？」

 「我在第四次擴張階段任職期間，放棄了穿戴『英雄斗篷 ( Hero’s Mantle，鈦星人對戰鬥服的別稱 ) 』的權利，」追曉者說道，「但在如果是打破約束的極端情況下，那麼是的，我能駕駛。」

 「我也能，儘管這意味著違背我們的就職誓言，」靜石說道，「我們將不再是火刃。」

 「已經是極端情況了。」影陽說道。

 「火之法典嚴禁此事，非我氏族的鈦族穿上『英雄斗篷』這件事想都不用想，更何況是跟我們不同種族？妳瘋了嗎？」追曉者說道。

 「這是極端情況，即使在我們種姓規定的嚴格規則範圍內我也有權隨機應變，所有人，進去。」影陽回答。

 「微光空，設定全迴圈程序... 然後進入最近的戰鬥服，你不需要駕駛它。」

 「我們會讓你保持飛行的，微光空，現在換你了，塔克，進去那台 XV8，如果有必要，像佩克查的木雕一樣把自己摺疊進去。」

 「不，」克魯特人說道，「即便受傷，我也不會進去那種東西裡面。」

 「那麼就在逆戟鲸墜毀時葬身在火焰中吧，你的救贖就在眼前，毫無疑問，你的族人隨後也會滅亡。你自己選。」

 克魯特人用自己的語言低吼了一句，隨即躍起，抓住最後一台戰鬥服的噴射背包，轉了將近一圈後，把自己縮進了控制座艙中。

 補充一下，火刃是火氏族的菁英老兵，實際上就是野戰指揮官，他們選擇不穿戰鬥服在前線指揮烈焰戰士小隊，從文中的敘述來看成為火刃就立誓不穿戰鬥服了。

 所以以技術來說鈦星人是做得到讓人類駕駛戰鬥服的，通過試煉的人才能穿上戰鬥服，從影陽小說的說明來看是火氏族才可能使用戰鬥服，正常來說其他氏族別想了，遠見八傑裡倒是有個原本是土氏族的Fio'O Vesa。

 所以問題在於怎樣的人能參加試煉？應該說火氏族之外的有沒有辦法？

 這部分我就真的不清楚了，火之試煉官方資料本來就沒寫啥，從寫比較多資料的六版軍書來看甚至連實際儀式要幹嘛都不一定。

 最後補充一下，最開始我是想從官階或位階去看看人類有沒有開戰鬥服的可能，這裡我們先來看看鈦星人的名稱邏輯，取自十版軍書：

 鈦星人名稱排法是氏族/種族、位階、出身、名稱、形容/頭銜，舉例Shas'o Vior'la Shovah Kais Mont'yr，解讀起來就是Shas / 火氏族、'o / 指揮官、Vior'la / 出生地、Shovah / 遠見、Kais / 形容技巧熟練的、Mont'yr / 身經百戰，這就是遠見指揮官的全名。

 因此我們來看看【Broken Sword】小說前審判官的名字，Gue’vesa Dal’yth O’Va’Dem，這麼看來鈦帝國的人類名稱應該也是相同邏輯，解讀起來可能是這串名字就是【來自 Dal’yth 的人類助手Ｏ’Va’Dem】。

 這裡有個的問題，如果是指揮官寫法應該是Gue’vesa'O，但有時候鈦星人名稱縮寫確實是會把O加在名字前，例如遠見的鈦名稱是Shas'o Vior'La Shovah Kais Mont'yr，可以簡寫成O'Shovah，從小說中審判官能指揮一隊戰鬥服小隊來看可以理解他確實有指揮的權限，有可能是筆誤。

 撇除筆不筆誤，從位階上看他確實有資格穿戰鬥服，問題在於位階的後綴也不是火氏族專屬，實際上各氏族都是如此，所以Gue’vesa'ui不一定等同於Shas'ui，同本小說裡甚至有Gue’vesa’vre的職位，結合影陽內的設定來看哪怕是火氏族當上火刃都不能開了，別的氏族也不用談，其他種族能不能開真的得打個問號。

 不過說起來鈦帝國內的人類其實定位比較模糊，有當戰士也有跑去幫水氏族外交的，但他們又不像克魯特人那樣特立獨行或是其他輔助種族真的只是專精某一塊，人類在鈦帝國內比較...泛用，所以有可能人類是真的位階到了就能開戰鬥服，或者那個審判官真的是特例 :P

 總之現階段來看確實人類能開，從官階來看也符合軍書的設定，但例子就一例，未來看GW會不會補充吧。
