# **沙漠掠袭者**

# **DESERT RAIDERS**

# **译者：范德彪**

# **作者：Lucien Soulban**

# **（坏点扫描 v1.1）**

# **第九章**

 “苦难写于沙，恩惠刻于石。”

 ——纪念者特雷莫《塔兰纪事》

1

 图尔克与尼斯里等候在指挥型奇美拉中，战车停在使徒洞穴入口内侧，身旁还停放着其他几辆作战车辆。两辆哨兵机甲守卫在侧，随时准备提供重型火力支援。附近堆放着燃料桶、弹药箱、炸药及其他防御洞穴所需的补给物资。

 两人倾听着洞穴外哨兵机甲驾驶员传来通讯。基地营地爆炸规模惊人，储备火炮炮弹足以造成毁灭性打击。高原顶部如今像一截烧焦雪茄，灰烬与浓烟弥漫。

 “泰伦情况如何？”尼斯里问道。

 “它们遭受重创。”驾驶员报告，“胡萨里少校等人成功激怒了另一支向你们逼近的虫群。爆炸摧毁了超过四分之一的敌军，包括一头与高原等高巨型生物。”

 尼斯里与图尔克交换眼神，随后点头。没错，他曾听闻泰伦能长到如此庞大体型。

 “那东西更像攻城引擎而非野兽。幸好它没能抵达我们这里，否则定会将整座山脉夷为平地。”

 图尔克点头，对着通讯器追问：“泰伦现在在做什么？”

 “看样子正在重整阵型，但进展缓慢，似乎……行动迟缓。”

 尼斯里捂住通讯器话筒，嘴角渐渐浮现笑容，些许紧绷的情绪得以舒缓。这是一次喘息的机会，虽短暂却弥足珍贵。“少校一定击杀了虫巢意志关键节点生物，给造成了沉重打击。”他对图尔克说，“它们正试图重新组织，这为争取到了备战时间。”

 图尔克明白其中关键：“我会告知士兵们，这次牺牲绝非徒劳。”说完，他走出奇美拉，快步前去传达消息。

 “一旦开始移动，立刻汇报。你和你的部下是否面临危险？”

 “没有，长官。我们距离足够远，即便它们追击，也能先一步抵达洞穴。”

 “飞行虫呢？”尼斯里追问。他还记得那些石像鬼般的泰伦虫族，它们的突袭迅猛如闪电，足以冲散任何部署完备防御阵型。

 “大部分飞行虫在爆炸中阵亡，剩余几只我们完全能够应对。”

 “很好。保持警惕，通讯频道随时畅通。尼斯里完毕。”

 他拍了拍通讯操作员的肩膀，指示对方记录下所有传来数据。随后尼斯里走出奇美拉，前去视察洞穴防御工事。至少在近期一连串危机中，一丝希望曙光终于穿透了阴霾。基地营地的牺牲为他们赢得了备战时间，也证明了泰伦虫族并非无穷无尽。军团实属幸运，仅有一艘虫族飞船着陆，尼斯里祈祷，迫使它们单独迫降的那场战斗，也能成为拯救他们的契机。

2

 图尔克穿过正在铺设另一捆炸药的士兵，走向努比斯向小队指挥官简报洞穴防御计划的隧道，十六名星界军士兵在一旁待命。不远处，一群士兵正在隘口处堆砌沙袋，搭建朝向通道深处的炮台。新任军需官萨巴克从他们身边走过，看到图尔克后停下脚步。

 “长官。”萨巴克拍了拍用Y型环带固定在背上的卷起布料，“我拿到了第892军团的旗帜。是否要悬挂在洞穴中？激励士气。”

 “多杀几只泰伦虫族就是对士兵最好激励。旗帜，等关键时刻再升起。”说完，图尔克继续向通道深处走去。

 这条隧道足以容纳一辆奇美拉通过，但蜿蜒曲折路径与起伏地势，让大多数车辆难以顺利穿行。隘口处是一条笔直通道，尽头是十字路口。根据最初简报，图尔克知晓这条通道与左侧另一条通道均从主通道分支而出，形成“Y”型交叉路口。两侧通道均用沙袋加固，布设了地雷，并各配备两门三脚架重型短管炮。任何闯入交叉路口生物，都将陷入毫无掩护致命交叉火力网。

 努比斯暂停简报，图尔克示意他继续。他十分好奇努比斯部下布设防御工事。努比斯回到墙边，那里用荧光漆绘制着隧道简易示意图。

 “我们已知泰伦虫族嗅觉敏锐，因此宰杀了部分骆马兽和驼兽，将尸体留在死胡同里。”他指着几条没有出口隧道说，“任何被尸骸吸引的敌人都会触发炸药，让洞穴塌方将掩埋。”

 “直接在它们抵达前炸毁所有隧道，坐等救援难道不是更简单？”拉库姆·内哈里上尉（Lakoom Nehari）问道。他身形瘦削，皮肤黝黑，模样更适合记账而非征战沙场。

 “这话从图雷纳格军官口中说出真奇怪。”努比斯说，“我这是务实之举。”

 努比斯叹气解释：“你忘了泰伦虫族有掘地虫吗？炸毁隧道，仍会挖地而来。而且无法预知进攻方向——哪条隧道？从顶部俯冲？还是从地底突袭？这样部署，能尽可能掌控战局，在塌方中击杀更多敌人，希望能震慑住它们。”

 “说到炸药，”努比斯继续道，“四条作战隧道每隔一段距离都做了标记。看。”他关掉沙袋旁照明灯，通道陷入黑暗，墙壁上绿色荧光漆标记显现。隧道更深处，每隔十米左右就有一圈漆环。“我们在每个标记点都布设了定向破片炸药，旨在击杀路径上所有目标，与嵌入墙壁的塌方炸药无关。”

 “隧道不会因此坍塌吗？”托里亚上尉追问。

 “只有下令才会。”努比斯厉声回应，“这些是破片炸药，专门用于杀伤敌人，和用于塌方炸药完全不同。”

 “最后一圈标记是什么意思？”托里亚毫不退缩，指向离他们几米远的漆环。

 “那是让你们向帝皇忏悔信号。”

 努比斯坦克点头，解散了其他军官，却留下了那十六名士兵。图尔克虽叫不出他们的名字，但知道他们是努比斯的反坦克与迫击炮支援小队——在洞穴中，他们的专业技能几乎毫无用武之地。

 “你们清楚任务吗？”努比斯问道。

 士兵们点头。

 “两人一组行动。炸药引爆后，会被困在外面，或者面临更糟的处境。”

 “我们为帝皇而战，”一人回应，“明白。”

 “诚哉。”其他人轻声附和，语气近乎戏谑。

 “很好。带上装备，找地方隐蔽。”

 努比斯坦克解散士兵，与图尔克目光相遇，随即移开视线，眼神中难掩内心的波澜。他脱掉上衣，前去协助星界军士兵为重型短管炮炮台添加沙袋。

 “我听说了，”努比斯一边堆砌沙袋一边说，赤裸的黝黑皮肤上汗珠闪烁，背上旧时鞭刑留下的疤痕如粗糙的绳索般凸起，“营地为争取了更多时间。胡萨里等人是帝皇的英雄。”

 “没错。”图尔克说，“停一下，看着眼睛说。”

 努比斯靠在沙袋上，锐利黑眼睛闪闪发光。图尔克知道，那目光中没有敌意——至少对他没有，但他能分辨出这位炮手长何时愤怒，何时准备开战。此刻，他的眼中燃烧着坚决的斗志，既要圆满完成任务，也要给敌人造成最大的痛苦。

 “科尔坦和你之间发生了什么？”图尔克问道，“和那天晚上有关吗？阿努曼等人死亡的那晚？”

 “长官，”努比斯回应，“军需官以英雄之姿殉国，我绝不会说死者的坏话，那会招致厄运。”

 图尔克点头：“我明白，朋友。”他在努比斯身旁坐下，示意其他星界军士兵退下。等人离开后，从战术腰带口袋里掏出一个磨损金属盒，打开后，三根手工卷制棕褐烟卷用橡皮筋固定着。

 努比斯微笑：“伊班·萨利德，竟然藏私。”他抽出一根烟卷，“谢谢。是库法集市那个老头卷的？”

 “他专门为卷的。”图尔克拿出一个小火柴盒。

 “啊。”努比斯露出欣慰笑容。

 “老头特意交代，”图尔克划燃一根长火柴，让火焰燃烧片刻，双手拢着火焰递向努比斯，后者将烟卷凑过去点燃，“雪松玫瑰火柴要烧两秒，才能释放出香味。”说完，他才用火柴点燃烟卷。

 “嗯。”努比斯深吸一口，浓郁香气在口中散开，烟雾袅袅升起，“味道真好，像……”

 “家的味道。”图尔克接话，“我知道，也想念家乡。”

 两人静静抽着烟，各自沉浸在思绪中，烟雾带来片刻惬意，也勾起了对美好往昔的回忆。当烟卷快燃尽时，图尔克开口：“朋友，我想谢谢你。”

 “谢什么？”

 “谢谢信守承诺，阻止阿努曼射杀更多尼斯里的部下，谢谢你成为我可以信赖的士兵，谢谢你是个言而有信的人。”

 努比斯点头，伸手覆在图尔克手上：“不客气，但我可不会嫁给你，你长得实在不符合我的审美。”

 图尔克抽回手，笑着说：“混蛋。”

3

 雷扎伊尔政委深吸一口混合着石灰岩与丛林气息空气，希望能永远记住这味道——不久后，鲜血与柯达火药的恶臭就会将其掩盖。使徒洞穴内充斥着引擎怠速的轰鸣与士兵们的号令声，但踏入丛林几步后，所有噪音似乎都消散了。有那么一瞬间，仅仅是短暂的一瞬，雷扎伊尔竟恍惚觉得自己正置身天堂，享受着片刻宁静。

 “我问你件事。”雷扎伊尔不愿打破这份静谧，却还是开口问道。他直视副官，神情无比严肃，“你是否给过伊班·萨利德中校建议，教他如何与达卡尔上校沟通？以他们的宿怨来看，两人能达成共识实在太过突然。”

 泰瑞尔犹豫片刻，低头看向脚下，随后点头：“抱歉，政委，但当时找到了摆脱困境的方法。”

 “就这么不信任我，不愿先与我商议？”

 “不，政委。”泰瑞尔立刻慌了神，“只是……我给出的建议是部族成员之间的私语，我绝不敢背叛信任……我发誓。”

 雷扎伊尔摇头：“下不为例，明白吗？若是换成其他政委，仅凭你玩弄信任这一点，我当场就会毙了你。”

 “是，政委，谢谢。绝无不忠之意。”

 “很好。”雷扎伊尔说，“接受道歉，但这是最后一次。”

 “是，政委。”

 两人继续向丛林深处走去，拨开挡路的植被。

 “但很好奇……你告诉中校什么事，觉得不能让我知道？”

 “并非不信任您，政委。”泰瑞尔解释道，“只是很难用言语说清。”

 “试试。”雷扎伊尔停下脚步，面向泰瑞尔，“慢慢说。”

 泰瑞尔思索片刻，试图找到最合适表达方式。最终，他深吸一口气，任由思绪自然流淌，开始解释：

 “政委，要明白，对塔兰部族成员而言，摇篮中习得的道理，会伴随他们直至坟墓。”

 “继续说。”

 “像伊班·萨利德这样班纳人，学到的第一课便是尊父-至高统帅是万物的最高统治者，对祂的效忠必须绝对。第二课，神谕者的话语不容置疑，因为祂传递的是帝皇的旨意。第三课，部族蒙受的任何冤屈，都必须讨回公道。”

 “这正是这支部队从一开始就存在问题。”雷扎伊尔叹气，“首先应该铭记对帝皇职责。”整件事让他心烦意乱，觉得不是在指挥一支军团，反倒像是在调解一场家族纷争。

 “是的，政委，但恕我直言？”

 “说。”

 “请不要射杀我。”

 “说！”

 “是，政委。”泰瑞尔显然十分紧张，“没有真正理解问题核心。您认为处决几个人就能树立纪律，但对一群甘愿成为殉道者人来说，区区几次处决又算得了什么？他们从摇篮到坟墓，心中都燃烧着对部族敌人的仇恨，这是他们唯一认知，是生命中不可动摇的准则。这份准则与效忠帝皇的使命一同被灌输给他们，两者在他们心中同样神圣。他们既不会违背对部族的誓言，也不会背弃泰拉最仁慈的黄金王座。”

 “该死。”雷扎伊尔回应，“之前为什么不告诉我这些？”

 “因为在今天之前，政委，要么无法理解，要么不愿倾听。”

 雷扎伊尔点头，这番话对军团的生存前景是沉重打击。即便能躲过泰伦虫族的魔爪，他们能躲过彼此的仇恨吗？雷扎伊尔没有把握，坦白说，他此刻面临着更严峻的问题。不过，他心中还有最后一个疑问，简单问题。

 “所以你到底告诉中校什么？是如何说服达卡尔上校改变主意的？”

 “我告诉他，要理解图雷纳格人信仰与执念：效忠尊父-至高统帅、对抗敌人、为信仰纯粹而战，以此换取奖赏。图雷纳格人或许不会公开宣称这颗星球是效忠帝皇奖赏，但他们内心深处渴望如此。我告诉中校，要将这片土地视为达卡尔上校的乐土，成为他不敢言说的顾虑的传声筒。我告诉中校，不要做他的敌人或对手，而要做他的顾问。”

 雷扎伊尔注意到泰瑞尔眼中的落寞：“就这样？”

 “不。”泰瑞尔懊恼地承认，“我告诉他，图雷纳格人殖民这颗星球的可能性微乎其微，既然如此，又何必为了一件注定不属于任何人东西争论不休。”

 “明智的建议，但促成双方和解后，你似乎并不开心。”

 泰瑞尔惆怅地叹了口气，露出一个勉强微笑：“我让两个部族达成了前所未有的和平，这是我们部族最睿智长者都未能做到的事，却没人见证我这小小的胜利。”

 “来。”雷扎伊尔在一棵巨大丛林树根上坐下，“我们一起庆祝你的胜利。”

 泰瑞尔在政委身旁坐下，惬意地舒了口气，哪怕只是片刻的放松也好。

 “为小小胜利干杯。”政委说。

 “愿这样的胜利源源不断。”

4

 图尔克穿过丛林，拨开巨大的叶片与发光的球茎，匆忙中险些被树根绊倒。他终于抵达一条小溪旁，溪水宽不过数米，切入岩石之中，岸边覆盖着肥沃的腐殖土。尼斯里赤裸着上身，瘦削的身躯让肋骨在黝黑的皮肤下清晰凸显，他正按照仪式清洗上半身，为即将到来的战斗做准备，背上布满了繁复的部族图腾疤痕。

 “有什么事不能通过通讯器说？”尼斯里将抹布浸入溪水中，擦拭着手臂问道。

 “我与托里亚上尉谈过了，他目前正在协助巴拉斯拉中士寻找地面通道。”

 “然后呢？”

 “托里亚上尉提出了一个计划，认为值得考虑。”

 “所以你亲自来为这个计划游说……恐怕不会喜欢，对吗？”

 “是的，长官，但恳请您听我把话说完。”

 尼斯里叹气，放下抹布，示意图尔克坐在他对面。图尔克跪下，耐心等待他的回应。

 “已知泰伦虫族正朝这些洞穴而来。”图尔克说，“或许它们从一开始的目标就是这里，我们不过是挡路石。”他停顿片刻，确认尼斯里在认真倾听，后者叹气示意他继续。

 “如果泰伦虫族进入洞穴，它们将获得大量生物质，足以组建军队入侵周边星系。我们绝不能让它们得逞。”

 “大概猜到你想说什么了，中校。”

 “请……听我说完。我只是在为一种可能性做准备。”

 “你是想炸毁洞穴！”

 “万不得已时，是的，长官。”

 “绝无可能！”尼斯里回应。

 “长官，我们已经走上了一条无法掌控的道路——”

 “我不会拿——”

 “请听我说完，长官。”图尔克鼓起勇气打断他，“之后决定权在您手中。无法掌控自己的命运，但凭借帝皇的力量，我们可以掌控泰伦虫族的结局。我并非主张不必要地摧毁洞穴，而是建议，若我们的防御失守，就不让这处纯净的天堂落入泰伦虫族之手。”

 “你是在要求我毁掉部族未来。”

 “不，长官，我是将这份希望的命运交到您手中。唯有您能决定这里的一切……是您，而非泰伦虫族。今天，哪种结局更可悲？是为拯救帝皇的子民而放弃天堂？还是让敌人玷污帝皇的恩赐？”

 尼斯里沉默不语，再次拿起抹布浸入溪中。他静静清洗双手和脸庞，显然在为这个决定而挣扎，眉头因沉重的抉择而紧锁。

 “我还没有同意你。”尼斯里最终放下抹布，“托里亚上尉的建议是什么？”

 “召回剩余的哨兵机甲，装满炸药和燃料桶，派往洞穴的薄弱点。托里亚上尉认为，在这些位置引爆哨兵机甲，能引发连锁反应。洞穴会因自身重量坍塌，相邻的洞穴也会随着岩石移位而陷落。至少，他是这么解释的。”

 “他找到这些薄弱点了吗？”

 “目前找到了两处，但他仍在继续探查。”

 尼斯里站起身，穿上衬衫和头巾，动作缓慢，仍在权衡此事。图尔克也随之站起，好奇尼斯里此刻的想法。两人都自认虔诚，既牵挂部族的需求，也忠诚于帝皇。他无法想象，一手握着部族未来的希望，一手握着摧毁它的权力，是种怎样的感受。他不认为这里是图雷纳格人的天堂，甚至觉得他们不配拥有，但他理解做出如此重要决定的艰难。他庆幸做决定的人不是自己，甚至不确定自己能否做出正确的选择。

 “伊班·萨利德中校。”尼斯里说，“告诉哨兵机甲侦察队，一旦泰伦虫族开始向我们移动，就立刻赶往洞穴。用炸药和燃料桶造成最大杀伤效果，但引爆权由我亲自掌控。”

 “请求允许将托里亚上尉从勘探任务中召回。”

 “批准，但此事暂时保密，没必要让士兵们觉得已经失去希望。”

“是，长官。”图尔克立正敬礼，随后返回指挥型奇美拉。
