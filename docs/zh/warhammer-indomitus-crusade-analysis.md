不屈远征为什么注定失败：公司的六个阶段

一、 公司的六个阶段：

1. 起步期（成立-0.5年）-我们是好兄弟，有事我帮你办

（1）业务状况：行业处于蓝海阶段。市场刚被发现。行业竞争少。挣钱容易。公司有稳定且唯一的合作商，目标是开拓本地市场，业务更新是一个月一次

（2）公司氛围：每一个员工都是珍宝。入职不设门槛，晋升只看能力，非大过错不罚款，非大过错不开除人

（3）工作状况：每天都能提前完成任务量，员工有充足的时间闲聊，换班自由。组长和员工几乎没区别

（4）团队构成：第一批初创团队全部在岗。每个小组设置一个正组长和至少一个副组长。底层员工有问题可以立刻反映，当天就能收到回复和改善通知。

2. 上升期（0.5年-1年）-我们是老同学，虽然熟悉但还是各论各的

（1）业务状况：行业处于蓝海阶段。已经有多家竞争对手。都在烧钱抢市场。公司有稳定且唯一的合作商，目标是开拓剩余的本地市场，优惠活动很多，业务更新是半个月一次。

（2）公司氛围：每一个员工都不能掉队。入职不设门槛，晋升只看能力，对违规者进行罚款，非大过错不开除人

（3）工作状况：任务量开始增多，但是大部分人都能在下班前完成。员工业余闲聊多，换班自由。组长开始脱离一线业务，去学习怎么做PPT、怎么开会包装自己

（4）团队构成：初创团队已经走了一半，因为性格不合或者缺乏更高的上升空间。一部分员工已经晋升了。剩下的员工还没晋升、但以后仍有机会。底层员工反映问题后几天内得到回复。

3. 全盛期（1年-1.5年）-我们是上下级，你必须听我的

（1）业务状况：行业处于红海阶段。市场已经饱和。行业竞争激烈。主要比拼服务质量。公司有稳定且唯一的合作商，目标是守住本地市场并拓展外地市场，优惠活动变多，业务更新是一周一次，这会的新业务开始有好有坏了，好业务是有利于员工挣钱的项目，坏业务就是罚款项目，总的来说好业务更多

（2）公司氛围：只有符合条件的员工才能留下。入职有门槛了，已经入职的人如果不能通过新的认证考核也要被辞退。晋升既看能力也看眼缘，只要工作粗心就会被罚款，重复犯错就会被开除

（3）工作状况：任务量继续增多，只有一半人能在下班时完成，另一半人要加班完成，员工的闲聊非常少了，换班自由。组长完全脱离一线业务，成为开会和写报告的工具人，专心负责写报表、向老板包装展示自己

（4）团队构成：初创团队只剩下了四分之一，离职原因是不接受管理风格的改变，也有能力足够，但因为长得丑或者学历低而被开除的。大部分领导都是老板高薪挖来的新面孔。也有一些老员工被外派去外地分店出差。每个小组设置一个正组长和一个副组长。底层员工反映问题后一周以后才能收到回复。

4.衰退期（1.5年-2年）-我们是路人，你的死活与我无关

（1）业务状况：挣钱像吃屎。行业处于红海阶段。公司在市场竞争中开始处于劣势。之前烧钱抢市场、开拓新业务大多以失败告终。外地市场已经丢了，现在的目标是守住剩余的本地市场。公司没钱了，开始降本增效，第一刀砍向材料费。产品质量下滑，进一步导致客户流失，优惠活动基本没有了，业务更新是一天一次，更新的好业务少，坏业务多

（2）公司氛围：完不成任务你就滚蛋吧。入职考核太严，新员工很少，而且离职率也很高，要么是业务太多了学不会，要么是任务太重受不了。只有老员工因为版本红利还能隐蔽摸鱼。但是老员工是走一个少一个。不再有晋升了。有些员工因为不合理的规定被罚款了但是不允许申诉。也有员工被公司当成替罪羊开除

（3）工作状况：任务量已经增多到所有人都至少要加班一小时才能完成了。员工之间非常冷漠，没有人关心别人。组长对一线业务已经彻底忘光了，开会纯粹是当老板的传声筒骂人，偶尔想拿底层员工找茬撒气，结果发现对业务还没老员工熟悉。

（4）团队构成：初创团队只剩下了几个人。所有的副组长（储备干部）都被开除了，之前出差去分店的员工也被召回，一些组长也主动离职了。底层员工被视为是愚蠢且无能的，因为他们没有高级职位，所以根本没人会重视他们的意见。

5. 断崖期（2年-2.5年）-我是督战队，你是动员兵，你完不成任务就挨枪子吧

（1）业务状况：行业处于死海阶段。公司已经基本失去了本地市场，并且也将要结束和过去合作商的稳定合作。此时降本增效的第二刀砍向了员工。上厕所时间长了要罚款，在工位整理久了也要罚款，总之只要被监控拍到没有干活都会罚款。并且薪资也降了小一半。大量员工扎堆离职。优惠活动完全停了。业务更新先是抽风一样的变成一天三次，之后又完全停了，不再更新任何业务。

（2）公司氛围：完不成任务你就去死吧。公司开除了HR和小秘书，不再招聘。罚款项目和红线项目已经多到可以列出好几页。

（3）工作状况：任务量已经多到所有人都必须从早上九点加班到晚上九点，员工已经快猝死了，组长的态度可以用“残暴”来形容。完不成任务量不许下班，但是任务量本身设计的就不合理，而且工资还降了，绩效明目张胆的降成原来的三分之一

（4）团队构成：初创团队全部离职。虽然走了很多领导，但是员工也走的差不多了，因此不会出现管不过来的情况。老员工全部离职。公司成为了老板的一言堂，因为所有的“忠臣”都走了，只剩下“佞臣”了

6. 崖底期（2.5年-？？？）-请输入文本

（1）业务状况：公司不再有稳定且唯一的合作商，转而跟多个不稳定的合作商合作。与其说这还是个公司，不如说这是个小型外包市场。虽然一个楼层的四个办公室都是“这家公司”的，但是分别处理的业务不一样，人员管理也是相互独立的。目的只是活到下个月。业务更新恢复成一天三次。

（2）公司氛围：办公室的空气非常的压抑沉重。待时间长了会想吐，多一秒都不想在那待着。入职前必须要有几年垂直工作经验。不存在真正的晋升，领导都是外地空降的。罚款项目和开除红线已经厚的可以打印一本书了。呼吸多一秒都会被开除，语气重一点都会被开除。而且上午“犯错”，下午就被开除了。并且这件事还会打印出来贴在墙上作为“警示案例”。

（3）工作状况：名义上是全职工作，实际上是兼职工作，经常上午上班、下午休假，发工资的时候少得可怜，因为公司导致的休假会扣除全勤奖。领导在开会时把员工骂的狗血淋头，毫不留情面，甚至逼迫员工自我羞辱

（4）团队构成：不可名状。什么样的人会选择在这种公司工作呢？也许是那些身上有纹身、患疾病、毫无退路、生活也没有希望的人吧。

二、六个阶段与战锤故事线的对照

起步期（大远征）、上升期（荷鲁斯之乱）、全盛期（野兽战争-泰伦战争）、衰退期（俄尔普斯战争-卡迪亚沦陷）、断崖期（大裂隙展开，原体复活-警戒星之战）、崖底期（欧克塔琉斯战争-第三次哈米吉多顿战争）

三、公司在发展中会遇到的“癌症”

1. 市场竞争越来越激烈，钱越来越难挣。工作越来越难。但是老板没有本事对外开拓市场，只能通过：换用劣质原料、强制员工加班、降低员工薪资、找茬罚款等办法来省钱。当这些事情积累到一个无法容忍的程度，就会发生员工的塌方式离职。整个团队一起走。

评价：作为底层员工，如果没有在入职的前半年进入领导班子，并且也不是老板高薪挖来的其他公司管理，之后就和晋升无缘了。要永远记住公司的利益和自己的利益是不一致的。如果公司已经明显的无法给自己带来合适的利益，那就果断离开。反正到哪都是底层，没有未来可言，只能抓住当下。

2. 管理层逐渐与底层脱节，蜕变成老板的传话筒。每天只知道开会和作报告，但是对于最重要的业务，则是既不懂、又懒得问。比起公司以后怎么发展、员工的利益是否保障，更关心的是自己当月的工作报表好不好看，能不能谋求晋升。哪怕是从底层一步步上去的领导，到最后也必然会瞧不起底层，甚至厌恶底层、欺压底层。

评价：大部分领导其实并没有能力，只是赶上了时代红利。比如有个领导就是因为长得阴柔被老板喜欢上，然后就晋升了。世界上的一切“职位”“称号”都是游戏里的荣誉皮肤而已。我们说白了都是农民，只不过有的人穿的衣服贵些，有的人穿的衣服便宜些。不要对别人有任何滤镜。尽量和直系领导搞好关系。如果不幸被领导记恨了，那就做好换工作的准备。直系领导想搞走一个员工太容易了。他天天啥也不做，就盯着你查，查出问题来就登表发给老板，然后就开除你。直系领导决定了你的工作能干多久。

3. 公司内部的工作流程越来越多，不干实事的关系户越来越多，但是底层员工却越来越少。所有的工作压力全都落在老实人身上。公司不停的新增业务知识、罚款事项，但是却几乎不删除旧的规矩。直到有一天新员工根本学不会，老员工也跑路了，这个摊子就烂了。

评价：所谓的降本增效，本意可能是开除那些蛀虫，但问题上那些蛀虫本身都是管理层，他们制定规则，实行规则，解释规则，那么不可能自己开除自己，最后所有的负担全都会落到底层员工身上，也就是说，谁是干实事的，谁就该死。多做多措，不做不错。找茬很容易，但是做事很难。不能当老实人，老实人确实该死。谁让他们是老实人呢。公司到了一定规模，注定要完蛋的。就像人老了就会死一样，公司老了也会死，只能换个新公司重新开始。

4. 薪资倒挂。新员工的薪资和待遇远远高于老员工。因为市场在变化，老板必须用更高的薪资才能招到人，但是对于老员工却不肯涨工资。老板就是赌老员工不走。

评价：对这帮虫豸有什么好说的。在私企上班最多一年就该跳槽了。想要涨工资只有跳槽一种办法。对这种垃圾不用谈忠诚，它们不配。如果对资本家盲目的忠诚，那就是工贼。

5. 公司最初的价值观是人人平等，但是之后逐渐变味。晋升不看业务能力，只看“媚上能力”。最后筛选出的就是一帮为了哄骗领导开心，没有道德底线的人。有责任心、有能力的人要么原地踏步忍受压榨，要么愤而离职。最后公司虽然还名义上存在，但已经变成“土匪窝”了。

评价：公司在末期，就像一具僵尸一样，它只知道吸血。既吸客户的血，也吸员工的血。这就是为什么要坚定的警惕权威，质疑权威，以及在必要的时候对抗权威。老板的值得追随，是因为他心存良善，高瞻远瞩，善待员工。如果他做不到，那么他就变了。我不会誓死捍卫我当奴隶的“权力”。“君之视臣如手足，则臣视君如腹心；君之视臣如犬马，则臣视君如国人；君之视臣如土芥，则臣视君如寇仇。”

四、不屈远征失败的必然性

基利曼接手的是一个濒临破产的公司。然而他所做的，只证明了他依旧是一个高领主，和高领主范迪尔没有任何区别。原铸战士的推广，是对老星际战士的卸磨杀驴，是又一次大规模的薪资倒挂。老星际战士想维护自身权益，那就只能投靠混沌了。

实际上战锤里的帝国，经历了这么多年的发展，早就不是当初的样子了。它只是一具僵尸，不停的从民众的身上吸血，然后制造痛苦与仇恨。但凡是看过官方小说的，都不会对帝国有任何滤镜。即使没有混沌，帝国也非常烂。我觉得一个人生下来是要追求真理的，而不是证明忠诚的。对老板的愚忠，就是对现实生活的逃避，最终导致悲惨的结局。

打工人的结局是跳槽，而不是升职。真正能升职的人是万中无一。至少我见到的是这样的。升职比拼的是很多业务之外的东西。它不比能力，比的是谁更被老板喜欢。
