# 第十三章

## 热烈欢迎

伴随着一阵微不可察的电流轻颤，考尔的穿梭艇（lander）穿过蓬托斯·阿凡尼斯（Pontus Avernes）的大气护盾，驶入澄澈的晴空。一片金色的草地向四面八方铺展开去，星罗棋布着一座座形制相同的阶梯金字塔，塔身爬满了繁茂的植被，反倒令它们各自显出独特的姿态。穿梭艇下降时的轰鸣惊起一群羽色柔和的鸟形生物，大型反刍动物从泥浆中笨拙地爬起，以慢镜头般的惊慌蹒跚着逃开。

穿梭艇着地了。艇身还未完全沉入起落架，舷梯便已打开，考尔大步迈出——他拿捏着时间，恰好让他的机械爪在舷梯齿状边缘触地的同一瞬间踏上地面。为展现外交姿态，考尔既未着甲，也未佩武器。他那全套装甲战备、护盾发生器、硕大的欧姆弥赛亚之斧（Omnissian axe）以及日冕爆炎枪（solar atomiser）[1]，都留在了探索者之王号上。那具硬连接在他下躯干输入阵列上的八足吉丁虫步行机（buprestis drone）又朝地面踏出几步，锯齿状的头部通过喙管吸入土壤样本。它察觉到了某种令它不快的东西，发出一声警告的低鸣。

“安静。”考尔轻声安抚道。他透过面部整流罩深深吸了一口气。空气清甜。这处景观构建得相当精巧，却又隐隐有些不对劲——大气中弥漫着一种沉甸甸的分量。他感到这地方强大的机魂因他的擅闯而深感冒犯。

日光灼目，从四面八方倾泻而下。每一颗太阳都为考尔投下一道影子，每一道都是苍白的幽灵，彼此争抢着地盘。从护盾上奔流而下的极光扰乱了传感器，又朝音阵通讯频道里推入一阵恼人的尖啸。他几乎能尝到能量的味道，空气因静电而刺得皮肤发麻。他伸出一根辅助肢体想更直接地采集土壤样本，一道火花便从他的长袍上跳下，溅入地面。

“奇妙的地方。”他说道。

货桥哐当作响，发出呻吟，四台卡斯特兰级（Kastelan-class）战斗自动机兵以该型号特有的沉缓从容走出了货舱。它们在大贤者四周散开，构成一个护卫方阵。西格玛·菲德利斯紧随其后，X99跟在它身后，手里忙着摆弄一包装满了数据晶片的挎包。奥斯文接着走下，两眼瞪得滚圆。

“这可真不得了。”他低声道。没有人理会他。

接着，邱弗迈动那双笨拙的腿走了出来。他正跟自己的袍子较着劲，仿佛穿衣于他是个全新的概念。走到舷梯底端时，他绊了一下，一头栽进草丛里。几朵会动的淡紫色花朵倏地缩了回去，他顿时僵住。

“不过是些花，不咬人的！快起来。”考尔伸出一根辅助肢体帮了朋友一把。他将自己的心情从沉思切换为开朗；邱弗需要被提振一下。“瞧，邱弗。蓬托斯·阿凡尼斯！群星之间的桥梁。多美的景色，嗯？”

“既然你这么说。”邱弗回道。他放眼望去，越过那片毫无变化的平原。远方地平线上的山脉是唯一的变奏。其余所有方向上，景致都止于一面面极光凝成的炫目墙壁。“地上全是泥。”他抬起脚又踩下去，像是在做实验。泥土噗吱作响。

“别看泥土，看这工程！”考尔说。“这可是巧夺天工的杰作。”

“这能维持下去吗？”邱弗指了指。在那些间距规整的金字塔之间，平原上散落着成堆的渣土，那是科技神甫们挖掘出来的废料。巨大的掘土机暂时沉默着，等待着啃噬这片未经开发的处女地。

“我竟不知你对考古学如此敏感，我亲爱的朋友。”

“死上八十七次，人总会变的。”邱弗说，“这太可怕了。我们难道就不怕毁掉自己正在追寻的东西吗？还有那些被我们毁掉的生命？你可曾问过自己这个问题？”

考尔将这番毁灭论调挥手拂开。“我相信他们不会把所有东西都糟蹋光的。这地方太大了。”

风景倒映在卡斯特兰机兵那镜面般的侦测面板上：它们始终沉默着，警惕地守望着。考尔仰望天空。大气包层十分稀薄，护盾的微光背后，清晰可见虚空的漆黑。在那片黑暗之中，阿弗内斯星系狂暴的太阳们正肆虐不止。

“让我想起了特里索利安（Trisolian）[2]，你不觉得吗，邱弗？”考尔说。“那场离子风暴可真要命。我几乎什么也听不见。音阵通讯断了，鸟卜仪（auspex）的探测范围被压缩到目视距离内。嗯，惹人厌的盲区。特里索利安也有点这个意思，但没那么强烈。那颗蓝太阳的嗓门太大了。”

“特里索利安是何时何地的事？”邱弗问道。

“你不记得了？”考尔失望地说。“真可惜，我还以为那些是你保存得最好的记忆片段呢。”

“不记得了。”

考尔叹了口气。声音从他肩头的音阵发射器中传出，十分刺耳。“就是在那个地方，发生了一系列事件，唉，最终导致了你的第一次死亡，也让我变成了如今这副模样。”考尔的语气转而带上了几分沉思。“其实，我自己也记不真切了。我失去记忆的次数太多了，记忆抹除、酷刑、巫术攻击。谁知道我都经历过什么？我之所以知道我们曾在特里索利安共度那段时光，全凭那些信息还保存在弗里迪希思维的全息记录里。所以依我看，既然连我自己都想不起来了，我也该给你留点余地。”

“可真够慷慨的。”邱弗冷冷地说。

“好尖刻的语气。你越来越像他了。”考尔评论道。

“你是个怪物。让我死了一遍又一遍。简直毫无人性。”

“没错。我确实是个怪物。但我也是你的朋友。终有一日，你会变成一个真正的孩子，援引那则古老的传说！等你的元素与命运的泛维度以太基底重新整合，等你灵魂的微粒重新校准，到那时，你将再度成为万机之神的造物，而非我的。”

“你是在谈论亚空间。”

“当然，当然。万机之神运行于物质界与非物质界之中。在这一点上，即便是我也无法超越祂的造诣。”考尔举目望天，用双手在心脏曾经所在的位置画了个圆圈。“不过我可以试试。”

“真是令人难以忍受。”邱弗说。

“可别泄露我的自负，今天我还得给一大群人留下深刻印象呢。我们往那边走。”他用一只钳状附肢戳了戳最近的那座金字塔。“这些大气场谐振器做工上乘！”考尔说。“我们眼前尽是奇迹。难怪我们的兄弟们在不停地挖啊挖。”

“为什么我们降落在这么远的地方？”邱弗抱怨道。说来奇怪，自打他初次死亡以来，他似乎还没有这么……牢骚满腹过。“不带军队来这儿，不是很危险吗？”

“我的军队正在赶来。”考尔头也不回地朝身后上方指了指。邱弗顺着他伸出的那只爪子望去，看到了一个正在接近护盾的光点。“是骑士。”

“他们眼下又不在，对不对？你现在很脆弱。”

“嘁，我这位非弗里迪希的同伴。我太重要了，他们杀不起，哪怕他们全都憎恨我。”他变得若有所思。“我倒不认为他们全都恨我。”他摇了摇头。“前进！”

伴随着活塞的叹息声，考尔那具经大幅改造的庞大身躯升了起来，向前走去。那些自动机兵比大贤者晚了不到一秒便迈开了步伐。它们以诡异的步调一致地向前行进，巨大的脚掌在松软的地面上噗吱作响。

“尽量别踩到我。”邱弗朝着离自己最近的那台机器咕哝道。

奥斯文走在队伍最后，敬畏地注视着一切，在他随身携带的一本皮质封面的厚本子上飞快地记着笔记。

此地的风景起初看起来浑然天成：一片松软的沼泽，长满了粗糙的植物、苔藓和危险的洼地，四处点缀着一片片开阔的水面。但走了一段时间后，一种规律便浮现出来——由堵塞的运河、残垣断壁和隆起的高地构成的网格，暗示着建筑物的存在。一条堤道从淤泥中升起。考尔拐了上去，其他人纷纷跟上。邱弗用鸟卜仪做了几次扫描。泥炭层之下是一条路面，保存得极为完好。

“你看这里像不像曾是一座花园？”考尔没等他回答。跟他对话是出了名的单向交流。“我看到了来自七个不同世界的植物。太迷人了。你瞧它们是如何形成了自己的生态系统？我猜想这里原本是经过精心规划的，这就能解释运河网络和植物的多样性了。我估计本来还有更多物种，但只有那些最适应生存的品种延续了下来。万机之神将如此详尽的细节与巧思倾注于祂的造物之中，供人类驾驭。生命是多么奇妙的东西！瞧瞧人类曾在这里取得了何等成就。一旦所有古人的秘密都落入我们手中，旧日的辉煌便会再度降临。”

“不，不会的。”邱弗阴沉地说。“修会早已堕落，沉溺于过去。我们变得目光狭隘。”

“没错，没错。”考尔说。“可我又不是他们，对吧？”

“是。”邱弗应道，这话听着不像认同，倒像是为了让谈话有来有回而勉强抛出的一个字。

随着他们走近金字塔，花园原有的布局愈发清晰起来，仿佛金字塔起到了阻挡大自然失序浪潮的作用。池塘的边缘变得更加笔直。古老的砖石从地面突兀地冒出。土壤变得更加坚实，古代耕种的痕迹也愈发显著。花圃、小径、雕像，几乎都淹没在簌簌作响的灯心草和莎草丛下。

蓬托斯·阿凡尼斯的地平线近在咫尺。它会欺骗人的眼睛。那座金字塔比从舰上望去时要更小、也更近。他们此刻看到，金字塔的四个角十分突出，每一面的中央都嵌着凹陷的阶梯通道。建筑的边缘处饰有巨大的，有人或许会称之为大胆的建筑雕饰，形如后足立起的蛇。考尔和邱弗那经过增强的眼睛看到了能量图谱，清晰得就像铁屑勾勒出磁铁周围的力线。在天空中，这些能量投射与其他金字塔的投射交汇、重叠、相互增强，由此构成了保护此地的力场。再靠近些，他们便能感到自己的身体也浸润在这些能量投射之中了。它搅动着他们液压系统中的流体，拖曳着他们的人造心脏，躁动着他们四肢骨骼中的合金。

“有够刺激。”考尔咂了咂他皮革般的嘴唇。“你知道吗，地面二十英尺以下，我就完全收不到任何读数了。一律如此。任谁都会好奇底下到底藏着什么。真令人兴奋，不是吗？”

这群贤者来到了一座环绕金字塔的齐整水渠边。鱼群在他们投下的影子掠过水面时倏地散开。他们转到了距离登陆点最远的那个面，面前豁然呈现出一片巨大的石板铺就的空场，面积足可充作降落区，此刻也正被三艘机械教的舰船当作这个用途。船体分别涂着泰格鲁斯（Tigrus）、阿卡特兰（Accatran）和梅塔利卡（Metallica）的涂装，正蒸腾着散发而出的热量。一队队身穿对应制服的护教军（Skitarii）朝考尔走来。信息空间中闪过了问询与危险信号标识。考尔的小队停下了脚步。机兵们举起武装的拳头，发出愁闷的哔哔声。

“贝利撒留，他们冲我们来了。”邱弗不安地说。

“他们当然是冲我们来的。来迎接我们是他们的职责所在。”考尔低头看着Qvo-89，微笑了。“我喜欢你叫我贝利撒留。”

护教军举起了他们的枪。辐射耀斑在邱弗的内部处理器中被标注出来。当他们经过那些舰船时，卡塔弗隆（Kataphron）重型战斗机仆从阿卡特兰登陆艇的货桥上轰然驶下。

“他们看起来可不太乐意见到我们。”邱弗说。

考尔快步向前挪去，直到他完全站到了石板空场上，然后转过身来面对自己的朋友。

“你认为我们身处险境。”

“我是这么认为的。”

“而我们究竟为何来此，你大概正这么琢磨着。这是个很好的问题，我现在就来回答。”

“我什么都没问，贝利撒留。”

“唔，反正我都要回答。你或许以为我来此地，是为了显示我的自由身和对火星的不屈从——按我对你里里外外的了解，邱弗，你肯定正这么想，因为你是个聪明的家伙。”

“我没在想这个。”邱弗说，“我在想我还没准备好再死一次。”

考尔继续他的演讲。

“我喜欢让火星知道我在做什么。主教会议以压倒性的多数批准了授予我首席传导者称号。尽管乌德·乌迪亚·拉斯金（Oud Oudia Raskian），那个身形如山岳般庞大的混蛋讨厌我的机械内核，但在母星我仍有大量支持者。我或许在某个时候需要仰仗他们。不过，要是我时时刻刻都向他们通报我的位置和行动，那反而会促使他们中的一些人，甚至更糟，一大群人承诺前来协助我。那将会导致火星上的内部分裂，乃至铸造世界之间潜在的内战。我更希望他们安心把军队派给基里曼，因为要是有一场我自己的愚蠢远征军跟在屁股后面，那看起来就像我在图谋攫取某种权力，而这绝不是我想要的，却又恰恰是拉斯金所恐惧的。他担心我已叛变。我如今现身此地，站在这块被火星声索主权的平台上，就是要让他们知道我在干什么，又不至于激起那种愚蠢的反应。这是我宣示我手上有牌可打的方式。你瞧，他们没法拒绝。来到这里，本身就是个一石多鸟的办法。别担心。没有任何危险。”

卡塔弗隆机仆们越过了护教军，它们被屠戮过的大脑可没有步兵那种谨慎。沉重的履带碾碎了古老的石板，它们在猛地刹停中将武器齐齐对准了科技神甫们。卡斯特兰机兵同样以武器回敬。磷光爆能枪（phosphor blasters）和重型伐木枪（heavy stubbers）瞄准了重型等离子炮。

“我们抱着和平而来！”邱弗喊道。奥斯文半躲在他身后，但仍继续飞快地写着。

“X99，让你的自动机兵退后！”考尔命令道。机兵们的手臂垂落到身体两侧，立正站好。考尔朝正在接近的护教军们庄严地挥了挥手。但这并没能阻止机仆们长管炮的线圈因积聚电荷而发出明亮的辉光。“三个铸造世界的三支部队协同一致。”考尔说，“多么壮观的景象。让你们为自己是火星人而自豪吧。”

按照机械修会多个铸造世界协同行动时的惯例，护教军们迅速选出了其中一人来领头。很难想象泰拉（Terran）的部队能如此之快地达成一致。那位来自阿卡特兰的护教军首席（Accatran Alpha）被指定为总领队，他走上前来，指令发射器发出悦耳的哔哔声。他将武器甩到肩上，单膝跪地。

“向您致敬，统御大贤者贝利撒留·考尔，伟大的智者，欧姆弥赛亚的首席传导者。我们各自世界的领主们正在这造物内部等候着您，并谦卑地请求您移步赏光。”

其余的人也纷纷跪下。机仆们垂下了武器，也垂下了头。

考尔将他众多的手臂高高扬起。

“不必为了我而卑躬屈膝！请起，请起！我们是钢铁中的兄弟。让我们像朋友一般相处。”他说这话时极为谦逊，却朝邱弗咧嘴笑了笑，挤了挤眼。

邱弗无需凭借八十余条性命积累的经验便已知道，这将是无比难熬的一天。

“来吧，诸位。”考尔对他的随行队伍说道。“我们进去吧！”
