# **源起**

纵使帝国关于荷鲁斯之乱的历史记载汗牛充栋，但是其中关于“苦涩战争”（Bitter war）的记载却寥寥无几（起码再明面上是是如此）。但是这一战役本身又是荷鲁斯之乱中，影响整个太平星域的重大战役，其影响之深远，以至于有说法其影响甚至延续至万年之后。而造成这一重大战役记录稀少的原因有很多，但是主要还是因为提及这段历史，就意味着要记述在这场战争中各方释放出的噩梦般的恐怖力量。在这场战争中，怀言者那堕落的巫术与铁手那些恐怖的旧夜时代的科技互相斗法，整个整个的星系被化为废墟，甚至遭遇更加恐怖的下场。诸如阿德拉米大清洗、纳拉西玛解体和萨尔科萨大屠杀之类的事件和相关资料鲜有人能或者敢于提及。而这场恐怖且在荷鲁斯叛乱结束时，已蔓延并影响了整个太平星域北部大部分地区，但又记述稀少战役的起因，则是由铁手军团对怀言者母星科尔斯基发起的复仇圣战。这些破碎美杜莎之子们为了复仇，将会无所不用其极。

美杜莎，钢铁之手母星，及其轨道上技术遗产：荒讯星环TELSTARAX

自伊斯塔万5之上惨烈的背叛发生，第十军团的原体费鲁斯身陨之后，钢铁之手便几乎四分五裂。作为曾经骄傲的第十军团，在伊斯塔万5之后，纷纷因为观点不同，而选择了不同的道路：如以梅杜森为代表的破碎军团派决定原地在叛军敌后斗争，也有各种脱离大部队的独狼式的复仇。而也有一批曾经不受原体待见的铁父选择了回到铁手的母星美杜莎，决定先去重建部队从长计议。但选择的返回美杜莎，不代表他们的复仇心有任何减少，甚至可能正相反。美杜莎派的铁手在伊五后，冷酷的采用了各种技术方式速成星际战士新兵以试图快速重建，除了铁手擅长的各种机械改造替代原有器官外，各种禁忌科技也被毫无顾忌的被全面投入，再加上他们从密米尔宝库当中拿出来的各种的旧夜恐怖技术产物，这使得美杜莎派在备战后的兵力膨胀速度相当迅速。而美杜莎派铁手在备战复仇的目标，便是伊五之上的其中一个叛徒的母星，也是太平星域当中叛军的核心之一，怀言者的母星：科尔斯基。而作为进攻科尔斯基路线上重要的前哨和工业基地，铸造世界米尔汉德，便成铁手势在必得的目标。由此开始的米尔汉德突袭，便成为了苦涩战争开启的代表性战役。

钢铁之手分别有两只部队投入了贝塔加尔蒙战役，但是两者互相不隶属。铁手在伊五后的分裂是实打实的。不过，这并不妨碍他们一起打叛徒和复仇，也不影响他们战斗力，更不影响他们利用各种技术遗产撬动战局

从时间上而言，作为苦涩战争的早期阶段战役，米尔汉德突袭战虽然是美杜莎派铁手发动达战役，但是巧合的是，其与位于太阳星域另一边的贝塔-加蒙二号星上的首战几乎同时发生，使得美杜莎派的铁手基本较少参与其它相关战役，使其记述也较少。（也是因为这个原因，贝塔加尔蒙战役中，美杜莎派并没有大量参与，但是他们还是回应了多恩的命令，派出一支小规模精锐部队，护送着13枚超巨型生物吞噬弹头参战）。而此时的米尔汉德虽然作为挡在铁手进攻科尔斯基本体的重要节点之一，但尚未触及紧要关头。故而双方还尚未大规模使用那些这苦涩战争高峰时期所使用的各种禁忌技术和亵渎巫术，但这里却出现了即将降临的恐怖的先兆：无论是土卫九自身的技术，还是当土卫九的技艺被邪崇技术所腐蚀后的成果，其展现的战力和邪恶将被双方所铭记。这都将推动使得破碎的梅杜莎之子，和科尔斯基的邪徒一起在后续的战争中，不断释放出越发恐怖的存在。而从这一点上而言，作为观察后续恐怖战争的起点之一，米尔汉德突袭战将是一个不错样本，来展现这场战争是如何逐渐发展并产生后续的恐怖与疯狂的……

# **“被捐献者”**

时至M31的271010年，随着美杜莎派的钢铁之手发起了针对怀言者的战役打响后，这些第十军团复仇者们开始了一系列势不可挡的攻势。他们以极快的速度，迅速拿下了怀言者母星科尔基斯星系辖区外围领域的十几个星系。而这些铁手进攻势头没有丝毫减弱，其进攻烈度和强度是如此之高，以至于怀言者军团不得不持续的将无数狂热邪教兵，以及整支整支的自杀船队填入铁手进攻路径，以试图延缓哪怕一点点钢铁之手的碾压式推进。而随着战局的持续吃紧，越发难以维持的怀言者不得不选择收缩防御。于是在紧邻科尔基斯的一系列星系中，怀言者开始执行一系列大规模撤退行动。通过从周边行星搬运所有物资与部队到科尔斯基，以在实现在其疆域的核心地带重新构筑壁垒。而作为邻居科尔斯基的铸造世界米尔汉德（Forge world Milhand）正是这样一个“被捐献”星球。

米尔汉德已是一个半死的世界，其地表星罗棋布的耸立着高大的铸造神殿，以及与曾为类似存在的庞大废墟。而其间绵延起伏的平原上，遍布着污秽浓重的泥浆沼泽，并且不断被征服大军的践踏与被奴役人口的大规模流动所搅动。而作为一个相对不那么出名的铸造世界，米尔汉德自荷鲁斯之乱爆发以来，可谓是灾难连连。早在荷鲁斯之乱刚爆发没多久，其小型泰坦军团——净炎军团 (LEGIO ABLUTUM) 便彻底与其母星决裂，选择了黑盾之路。从而使得其本身就没多少防卫力量的米尔汉德的防卫力量越发空虚。紧接着，作为就在科尔斯基边上的铸造世界，几乎是理所应当的很快就被在怀言者盯上，使得他们很快就遭到了来自怀言者与蚀心军团（LEGIO MORDAXIS）的惩罚性打击。虽然他们的很快屈服，但是其自身的机神禁卫军的军备和工事，在那场惨烈的惩罚性打击后，大部分仍未恢复，这就使得的米尔汉德注定比大多数铸造世界更易攻克。

更加雪上加霜的是，随着铁手开始发动他们针对怀言者的攻势，怀言者对米尔汉德的压榨达到了足以令米尔汉德的技术议会恐怖的地步，因为他们无疑成为了怀言者的“被捐献”星球。几乎在短短一个月里，米尔汉德的铸造厂之前为第十七军团生产的巨量战争物资相当一部分，便已被敲骨吸髓般的提取。然而，即便如此疯狂运作仍然赶不上钢铁之手战士们复仇的攻势。仅数周后，当首批钢铁之手的舰船突破亚空间，开始逐渐出现在星系内时，在米尔汉德上仍有数量庞大的弹药与装备堆积在米尔汉德地表各处集结点，等待运输。尽管如此，作为本地统领，战斗母舰释经号（Exegesis）的指挥官，兼米尔汉德掠夺行动监督者的科里法斯·伊沙安·图尔（Coryphaus Yshaan Tur）仍押注其能够组织起足够的抵抗能力，他试图在此抵挡铁手的攻势，即便只是短暂拖延。

# **降临**

随着钢铁之手舰队抵达米尔汉德星系的消息传到，怀言者和此地的机械教不得不进一步加快速度并进入战争状态。在米尔汉德轨道上，叛军的补给驳船无视风险，强行降低至危险的低轨道，以期望加速物资装载进程，这些舰船的上层建筑在增强的重力下嘎吱作响，随时有出事的风险。而驻守米尔汉德的怀言舰队则拔锚前去迎击铁手，而释经号作为战斗母舰，则加入了补给驳船的行列。释经号在危险的低轨道，一股脑的将机库中的登陆艇与炮艇尽数投向米尔汉德下方的污染云层。而其他所有叛军的舰船，无论是米尔汉德自身的，还是怀言者的舰船，则逐渐组成防御方阵，将起火炮与传感器阵列对准了深空轨道，扫视着米尔汉德轨道之外的深空。（可能是因为他们直到米尔汉德的所谓外轨道和外行星域防御根本不可能起效，只能放弃）而随着怀言者们凝视的远方的虚空中，他们看到了前来复仇的钢铁之手舰队，以及令他们呼吸停止的东西。

纪仇号想象图（ai创作）

来袭的铁手舰队本身并不足为奇，但是他们所簇拥的东西却几乎超出了认知。在钢铁之手舰队中心，被铁手舰队层层环绕拥簇着的，是一艘尺寸堪称夸张的庞然巨构，其名曰纪仇号（Memorius）。这一存在的本体，据传是源自美杜莎那宏伟的，破碎的巨型轨道环“荒讯星环（TELSTARAX）”其上的一枚碎片。而如今，其无疑被美杜莎派的铁手进行了高度的改造，其不仅被赋予了动力，并且据传其还拥有着足以毁灭星球的火力，而其存在本身，便无疑将矛头指向了怀言者迄今无敌的君王舰，甚至可能更强。不过纪仇号（Memorius）虽然几乎无可匹敌，但是在亚空间之外的常规行动速度上十分迟缓，而这为怀言者们提供了一丝希望。而随着铁手舰队的前卫舰疾驰而来，准备试探火力时。怀言者和其它叛军清楚的意识到：无论他们如何努力，一旦纪仇号抵达，米尔汉德必将被攻陷。
