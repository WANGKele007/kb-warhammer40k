忠嗣学院是帝国国教开设的军事院校，由一名泰拉元老院成员负责管理，其校区遍布整个帝国，与国教联系紧密的星球上尤其多见。这些军校负责收容抚养帝国的孤儿，并把他们培养成出类拔萃的战士。

 校园环境十分“优美”

# **生源**

理论上，忠嗣学院的生源囊括帝国的所有阶层，从官宦家族的少爷到前线大头兵的遗孤都在其中，但在41千年的晦暗银河中，公平只是一种奢望。永无休止的战争每天都在量产烈士遗孤，数量多到取之不尽用之不竭，而忠嗣学院只会收容其中的“佼佼者”——通常是家境的佼佼者。

# **“校园生活”**

为了把不谙世事的孩子培养成狂热的帝国士兵，忠嗣学院的“学习生活”并不轻松。许多忠嗣学院会故意建在偏远地区，这既有安全考量，也是为了防止学生逃跑：不是所有10岁的孩子都能熟练使用自动枪。

忠嗣学院的惩罚方式之一：教锤

在忠嗣学院内，学生会受到24小时的严密监视，走廊里有伺服颅骨巡逻，训练住持也经常搞突击检查，确保学生心无旁骛地专注于课业。同时，为了学生的身体健康，各种严苛的体能训练也不会落下。成绩不好的学生会受到极其严酷的惩戒，运气不好的甚至会成为射击课的训练靶。

忠嗣学院的训练在其他场合通常被称为酷刑。学生们需要穿着沉重的盔甲进行体能训练，通常在爬墙或过铁丝网时就累到精疲力尽，身体受伤和精神崩溃也并不罕见；但看到训练住持戴手套的手撸起袖子，再看看他的长柄教锤，继续努力才是明智之举。

作为帝国的军事院校，实弹演习也是必不可少的。学生们会被带到荒野之中，没有食物、没有指导，只拿少量武器装备，在野外环境中活过数个标准泰拉日。这种演习的地点通常是学院周围的旷野或者所在行星的卫星之上，因为这些地方有着生生不息的野生动物作为食物和训练项目。

在黑暗的41千年，野生动物很可能是防弹的，甚至做成的罐头都能杀人

祈祷、禁食和苦修是国教的三利器，也是忠嗣学院的基本教学法。忠嗣学院新生的第一节课，便是明白神皇不需要软弱的人，痛苦只是未经训练的头脑的幻觉。这之后，他们便从识字和国教教条开始学习，然后是历史、政治和帝国圣人的启示，再到各种领导技能。

# **训练住持**

忠嗣学院的生活、纪律等工作基本都由训练住持负责，只有在少数课程的教学工作中会邀请战斗修女进行协助。训练住持这一职务通常由历战老兵担任。从身份上说，这些人是帝国国教的牧师，但这些老兵油子无疑没有牧师的矜持和文雅，他们的职责是将对皇帝的敬畏植入青少年的心中。为了履行这一职责，他们可谓无所不用其极：从做俯卧撑、背诵国教经文这样的轻罚到教锤砸头、剥夺睡眠等重罚，训练住持几乎掌握着学生的生杀大权。有的人即便在毕业几个世纪之后，有了决定数百万人生死的权力，也没能摆脱训练住持带来的童年阴影。

其实正经牧师也够吓人的

当然，训练住持不只是虐待学生的暴力狂。他们既以严厉的方式训练自己的学生，也会用自己坚强的意志和实际行动为学生做榜样，他们丰富的实战经验和见识也会让学生受益良多。有些善待学生的训练住持与学生建立了终身的情谊，这也可能在多年后成为重要的机遇：忠嗣学院的毕业生很可能有朝一日会身居高位。事实上，很多审判官都会聘请他们在忠嗣学院时的导师作为学徒，而众所周知，学徒是新晋审判官的主要候选人。

# **服从性测试**

作为人类帝国的栋梁之才，忠嗣学院学生的“毕业考”，服从性测试，也极具帝国的风格。测试的形式有许多，但目的都是选出逆境中最能服从命令的人，并测试他们如何对待命令。没能通过测试的人通常会留在忠嗣学院干苦力，直到他们最终被允许加入星界军。

每个忠嗣学院的毕业生都会帝国担任一项具体的职务，而找到这项职务、培训职务所需的技能便是忠嗣学院的工作。在严苛的考验和挑战中，训练住持将不断地评估，谁能成为一个优秀的风暴忠嗣，谁能成为一个负责的政委，或者谁更适合在进入泰拉议会。也有一些教师使用更深奥的选择方法，比如有的导师会用占卜来指导或决定学员的道路。因此，大部分忠嗣学院的学员在毕业之前就已经明确了自己的去向。

内部单位，毕业包分配

对于将来的风暴忠嗣，服从性测试通常是幻觉室进行实弹演习。在无尽的迷宫中，考生会不断接触到奇怪的景象和错误的指令，而他们必须辨别出正确的命令并毫不犹豫地执行，不管这些命令是多么奇怪。也有定时的物理测试，比如攀登学院的高墙，同时不断地吟唱特殊的忠嗣学院信条。如果考生念经的节奏与附近的伺服颅骨不同步，便要面对无情的炮火。

对于将来的政委，毕业考通常采取更深奥的形式。在不知道这是一场考试的情况下，考生可能会被命令找到他最亲密的同学之一——一名多年来与他共同经历磨难的朋友——并射杀对方。如此冷酷无情的指令有两个目的，一是证明了考生绝对服从上级的命令，二是确保在激烈的战斗中，考生可以毫不犹豫地杀死顽固的军官。这一测试的落榜考生通常会成为下一个考生的测试项目，或者被当成风暴忠嗣测试中的猎物。

# **出路**

毕业生通常国教或泰拉议会，或者进入星界军或帝国海军，许多女毕业生都会加入战斗修女会。表现出灵能天赋的学生通常会被移交给星语庭，或者成为审判庭麾下的灵能者、接受进一步训练。

冈特政委，忠嗣学院毕业生的优秀代表

在帝国，忠嗣学院是个不错的起点。进入帝国军队的毕业生可以担任很多要职，如帝国政委；或者进入风暴忠嗣军，一支只收忠嗣学院毕业生的精锐部队；少数佼佼者甚至能在审判庭和内政部就职。
