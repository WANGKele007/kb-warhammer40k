# **911.M41 卡'班哈之陨**

预言者们预测卡'班哈，恐虐最强大的嗜血狂魔，即将重返凡世。因为深知卡'班哈是危险的敌手，并且与圣血天使结下深仇，大导师议会便将此消息告知了指挥官但丁，并提议联合出击。于是在卡'班哈重生后仅数小时后，一支由圣血天使与灰骑士组成的联合打击部队便攻入了他在恶魔世界卡拉加扎尔的要塞。一场激战过后，卡'班哈被放逐了，他的心脏被修士连长索洛尔的削尖股骨刺穿——这是一件奇特的武器，却承载着重大的宿命。在M34时期，索洛尔是首位击败卡'班哈的灰骑士，尽管如今已逝去许久，他的遗骨依然能够克制这头大魔。随着卡'班哈的陨落，恶魔大军覆灭了，那座要塞也倾覆倒塌，而卡拉加扎尔本身则遭受了灭绝令。战役结束时，幸存的圣血天使被抹除了记忆——这是但丁在任务开始时便与灰骑士达成的代价。
