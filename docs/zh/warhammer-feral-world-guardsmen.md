眾所周知星界軍對人力的需求無窮無盡，所謂物資不問來路，士兵不問出處，只要能產出資源的星球都得納稅，從科技風滿滿的巢都一直到玩真人版部落衝突的蠻荒世界 ( Feral World ) 都得繳納什一稅，那麼問題來了，那些還拿著骨頭當武器的原始人被強制徵招後組成軍團是怎樣的情景？

 這點2008出版的RPG規則書【Dark Heresy Core Rulebook】有相關說明，這邊貼原文截譯：

 蠻荒世界是生存極其艱難的地方，無論環境氣候人類都退回到了更原始的生存狀態，這些星球的科技基礎通常處於黑火藥時代之前，在最落後的情況下甚至是石器時代，居民往往已墮入野蠻狀態，他們可能是很久以前就已毀滅的古老殖民地的殘餘人員，也許是來自某個廢棄哨所、隨後變得野蠻的研究人員和帝國衛兵；又或者是被迫在可怕的苦難中生存了數代人的落難太空旅人的後裔，無論情況如何，蠻荒世界的人很可能是原始的獵頭族、狩獵野獸的遊牧民、手持戰斧的蠻族或其他類似的人。

 蠻荒世界由行星總督控制，在多數情況下這位統治者在軌道上管理他的星球，僅在為了清除靈能天賦者和變異者時才降落到地表，在蠻荒世界上宗教偏差極為普遍，特別是在戰士教派中，因此保持警惕是必要的，然而負責蠻荒世界的總督通常受到嚴密監視，經常被懷疑「土著化」，在一些蠻荒世界部落中人們執著於對帝皇以外的信仰，這些信仰通常會被國教修改，或者乾脆被殘暴地鎮壓，帝國當局不斷獵捕異端教派，而蠻荒世界則是此類異端分子的避風港。

 蠻荒世界的居民是強壯、堅毅的人民，他們鄙視軟弱，且經常聚集在一起組成部落戰士氏族，蠻荒世界者的生存主義心態和強健體魄，使這些星球成為帝國防衛軍甚至星際戰士的優質徵兵場，有時將蠻荒世界者從他們熟悉的環境中移走對他們來說會是一次令人不安的經歷，他們原始的大腦將無法應對諸如太空旅行等基本概念的知識。

 在這些情況下瘋狂隨之而來，可憐的蠻荒世界者必須被監禁或被解除痛苦，即使是那些進入更廣闊帝國的人也保留了許多部落特徵和傳統，有時這可能非常有用——卡塔昌叢林戰士或芬里斯的太空野狼就是典型的例子——但有時這些傳統可能表現為奇怪的癖好或社交障礙，例如堅持在戰鬥中佩戴死去的戰友骨骸、每當靈能者使用力量時就吐唾沫或在任務前塗抹戰漆。

 蠻荒世界的星界軍通常是由特定氏族的長老作為什一稅徵召給帝國防衛軍的部落戰士，他們有時會在巨大的操練營或船艙中接受集體訓練，而其他人則僅僅是被演示了如何使用激光槍，隨後就被寄予厚望自行應付，此外還有一些人是由部落成員指導，使用死記硬背的祭儀和宗教儀式進行戰鬥。

 總之對帝國來說，是個人能開槍就行，真的學不會開槍帝國也有很多武器能用，挑個順手的上場，蠻騎兵 ( Rough Rider ) 就是最好的例子，你會騎馬拿長矛那帝國就繼續讓你騎馬拿長矛，歐格林都能上戰場了原始人有啥不行，在古早三版軍書裡還真的有這麼個從蠻荒世界徵兵組成的軍團：卡納克顱骨掠奪者 ( Kanak Skull Takers )，許多卡納克部落無論體型或性情，都更接近食人魔而非普通人類。

 他們嗜殺成性的天賦很快就被帝國衛隊所接納，而帝國衛隊對他們野蠻的戰術也表現出了相當大的容忍度。如同許多野蠻的軍團一樣，在帝國衛隊服役的目的是為了讓野蠻的卡納克人學習帝國之道，以便他們日後返回故鄉時，能夠對當地土著居民產生文明教化的影響，他們不使用普通的雷射槍而是攜帶各種近戰武器和雷射手槍。有些士兵甚至同時裝備兩種原始武器。他們很少使用重型武器但尤其偏愛火焰噴射器。

 雖然是三版的小軍團，但一直到前陣子的不屈遠征他們都還有登場，可惜的是他們的母星卡納克在帝國暗面那邊，在上頭太空野狼和帝國對上了當地的死靈族王朝和入侵的懷言者，目前暫時擊退敵人 :P

 至此我們能大概看出端倪，這些原始人會被整個部落打包帶走，然後在運輸過程中學習怎麼使用雷射槍，不需要知道原理反正能開槍就好，不能開槍就發近戰武器或部落擅長用的東西，總之能夠攻擊敵人就行，然後丟到戰場上自身自滅。

 另外一本短篇小說【Savage】裡面有提到類似的事情，這本出現的人物應該是某個長篇小說系列的短篇但我不知道出自哪裡，不過裡頭關於蠻荒世界人民被強制徵招後的情節更寫實也更殘酷一點：

--

 目前第七連看起來並不起眼。

 連隊乘員因為酷熱拋下了他們那房屋般巨大的座駕，他們的武器被保護性的防水布覆蓋著、艙門緊閉，引擎面板已被拆除以防止熱損傷，並用網罩罩住以防歐姆杜曼種類繁多的昆蟲，登車梯和扶手成了遮陽篷的固定點，為地面上無所事事的人們提供陰涼。

 坦克停放區看起來有些凌亂，完全是根據不平整的地形佈置的，超重型坦克儘可能地停放在水平面上以免在休整時給懸掛系統造成壓力，如果當他還是在博索瓦當獵人、對真實世界一無所知時看到這些坦克他會覺得它們很奇怪但無害，那時他對科技那種純粹的破壞力毫無概念。

 他笑了，他記得第一次見到坦克作戰的情景：引擎轟鳴，大砲齊放，雷射砲射出如長矛般筆直的閃電光束，高爾夫絕非膽小鬼，但在那一秒他被嚇壞了，同時他也感到著迷與興奮。

 現在坦克如此安靜，連一頭牛都嚇不倒，他為它們感到遺憾。

 坦克後方是一疊疊的軍需部集裝箱，再往後則是維修車輛，營地的那個部分都很雜亂——不只一位特遣部隊軍官對此發表過評論，每當這件事被提起來，受人尊敬的班尼克上尉就不得不叫出他的技術神甫來解釋這種佈置的必要性，如果他們在那裡待得更久一點，就會調來設備重新塑造地面，星界軍對凌亂的容忍程度是有限的。

 「就這樣吧，」高爾夫拍著「科特因之傲」說道，帕拉岡人、阿特拉西亞人以及其他人——這些來自星空的陌生人——都說他們的機器有自己的靈魂。

 高爾夫不太相信這套，他曾經膜拜過一塊形狀古怪的石頭，所以覺得自己擁有一種獨特的視角，當他原本的世界觀被現實炸得粉碎還附帶遭到一頓嘲笑後，這讓其他所有人所珍視的信仰顯得同樣不可信。

 儘管如此，他離開時還是走得很輕，以免驚醒它們沉睡的靈魂，以防萬一。

 在維修場內人們在清晨的涼爽中工作，機床在切入金屬板時發出哀鳴，那是他被徵召入伍時另一件嚇壞他的事，任何種類的機器都讓他充滿恐懼，來接他的太空船、部隊運輸車、船上的洗漱設施——甚至是門。

 其他一些博索瓦人則永遠無法從這種文化衝擊中恢復過來，幾個被恐怖擊垮而喪失行動能力的人被當作典型處決了，但這些槍決並未能讓剩下的受害者從僵死狀態中清醒過來，軍需部從不浪費，他們為那些無法適應的博索瓦人找到了其他用途，高爾夫時不時仍能看見他們那被改造為半機械人的殘軀在各處麻木地蹣跚而行。
