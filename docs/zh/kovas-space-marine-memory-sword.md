没有人知道一个普通的星际战士能做什么。

科瓦斯知道。

他走向那道裂痕。

每一步都像踩在刀尖上。不是肉体上的刀尖——是灵魂上的。每走一步，混沌的低语就涌入他的脑子。恐虐给他看无尽的杀戮，奸奇给他看永恒的迷惘，纳垢给他看腐烂的安宁，色孽给他看堕落的美妙。

他走着。

他想着那些灯。那间贫民窟的窗。那个中尉的眼睛。那个小女孩的野花。晨星世界的田野。那些他教过的年轻人。那些他挡过的世界。那些他不知道名字的人。

低语停了。

不是它们不想说了——是它们发现，这个人的脑子里，没有它们的位置。

他的脑子里只有灯。

他走到裂痕正下方，举起盾。

那一瞬间，整个战场都看见了。

一个不起眼的黑色身影，站在混沌的源头下面，举着一面破旧不堪的盾。那盾上嵌着二十三块弹片，刻着三百年的伤疤，装着一束干枯的花。

混沌的洪流砸在那面盾上。

一次。两次。三次。一百次。一千次。一万次。

科瓦斯站着。

他的骨骼在碎裂，他的肌肉在燃烧，他的基因种子在尖叫，他的灵魂在颤抖。但他站着。

他想起禁卫长的话：你要站在那些你站在他们前面的人面前。

他想起帝皇的话：谢谢你。

他想起那个小女孩的话：你看起来很累。

他很累。

但他站着。

第七天，那面盾碎了。

不是裂开，是碎成千万片。那些嵌着弹片的金属，那些刻着伤疤的残骸，那些装着三百年记忆的碎片，在混沌的洪流中四散飞溅。

科瓦斯站在那里，手里握着最后一块碎片——那块装着干枯花朵的碎片。

他低头看了一眼那束花。

三百多年了，它还保持着那个小女孩递给他的样子。

他笑了。

那笑容很轻，很浅，像三百万盏灯里最远的那一盏。

然后他松开了手。

盾牌碎裂的那一刻，整个战场静止了一秒。

不是时间静止，是某种更深层的东西。

那些飞溅的碎片没有落地。它们悬在空中，每一片都在发光。那光不是金属的光，不是能量的光，是另一种东西——是所有他救过的人的眼睛，是所有他保护过的灯，是所有他来不及救却永远记得的名字。

碎片开始旋转。

它们不是朝外飞，是朝内聚——朝科瓦斯聚。

他站在那里，双手空空，没有盾，没有枪，没有动力甲——那甲已经在七天的轰击下彻底粉碎。他赤手空拳地站着，像一个刚刚出生的婴儿，像一个即将死去的老兵。

碎片落在他身上。

不是刺穿他，是融入他。

第一片碎片融入胸口的时候，他听见了一个声音——那个中尉的声音：“我就知道会有人来。”

第二片碎片融入肩膀的时候，他看见了那间贫民窟的窗，灯还亮着。

第三片碎片融入手臂的时候，他握住了那个小女孩的手。

第四片、第五片、第一百片、第一千片、一万片。

三百年的记忆，几百万人，几十亿盏灯，全部融入他的身体。

他的身体开始发光。

不是混沌的光，不是灵能的光，是另一种东西——是他自己的光。是那个一百七十三岁才开始想“我到底在保护什么”的狙击手的光。是那个愿意多趴二十个小时就为了多看一盏灯的人的光。是那个站在这里七天七夜、一步不退的盾的光。

科瓦斯睁开眼睛。

他的眼睛里，没有疲惫了。

他看着那道裂痕，看着那四双眼睛，看着那些他挡了三百年却依然汹涌而来的混沌。

然后他做了一件事。

他伸出了手。

不是去拿武器——他没有武器。

他的手，指向那道裂痕。

那一瞬间，整个宇宙都安静了。

不是真的安静，是某种更深层的安静——是亚空间本身的尖叫，被一只手握住了喉咙。

他的身体开始瓦解。

不是被摧毁，是转化。他的每一粒细胞都在燃烧，每一滴血都在蒸发，每一个记忆都在释放。那三百年里装着的几十亿盏灯，在这一刻同时亮起。

光汇聚成一道。

一道剑光。

那剑光从他指向裂痕的手里涌出，不是金属的剑，是光的剑，是记忆的剑，是那些灯的剑。

它刺入裂痕。

刺入亚空间。

刺入那四双眼睛。

那一剑，斩过恐虐的血斧，斩过奸奇的迷宫，斩过纳垢的花园，斩过色孽的宫殿。不是杀死——是重创。是撕开一道它们需要千年才能愈合的伤口。是让那四双眼睛第一次露出惊恐。

亚空间的裂缝开始愈合。

不是被外力堵上，是它自己开始愈合——就像一道伤口，终于等来了药。

那药，是一个普通星际战士的三百年。

剑光消散。

科瓦斯的身影，也消散了。

他站在那里，最后看了一眼那间贫民窟的方向。

那里，有灯亮着。

然后他闭上了眼睛。

战场上，一束干枯的花缓缓飘落。
