如今泰图斯连长被正式任命为守望之主，肩负起保卫奥特拉玛的重任，这活儿可不好干。在 41 千年的险恶世道里，光是守住几颗星球不被泰伦虫潮、混沌入侵以及其他妖魔鬼怪撕碎就已经足够艰难，现在，整整五百个世界都得让他操心？——哎呀，是的。

在这样的非常时期，你需要一支真正可靠的伙伴队伍来共同分担重任，而泰图斯向来务实，自然乐于把各行各业最杰出的人才聚在身边。让我们来认识一下奥特拉玛守望者吧。

上次公布模型时，我们曾短暂瞥见过他们的身影，如今随着发售日近在咫尺，是时候更深入地了解一下他们了。就让我们从两张熟悉的面孔开始。

# **老兵军士梅陶露斯**

作为仍在服役的最年长的极限战士之一，剑卫军士梅陶露斯历经数百场战役，也是一位睿智的顾问。数世纪前，正是他在农业星球塔伦图斯招募了年轻的德米特里安·泰图斯，并主导了其大部分训练，成为不可或缺的导师。当昔日学生遭遇指控时，他更是公开回以蔑视。

二人后来在一次被视作自杀式的任务中重逢。在目标星球扎乌依上，一支精锐小队奉命踏平一座常规手段无法触及的邪教要塞，只能徒步血战突入。正如上级早该预料的那样，泰图斯拒绝让任务成为自己的终点，他在轨道轰炸将据点彻底抹除之前，把重伤的梅陶露斯硬生生拖了出来。

如今，梅陶露斯作为奥特拉玛守望者中沉稳老练的代言人，始终注视着自己的得意门生，免得他又一时冲动，再次单枪匹马冲进敌阵。

# **旗手加德里尔**

在雷西迪乌斯星系遭受泰伦虫族入侵期间，加德里尔本是极限战士第二连一位年轻却颇有能力的军士，而他小队的指挥权被转交给了当时的副官泰图斯。两人之间——这么说吧，有点摩擦：泰图斯对自己的过去讳莫如深，加德里尔则对这位怎么看都像有“满身原罪”的上司颇感抵触*。

***我们当然知道泰图斯绝不会叛变，但说句实话，他当年可没少给自己挖坑。**

然而，随着战役推进，两人不断成长，情谊也愈发深厚。加德里尔离开该星系时，已对泰图斯抱有钢铁般坚定的信任，这份信念正是在他人生中最惨烈的战斗中铸成的。后来，在守卫莫迪卡巢都时，加德里尔以慷慨激昂的演讲重整一条溃散的星界军防线，坚定了他们抵御汹涌泰伦虫潮的决心，最终成功守住一座关键大门。加德里尔因此获得泰图斯的亲自举荐，在前任旗手阵亡后接过第二连队的战旗。

尽管他是历来最年轻的掌旗官之一，加德里尔已证明自己无论是技艺还是勇气皆不逊先辈。人们看重他，不仅因为他战力超群，更因为他直言不讳的忠告。

# **星语者丹尼尔·科内留斯**

在奉命效忠泰图斯连长之前，丹尼尔在极限战士的要塞修道院担任星语者已逾百年，其对修会独门技艺的掌握已炉火纯青、无人能及。他收发的星际讯息始终清晰如镜，即便亚空间潮汐异常汹涌，他也从不退缩。要知道，在这种时候，哪怕最轻微的失误都可能让脑袋当场炸裂，而“爆头”还算是悲惨下场中最体面的那一种。

常年与惨死擦肩而过，让丹尼尔生出了一副尖刻的性格，即便是自己人，也没几个愿意跟他多待一秒，尽管谁都不敢否认他那无可取代的才华。好在泰图斯早已习惯了一肚子牢骚的刺头，为了奥特拉玛的安危，他可以忽略这位星语者带刺的外壳。

# **星球代表露西娅·维萨**

让我们来学个新词，“星球代表”：指一位能代表其主君全部威严与信任的外交官或使节。星际战士战团肯把自家事务交给一个凡人高官打理，光从这一点就足以见得露西娅·维萨的能耐。她惊人的谈判技巧和闻名遐迩的三寸不烂之舌，让数十颗星球被兵不血刃地重归于帝国麾下。

她把外交场上的本事原封不动搬进泰图斯一场接一场的战前会议，哪怕一句微小的谎言、一丝犹豫或掩饰，都会被她当场拆穿，根本来不及酿成祸端。凭着这份滴水不漏的敏锐和亮到发光的履历，露西娅赢得第二连上下的由衷敬重。再加上极限战士的舰队在她身后压阵，那些动歪心思的星球想不低头都难。

# **盖乌斯·席尔瓦**

光靠星际战士是无法让奥特拉玛全境重新归顺的，帝国必须出动庞大舰队，把兵员和物资跨星海运送到战火最前线。成群的巨舰搭载着数十万生灵，每一艘都得清点、登记、调度。当它们如潮水般涌向下一个被围攻的世界时，站在帝皇级战舰辉煌登基号舰桥发号施令的，正是盖乌斯·席尔瓦。

盖乌斯曾率领帝国大小舰队南征北战，哪怕最惊险的绝境，他也能稳如磐石，这份镇定早已成了传说。可更难得的是，他能处理星际战士与凡人船员之间的紧张局势。每当帝皇的天使们要求“再快一点、再猛一点、再严一点”，往往会把凡人的脆弱抛诸脑后，而席尔瓦总能填补这道裂缝。

# **埃米莉亚·密涅瓦斯**

当极限战士在自己的领域里燃起战火时，与他们并肩作战的是奥特拉玛防御辅助军的浩荡人海。这支凡人军队训练有素、装备精良，比寻常星界军团更胜一筹。埃米莉亚·密涅瓦斯指挥着马库拉格防御辅助军第 30 军团，这是一支战功赫赫，声名远播的舰队，现隶属于泰图斯连长。她本人则充当守望者与凡人部队之间的桥梁，每逢枪火，必挺身在前，率兵无畏冲锋。

身为马库拉格的忠诚子民，埃米莉亚能熟练引用《阿斯塔特圣典》，敬之如最虔诚的极限战士。在别人眼中那是一部冷冰冰的铁律，她却能在先辈的基石上继续雕琢，把其中诸多准则与要义转化为适用于辅助军的战略战术，一字一句铭记于心，并在战场上运用得淋漓尽致。

这六位杰出战士将于本周六与刚晋升的泰图斯连长一同开启预售，备受期待的《500 世界：泰图斯》会像一颗巨大的蓝色彗星砸向战锤旗舰店。即便你手头没有星际战士或太空死灵军团，这套扩展也绝对不容错过。全新的叙事战役等你体验，大受欢迎的“登舰行动”模式也将迎来扩充内容。
