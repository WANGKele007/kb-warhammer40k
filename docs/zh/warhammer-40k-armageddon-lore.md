哈米吉多顿的主体是一片横亘于星球中央的广阔大陆，与南北荒凉的极地地区之间隔着凶险的海洋。这片中央陆地包含两个主要区域：哈米吉多顿主大陆和哈米吉多顿次大陆，两者之间是一片广袤的赤道丛林。火山活动十分频繁，因为每当这颗星球运行到更接近星系恒星缇斯拉的位置时，其椭圆形轨道都会对地壳构造造成严重破坏。

# **哈米吉多顿主大陆**

哈米吉多顿主大陆上矗立着三座主要巢都——沃坎努斯巢都、坦佩斯托拉巢都，以及死亡沼泽巢都。

沃坎努斯是一座重兵把守的堡垒，坐落于星球最大山脉的怀抱之中，每逢碎骨者入侵，这里都是欧克蛮人主攻的肥美目标。堡垒周围是一片深不可测的载具残骸与战场废墟，一路延伸至恶名昭彰的曼海姆隘口——这是山脉中唯一宽阔到足以让超重型载具通行的关隘，也是数十台泰坦与战争雕像的最终葬身之地。

与之形成鲜明对比的是，坦佩斯托拉巢都是碎骨者·斯拉卡离开哈米吉多顿去集结他的伟大 Waaagh！时，留守欧克蛮人们所占据的最大据点。在蛮人大技师格里兹托夫的统治下，他们自那时起便成功抵御了帝国的反击——只有一次著名的例外。如今这座巢都被一道绵延数英里的壕沟、碉堡与防御工事网络所环绕，史称莫菲昂防线，用以将欧克蛮人困于其中。

这两座巢都与死亡沼泽巢都之间，隔着大片致命的灰烬荒原。这片荒原由数千年累积的污染物、放射性废料和有毒化合物构成。而死亡沼泽巢都本身，既是一个重要的物流枢纽，也是广袤观测阵列——“帝皇之眼”天文台的所在地。在灰烬荒原，人类必须时刻佩戴呼吸器，否则几分钟内便会痛苦死去，这让更为坚韧的欧克蛮人占据了明显优势。

# **赤道丛林**

一片广袤而茂密的丛林如墨绿色臂环般横亘于主大陆之上，从太空中清晰可见。这里曾是游击战场。据帝国散兵游勇所言，他们的对手是鬼祟潜行的欧克蛮人刺客。如今赤道丛林已沦为数百个互不相属的部落巢穴，他们借树冠为庇护，躲避星球的灼火季——届时地表温度会飙升到 90°C 以上，震颤将大地撕裂出狰狞裂口。

在《哈米吉多顿：雅瑞克归来》的开端，帝国指挥部制定了一项大胆计划，意图一劳永逸地肃清丛林中的欧克蛮人：从边缘开始，向前推进，将每一根细枝、每一条树干、每一缕根系都焚为灰烬。想必，这是一个毫无弊端的完美方案……

# **哈米吉多顿次大陆**

哈米吉多顿主大陆的另一半远比主大陆更为工业化，曾拥有数量更多的巢都。在第二次哈米吉多顿战争中，伟大的哈迪斯巢都是击败碎骨者·斯拉卡的传奇战场，而它却在第三次战争伊始便被轨道陨石轰炸夷为平地；而孤立的索拉迪斯巢都则在最近的鲜血时节中，沦陷于安格隆的恐虐大军之手。*

** *除了灼火季和鲜血时节之外，还有阴影季，因此游客们在预订哈米吉多顿之旅时，务必小心选择出行时间。**

在其余的巢都中，因费努斯巢都现已处于帝国控制之下，而赫尔斯利奇巢都**则失去了大部分工业劳动力，仍在欧克蛮人袭击的震荡中喘息。尽管如此，制造设施与交通枢纽仍纵横交错于这片区域，在非战时期，它为哈米吉多顿提供了大部分的物资来源。次大陆先进的基础设施，也让帝国军队防守这些城市远比防守主大陆来得轻松。

****有传闻称，它甚至可能是哈米吉多顿历史上的第一座巢都。**

碎骨者显然也看出了这片区域的重要性，因此在第二与第三次哈米吉多顿战争中，他将绝大多数兵力集中于征服次大陆。因费努斯巢都与阿刻戎巢都相继沦陷于兽人之手——后者还得益于叛变的前总督冯·斯特拉普***的协助——但此后帝国已将其收复，并重新补充了至关重要的劳动力。

# **炽火荒原与死亡荒原**

远在主大陆以北，跨越沸腾之海，炽火荒原是一片火山活动肆虐、熔岩河流灼烧的险恶地狱，尽管如此，这里仍遍布着炼油厂与采矿基地网络。由于哈米吉多顿的轴倾角，这片区域几乎永远直面星系中狂暴的恒星。而在灼火季，恒星引力逼近，将本就致命的地貌化为烟与火的噩梦。

在星球另一端，死亡荒原为众多巢都提供了至关重要的水源补给。尽管地位重要，兽人入侵此地却仅将其作为跳板，以便发动大胆的潜艇突袭，进攻沿海巢都。第三次哈米吉多顿战争期间，一些疾速帮派留守此地，意图痛击少数帝国守军，但被苏博登可汗彻底击溃，这确保了众多码头与钻井站牢牢掌控在帝国手中。
