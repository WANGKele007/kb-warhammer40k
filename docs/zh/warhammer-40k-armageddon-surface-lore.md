上周，我们对阿米吉多顿星系的各个行星进行了一次旋风式的巡礼。今天，我们将降落到其首府星球，了解其主要区域——这些区域很快就会被兽人占领。

阿米吉多顿主星的主体是一块横跨行星中心的巨大陆地，与南北两极荒凉的极地地区隔着危机四伏的海洋。这块中心陆地包含两个主要区域：阿米吉多顿主大陆（Armageddon Prime）和阿米吉多顿次大陆（Armageddon Secundus），两者之间是一片广袤的赤道丛林。由于阿米吉多顿的椭圆轨道每次靠近其恒星提斯拉时都会对其地壳结构造成剧烈扰动，因此火山活动十分活跃。

# **阿米吉多顿主大陆**

三大巢都占据了阿米吉多顿主大陆广袤的疆域——火山巢都（Hive Volcanus）、风暴巢都（Hive Tempestora）和死亡沼泽巢都（Hive Death Mire）。

火山巢都是一座重兵把守的堡垒，坐落在星球上最大的山脉之中，每次碎骨者入侵时，它都会成为兽人大规模进攻的肥肉。它周围环绕着难以想象的车辆残骸和战场废墟，一直延伸到臭名昭著的曼海姆隘口（Mannheim Gap）——这是山脉中唯一一条足以让超重型车辆通过的通道，也是数十台泰坦和钢加特的最终归宿。

相比之下，风暴巢都城则是碎骨者撒拉卡离开阿米吉多顿主星去集结他的大Waaagh！时，留在阿米吉多顿的兽人占据的最大据点。在大技霸格利茨图夫（Big Mek Glitztoof）的统治下，它们一直成功抵御着帝国的报复——除了一个明显的例外——现在，为了将兽人困在巢都里，巢都周围环绕着绵延数英里的战壕、掩体和防御工事网络，被称为莫菲恩防线（Morpheon Line）。

这两座巢都与死亡沼泽巢都（关键后勤枢纽和庞大的扫描阵列“帝皇之眼”天文台所在地）之间的绝大部分地形都是致命的灰烬荒地，由数千年来积累的污染物、放射性废物和有毒化合物形成。人类必须时刻佩戴呼吸器，否则会在几分钟内痛苦地死去，这使得更具韧性的兽人拥有明显的优势。

# **赤道丛林（The Equatorial Jungle）**

一片广袤茂密的丛林如同一条深绿色的臂环，横跨主大陆，从太空清晰可见。这里曾是残存的帝国士兵与狡猾的兽人刺客交战的战场，如今，数百个不同的部族在此安家落户，它们以丛林树冠为庇护所，躲避星球的烈焰之季——届时地表温度将飙升至90摄氏度以上，地面也会因剧烈震动而撕裂出嶙峋的裂痕。

在《阿米吉多顿：亚瑞克的回归》的开篇，帝国指挥部启动了一项大胆的计划，旨在彻底清除丛林中的兽人：从边缘开始，一路推进，将每一根树枝、每一棵树根都烧成灰烬。这无疑是一个万无一失的计划……

# **阿米吉多顿次大陆**

阿米吉多顿主星的次大陆比主大陆工业化程度更高，并且拥有（或曾经拥有）更多数量的巢都。伟大的哈迪斯巢都——亚瑞克政委在第二次阿米吉多顿战争中击败碎骨者撒拉卡的著名地点——在第三次战争初期被轨道火箭轰炸摧毁，而孤立的索拉迪斯巢都则在最近的血腥季节中落入安格隆的恐虐大军之手。

在幸存的巢都中，因费努斯巢都（Hive Infenus）已落入帝国控制，而海尔斯瑞奇巢都（Hive Helsreach）则失去了大部分工业劳动力，并且仍在遭受兽人袭击的重创。尽管如此，制造设施和运输枢纽仍然遍布该地区，在阿米吉多顿没有遭受持续攻击时，它们提供了绝大部分的物资。次大陆先进的基础设施使得帝国军队能够比在主大陆更容易地保卫这些城市。

撒拉卡也清楚地意识到这片区域的重要性，因此在第二次和第三次阿米吉多顿战争期间，他将绝大部分兵力集中于征服次大陆。因费努斯巢都和阿刻戎都落入了兽人之手——后者是在叛徒前总督冯·斯特拉布（Von Strab）的帮助下取得的——但此后帝国已收复了这些地区，并补充了至关重要的劳动力。

# **烈焰荒原与死亡之地（The Fire Wastes and Deadlands）**

在主大陆遥远的北方，越过沸腾之海，烈焰荒原是一片荒凉的炼狱，火山活动频繁，滚滚熔岩流淌，然而这里却遍布着炼油厂和采矿基地。由于阿米吉多顿星的轴倾角，这颗星球的这一部分几乎总是正对着该星系的炽热恒星，在烈焰季节，它强大的引力将这片原本就危机四伏的土地变成了烈焰与浓烟交织的噩梦。

在星球的另一侧，死亡之地为许多巢都提供了至关重要的水源。尽管它如此重要，但兽人入侵这片区域仅仅是为了将其作为跳板，发动针对沿海巢都的大胆潜艇袭击。那些被留下来袭击少数帝国士兵的飙速怪咖在第三次阿米吉多顿战争中被苏博登·汗彻底击败，确保了许多码头和钻井站牢牢掌握在帝国手中。
