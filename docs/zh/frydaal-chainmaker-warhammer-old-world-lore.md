以前我就好奇中古戰錘有沒有女性的渾沌戰士，理論上只要有實力就能當，但是這方面的描寫就真的比較少，不過去年戰錘：舊世界 ( TOW ) 開始更新後就補了個女性的渾沌冠軍 :P

 鑄鍊者弗麗達爾 ( Frydaal the Chainmaker )

 弗里達爾，又名鑄鍊者弗麗達爾，是渾沌無分的諾斯卡至高冠軍 ( Exalted Champion，比普通的冠軍還要更強 )，在帝國曆2270年代初無政府時期 ( Anarchy ) 的最後幾年裡指揮諾斯卡人和盟友渾沌勇士對威斯特領 ( Wasterland ) 發動了多次襲擊。 補充一下，戰錘舊世界的時間背景是帝國曆23世紀左右，這時期的帝國陷入混亂分裂成塊，這時期西邊的威斯特領由女選帝侯艾爾斯佩思．瑪格里塔六世 ( Elspeth Magritta VI ) 整合周邊領土形成一大盤據勢力，絕大多數人口集中在瑪林恩堡，和其他三個自稱有帝國繼承權的勢力互相抗衡。 弗麗達爾追隨那呼喚所有諾斯卡人的渾沌誘惑，在渾沌荒原中與其他渾沌勇士交戰，隨後她帶著被黑暗力量所灌注的身軀返回諾斯卡，實質上已成為一名渾沌無分的至高冠軍，不效忠任何特定神祇，而是侍奉渾沌整體的意志。 她是位極具感召力的掠奪者，她鼓舞了其他渾沌勢力並集結了一支龐大的諾斯卡艦隊，沿著利爪之海襲擊文明人類諸國的海岸，所到之處皆進行劫掠並散播渾沌的腐化。

 在帝國曆2270年代初期弗麗達爾襲擊了當時屬於威斯特領的北部海岸城鎮霍勒姆 ( Hollum )，數年間她以霍勒姆與鄰近城鎮的廢墟為核心在商業城邦瑪林恩堡以北建立了屬於自己的封地，她的劫掠行動以此據點向整個北威斯特領擴展，渾沌的力量與腐化也不斷在大地上滋長蔓延。 隨著腐化加劇，野獸人戰群被吸引而來棲息於周邊森林之中，進一步加深了對瑪林恩堡與帝國的威脅，弗麗達爾還在霍勒姆的中心建立了一座供奉毀滅諸神的黑暗紀念碑，不久後便開始將大量黑暗魔法吸引至該地區。 

 在約帝國曆2276年的冬季期間，女選帝侯艾爾斯佩思．瑪格里塔六世集結了一支傭兵軍隊以應對迫在眉睫的威脅，她深知一旦利爪之海解凍諾斯卡人的狼船便會再次為掠奪而來，因此在春季率領傭兵與威斯特領正規軍向北行軍直指霍勒姆廢墟 然而弗麗達爾早已得知女選帝侯的進攻計畫，她不畏嚴冬尾聲率領渾沌掠奪者與渾沌戰士提前抵達霍勒姆的據點，當帝國軍隊抵達時渾沌勢力已然嚴陣以待，戰鬥開始前弗萊達爾在霍勒姆向她為黑暗諸神所建的紀念碑俯首致敬，祈求祂們見證她以其榮耀之名摧毀帝國軍隊。 霍勒姆戰役標誌著帝國和渾沌勇士之間第一次真正意義上的戰鬥，這場戰鬥將是大約二十五年後爆發的大戰之前帝國軍隊和渾沌勇士之間規模最大的戰鬥之一。
