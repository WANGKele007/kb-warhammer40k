# **火葬者 The Pyre**

火葬者（The Pyre）是一支出身不明的混沌星際戰士，現今活動最頻繁於傑里科星域（Jericho Reach）。

# **基本数据**

**名称：火葬者**

**來源：未知**

**颜色：橙甲，黑边框**

**战幫歷史**

火葬者首次被帝國部隊在131.M41於恐懼之眼附近觀測到。此前並無確認記錄顯示與該戰幫有過交鋒。

帝國軍需部的分析師無法斷定火葬者是否由另一已知混沌戰幫分裂而成，或是由數個不同團體的殘餘勢力組合而成。

也沒有跡象顯示火葬者效忠於任何單一的混沌諸神；相反地，他們傾向於與所有黑暗諸神的僕從協調作戰。已知火葬者曾在某個時期以名為「不潔先驅號」（Unholy Harbinger）的太空廢船作為行動基地。

# **重要戰役**阿基里斯遠征（777.M41）——在帝國持續進行的阿基里斯遠征期間，火葬者持續在傑里科星域製造騷擾。火葬者的部隊在多次行動中扮演重要角色，尤以虛榮星系（Vanity System）為甚。奇怪的是，目前尚未有該戰幫的高階成員被確認身分。相反地，這些叛徒經常與虛空生物及在星域內活動的混沌崇拜組織——斯蒂格馬特斯（Stigmartus）同行。另一值得注意之處在於，尚未觀測到火葬者單位與其他混沌戰幫的部隊直接合作。鑑於混沌勢力常採用多元化部隊組成，這種隔離現象難以解釋。

# 阿基里斯遠征的部隊曾遭遇數艘帶有火葬者標記的突擊巡洋艦與一艘戰鬥駁船。這些艦隻曾在虛榮星系與瑪戈格星系（Magog Systems）現身，並伴隨有連級規模的火葬者地面部署。所目擊的太空艦隻數量顯示，至少有數個連級的異端阿斯塔特單位在星域中活動，但遠征軍主力尚未與任何此等規模的混沌部隊接觸。這可能意味著火葬者的編成分散於整個要區域，或被大量保留於後備，亦或如已知部署所示，他們與其他混沌勢力共用艦艇。

# 已知火葬者在虛榮星系擁有數個防禦工事，例如「火炬要塞」（Torch）與「熔爐堡」（Crucible）。

# **戰鬥風格**火葬者雖擅長近戰與中長距離交戰，但該戰團以短距離作戰為首選，尤擅城市/密集環境中的巷戰與室內衝突。

# 火葬者對火焰武器的偏愛深刻影響行動戰術，通常捨棄傳統的突擊與遠程火力支援編成。取而代之的是磨練在遮蔽中機動的技巧，悄然靠近目標，然後以致命的邪火突然發起攻擊。

# 火葬者常與各路黑暗諸神的僕從協同作戰，已觀測到其配合惡魔軍團與混沌邪教徒等勢力共同部署與作戰。

# **登場角色**

歌德·暗焰（Goethe Darkflame）——一名被神選終結者（Chosen Terminator），暗焰在火葬者服役已達地球紀元數個世紀。在這段時間裡，他對帝國及其「屍皇」的憎恨不斷被煽動，以致於如今只要一點導火線便會瞬間燃燒成烈焰。他對黑暗諸神的虔誠遠不及對那些向帝國屈膝之人的憤怒來得深沉。比他燃燒般怒火更強大的，是他極度的自我保存意識。儘管他樂於與那些他視為低賤之人作戰，但在他認為勝算不在己方時，他也不會因自尊而拒絕撤退。這一面向在某種程度上被他對自身戰鬥能力極高評價所中和。現任虛榮星火炬要塞指揮官的他，認為這一職責是火葬者中崛起的混沌冠軍對他的懲罰。因此，他對戰幫內的高階成員懷有深厚怨恨。

科爾·魂焰（Kole Soulfire）——曾為審判官甘特效力的叛變靈能者，生前曾用名達里烏斯·費恩（Darius Phine）。現已成為混沌巫士，並掌管火葬者在虛榮星系的要塞「熔爐堡」。他企圖利用盜取自帝國的聖物「聖阿瑞特之球」（Sphere of St. Aret）施行一場召喚惡魔的儀式。
