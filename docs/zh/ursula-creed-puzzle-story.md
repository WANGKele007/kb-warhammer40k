# **第十七章**

“那个兽医花的时间太长了，”瓦尔顿低吼道。

埃克尔紧张地瞥了一眼那名兽霸。他正盘腿坐着，目不转睛地盯着剧痛堡垒的入口坡道。它是封上的，因为格鲁斯尼克坚持认为最后的手术需要全神贯注，瓦尔顿的粗暴存在会吓到屁精们。他的话可能有道理。其当然吓到了埃克尔。

“也许手术需要时间。”

“对克莱沃尔来说从没有过。不，他是在搞什么阴谋。”

“你确定吗，头目？”埃克尔坚持道。“俺的意思是，别告诉他是俺说的，但那个兽医并没有完全掌握一切。俺不知道他是否有能力制定一个聪明的大计划。”

“是的，他是这样。或者说，至少他的一部分确实如此，”瓦尔顿回答道。“俺开始怀疑这些小事故了。比如巴库姆的史古革怎么不小心被注射了某种东西让它发疯，或者泽勒怎么死了而格鲁斯尼克得到了他的颅骨板。一个屁精恰好发现了它？不，他大概还杀了泽勒。”

埃克尔想了想，记起了他曾在船上偶然听到的谈话。

“你可能是对的，”他说道，避开了那名兽霸的目光。瓦尔顿并非一个聪明的兽人，与技霸和兽医们相比当然不是。可他有时是个深度思考者。迟缓，但愿意坐下来推量。让其发散。

但那个时间似乎已经过去了。那名兽霸起身，拿起了他的砍刀。

“你打算做什么，头目？”埃克尔问道。

“俺想俺可以看看这次手术的进展如何，”瓦尔顿回答道。“如果杀脸有所好转，或者那个兽医至少有过不错的尝试，那么俺会再动身。瞅瞅还有什么可以狩猎的。”

“如果它没好转呢？”

“那就得有人去教教那个兽医，真正的兽人说到做到。不像撒谎的屁精们。”

他心不在焉地说着，几乎没考虑过这些话。有一小部分的埃克尔感到了受挫，尽管这种含沙射影很准确。

“可是，如果那个兽医像你说的那么聪明，如果他一直在耍你，他难道不会有什么计划吗？”

瓦尔顿放慢了脚步，眉头紧锁。

“俺们还可以只是离开？”埃克尔建议道。“俺不太喜欢徒步，但这周围可能会有一些兽霸。俺敢肯定你能弄到一头史古革。然后俺们可以-”

“俺不能一走了之，屁精，”瓦尔顿叹气道，转向埃克尔。“俺不会让其发生的。计划与否。”

他笑了。这可不是一种让人安心的表情，涉及太多的牙齿了。但他的眼睛里没有什么威胁，至少没有针对埃克尔的。只有对即将发生之事冷冰冰地顺从。

“……你想让俺跟你一起去吗，头目？”埃克尔听见自己问道。他不想去。任何一个好的上鞍崽子都知道什么时候该抓紧，什么时候该离开。他的直觉告诉他，现在是时候离开了。可他仍然望着瓦尔顿。

“不。你为啥不在外面等着呢？”瓦尔顿回答道。“就……随你的便。”

他走近入口坡道，按下了应该将其打开的按钮。当门仍然是关着的时候，埃克尔看着他抡起砍刀并将其猛砸在坡道边缘，金属在撞击下被扭曲变形。又敲了几下，它已经弯曲到足以让瓦尔顿把手指塞进缝隙里。他放下砍刀，用双手抓住然后使出全身的力气，肩膀上的肌肉都竭力绷紧了。

无事发生。一开始没有。但他仍然坚持着，一只脚踩在战车的外壳上，前后扭动，把他的体重压在那上面。另一个兽人可能会感到厌倦，或者认为这项任务不可能完成，但瓦尔顿不会放弃。每次他将他的重量甩回去，那块金属都会再扭曲一点。

它未曾崩断。装甲太厚了。但机械装置里有什么东西失灵了，因为传来一阵不和谐的叮当声，坡道突然打开，瓦尔顿滚到了一边。他站起身，取回他的砍刀，凝视着剧痛堡垒的边界。

很暗。没有光亮。没有声音。

“头目？”埃克尔听见自己说道。但瓦尔顿没有答复或回头看。相反，他踏入了那片黑暗。

瓦尔顿过去常常在阴影中狩猎。

当然，那通常是在更宽阔的空间，而非狭窄的剧痛堡垒。正常情况下他会依靠气味来定位他的猎物，但这室内充斥着各种化学品的味道，几乎不可能分辨出其他任何东西。周围还一片寂静，除非算上剧痛堡垒发电机持续不断的隆隆声，或远处昆虫的嗡鸣。

不过他知道这里的布局，他小心翼翼地穿过中央舱室，朝着幽深处走去。那里是此前照管杀脸的地方，通常手术也是在那儿进行的。当他靠近时，两种气味愈发浓烈。鲜血是其一，或者更准确地说，是血液、胆汁以及刀刃刺入肉体时散发出的各种香味。但另一种气味盖过了它。那仍然是一种相当新的味道，但似乎已经充斥了这个愚蠢的世界。它闻起来是错误的。受污染的。病态的。

他在挤向更深处时紧紧握住手中的砍刀，越过了那台此前能自由施与皮肤的机器。如今它被废弃了，其储备已经用尽。事实上，随着他的眼睛适应黑暗后，他可以看到那名兽医的大部分储备都不见了，椽子上的肉袋都被洗劫一空。密封水箱就在前方。那里的血腥味更浓。

“杀脸？”

那头史古革还躺在原来的地方。至少是还剩下的东西。兽医之前在培育的那些可怕的畸形腿已经不见了，伤口敞开着，未经处理。但那头史古革还活着，它呼吸缓慢而吃力，其身体连接着可能曾经是兽人躯干的肉袋。很难说它是否还有意识。一只眼睛睁着，却茫然地盯着前方，而当一只苍蝇落在其上时，那头史古革连眼都不眨一下。

瓦尔顿站在那里，注视着这个生物，他的目光慢慢转移到他的砍刀上。

也许最好还是让它从痛苦中解脱。就像他对待那个被坦克压扁的虾米一样。

但当他举起武器时，黑暗中传来一个声音。

“俺更喜欢你不要动它。那家伙还有用呢。”

瓦尔顿转过身。一个熟悉的身影瘫坐在阴影里，双腿伸开。

格鲁斯尼克。

他身上沾满了发紫的血迹，在黑暗中看起来几乎是黑色的。他的一只手里拿着他的黄铜瓶子。但他并没有将其提供给瓦尔顿。这次没有。

“你本该让它好起来的，”兽霸低吼道。“俺们说好了的。”

“嗯，”格鲁斯尼克说道。“俺肯定是撒谎了。或者改变了俺的主意。俺完全想不起来了。那不重要，跟俺完成的事情比起来算不了什么。你不想看看吗？”

“不。”

“不？好吧，俺想这也有道理。毕竟你是个兽霸。你并不像懂得欣赏俺礼物的样子。俺的天才。没几个人能做到。铁颅，当然，但他是不同的天才。疯狂，但你必须得疯狂。必然的附带。”

他叹了口气，垂下了头。“还有纳尔茨。纳尔茨知道。他了解太过聪明而招致的祸患。”

“你这么认为？”瓦尔顿咆哮道，朝着瘫坐的兽医走去。“各种自负的主意在你的脑袋里。然而你从未想过当俺意识到你耍了俺之后会发生什么。从不知道-”

有什么东西在他脚下嘎吱作响。柔软，但有一小点儿刺刺的。骨头。

他低头瞥了一眼，当试图辨认倒在兽医脚边那团扭曲的小东西时皱起了眉头。只有那身制服和没戴面罩暴露了其身份。

纳尔茨。

“真可惜，”格鲁斯尼克说道。“他有天赋，那个小伙儿。了解界限并知道何时忽略它们的才能。还有想象力，以及直线思维。拥有的人不多。俺，铁颅。少数其他人。”

“……你做了什么？”

“当俺看到他在工作时，将其穿在一起，把弯弯曲曲的玩意儿和管子拼接起来，俺真是印象深刻。或者骄傲。从没见过一个剧痛小子拥有如此技艺。如此专注。只有俺拥有这种天赋。”

格鲁斯尼克的声音很小。瓦尔顿发现自己手中的武器微微放低了一些，因为那名兽医似乎很消沉。颓丧。

“是啊，一份天赋，”兽医说道。“只是这不可能是他的。你不可能学到那么好。你天生如此。不，他的技艺是偷来的。他从俺这儿拿走了它。”

他抬起头，仿生义眼在阴影中闪烁。

“他肯定觉得自己聪明得要命。声称俺们的行为不理性。俺们需要切除俺们的一部分。哦，大部分都投入了那个工程，俺能看出来。但他肯定是偷了俺的一小点天才。将其塞进他的耳朵里。所以他才做得那么好，因为他在试图成为俺。不能那样，对吧？不，俺们不能。可怜的小屁精。如此熟练。即使在俺敲开他的脑袋时，俺也看不到接缝。俺看不出他把俺的小块儿缝在了哪里。他是怎么把那些接缝隐藏起来的，连俺都看不出来？”

兽医叹了口气，然后瞪着他铜瓶子的反光表面。

“俺看到你在那里，”他低声道。“是你干的。让俺们这么做。而且俺们看不到那些接缝。”

瓦尔顿摇了摇头。“你疯了。”

“疯？”格鲁斯尼克轻笑道。“哦，在你看来肯定就是这样。但你啥也不是，只是个擅长坐着拍脑袋的大块头兽人。俺塑造肉体，缝合血液，拼接思想就像拼接肢体一样轻易。正是因为俺，兽人们才会赢得这个银河系。因为是俺创造了碎骨者，并在他倒下的时候为他注入了生命。不是诸神，俺！事实上，俺是你这辈子见过最接近神的东西。”

“是吗？”瓦尔顿咧嘴笑道。“有趣的是碎骨者怎么厌倦了你和你的谎言。有趣的是他怎么不再需要你了。没人知道。当俺砍倒你的时候，他甚至都不会在意。没有兽人会想念你，或者注意到你已经不在了。即使是你那些可怜的哭哭啼啼的屁精们也不会。你杀了他们当中唯一可能喜欢你的那个。其他的则会欢呼，如果你没把他们的嘴缝起来的话。疯医到此为止。格鲁斯尼克到此为止，屁精杀手。”

他举起武器，然后使出全身力气猛击下去。这一击足以凹陷一台战斗坦克，打倒一头横冲直撞的野猪史古革。那名兽医应该已经被切成了两半。

相反，格鲁斯尼克接住了刀刃，他的目光始终没离开那个瓶子。

瓦尔顿简直不敢相信。他咕哝了一声，使劲地拉。但那名兽医一只手握着它，鲜血从掌心渗出，他缓缓站起身，将那个瓶子塞进腰带上的一个小袋里。他不知为什么变高了？他的脊椎通过手术变直了？还是说他一直这么巨大，只是他的驼背隐藏了他的身材。让他自己看起来更小。什么兽人会选择显得更小？

“格鲁斯尼克，”兽医嘶声道。“你随口抛出那个名字好像它是一种侮辱。格鲁斯尼克。你没搞懂，对吗？”

他单臂将那刀刃放低至了自己身侧，瓦尔顿仍在用力，但无法阻止他。

“格鲁斯尼克因他杀害小矮个儿们而得名。那些顶嘴的小矮个儿们。那些碍事的小矮个儿们。那些不提供尊重或展示太多前途的小矮个儿们。那些当俺需要借用他们的少许器官时就发脾气的小矮个儿们。那些在俺最需要他们的时候却让俺失望的小矮个儿们。他们不明白吗？你难道不明白吗？你对俺来说啥也不是。全都是弱不禁风的小屁精！”

他的头重重地撞在瓦尔顿的头上，弄得那名兽霸踉踉跄跄，他的武器也从其松弛的手指间滑落。但他稳住了自己，向前一步，对着兽医的下巴送出了雷鸣般的一击。他感觉到有什么东西在撞击中裂开了，但那兽医几乎没注意到，他的手悄悄伸出，抓住了瓦尔顿的手腕。他用力一捏，接着瓦尔顿就感到骨头嘎吱作响。

“真遗憾，你的手腕还没完全愈合，”格鲁斯尼克说道，用力捏着。“俺们在那儿留下了一些裂缝，而且骨浆还没变硬。让俺们向你展示。兽医现在会看你了。整个你，尤其是你血液中那些弯弯曲曲的小块儿。躯体-”

瓦尔顿的拇指戳进了格鲁斯尼克的好眼睛。兽医发出嘶嘶声，抓着自己的脸摇摇晃晃地后退。瓦尔顿冲上前去，将兽医扑倒在地，他的前臂紧紧扼住另一个兽人的喉咙，谋求压碎对方的生命。兽医在他身下激烈地扭动，但即使他更强壮，瓦尔顿却有重力在他这边，用他身体的重量压住了那名兽医的气管。

“叫俺是个屁精，”他咆哮道。“继续啊！再叫俺是个屁精！”

格鲁斯尼克没有回答。相反，他抓住了瓦尔顿的前臂，野蛮地扭动起来。咔嚓一声，骨头断了。瓦尔顿在痛苦中大吼，另一只手朝他乱抓着，但兽医已经将他翻了个身，此刻在上面了。他的好眼睛布满血丝，另一只则闪烁着绿光，同时他的金属颅骨处冒出了一团团烟雾。

“肮脏的撒谎屁精！”他咆哮道。“对俺们来说你只是肉！俺们可以随意切割与缝合的没用的肉！先是你，然后是他！俺们会剥他的皮，扯下他的脑袋，然后把里面无论什么乱七八糟的东西舀出来。他们称他为诸神的先知？俺们才是诸神！俺们创造了他，并且俺们会像终结你一样轻易地终结他！”

他的说话声是一阵咆哮，他的爪子挖进了瓦尔顿的咽喉。这名兽霸盲目地摸索着，试图找到什么武器。他能感觉到有什么东西顶着他的腿。

注射器。就是他从船上的屁精那儿没收的那个。他还保留着它，但他却够不着。用他那只残废的手臂不行。

“头目？”

那声音几乎是耳语。他抬起头来，透过模糊的视线，看到一名医护屁精正依附在高处的支撑杆上。

有趣的是，他们中大多数都不会说话。

“头目？”

是埃克尔。那个屁精的耳朵垂平，肩膀耸起。他看起来很害怕，但他在那里。

“埃克尔，”瓦尔顿咕哝道。“俺的……腰带……注射器……”

那屁精朝他的腰部瞥了一眼，然后再次与他对视。

“俺不知道，头目。似乎有风险。”

“只管……去……做！”

埃克尔蹑手蹑脚地下来，用双手和膝盖朝他爬去，目光在注射器跟格鲁斯尼克之间来回切换。那个兽医浑然不觉，他的注意力完全集中在将瓦尔顿的脑袋从他的肩膀上扯下来。他也取得了不错的进展。瓦尔顿能感觉到他的脊椎在伸展，脖子上的皮肤在撕裂。那名兽医距离终结他只有片刻之遥。

但埃克尔拥有了注射器。他双手紧握着它，目光在兽霸和兽医之间来回游移，似乎不确定该怎么办。

“捅……他，”瓦尔顿倒抽他的最后一口气道。他不确定自己的话是否能让那个屁精信服。也许就在他回头瞥的一瞬间，其无疑是在寻找一条逃生路线，但面对的却是被活体解剖的杀脸残躯以及曾经是纳尔茨的那片污渍。

不管怎样，他举起了针头，接着狠狠刺进了兽医的喉咙。

兽医发出嘶嘶声，他的抓握开始松动。然而瓦尔顿发现自己还是站不起来。他努力尝试，想让自己朝兽医乱打一顿，但他几乎动弹不得，手指虚弱地抽搐着。那兽医刚才野蛮地猛拉他的脖子，弄伤了什么东西。这个兽霸无力反抗。

格鲁斯尼克自己也在抽搐，抓挠着他喉咙里的针头。瓦尔顿认为这是某种毒药，旨在使受害者失去知觉或杀死他们。而且的确，那兽医似乎在摆动，他的好眼睛在脑袋上打转，他的双臂正变得无力。

但他没倒下去。相反，他的颅骨里传来一阵飕飕声，一种蒸气逸出的啸音。

他睁开眼睛。接着笑了。

“啊。这样……这样好多了。能想得更清楚一点，”他说道，转向正在颤抖的埃克尔。“做得不错，小不点儿。这确实有所缓解。”

埃克尔只是呆呆地盯着，目光在兽医和兽霸之间闪动。

“迷失在俺的头脑里了，”格鲁斯尼克继续道。“让所有的胆汁都积聚起来。必要的，当然，为了最终阶段。不过俺差点就浪费掉了，差点扼杀了一个贵重的样本。并不是说他很特别，这一个。但俺总是需要部件，不是吗，一点-”

他皱起眉头，望着这个屁精时声音渐渐低了下去。

“等等，你是俺的人吗？”他问道，伸出手，拉下面罩，露出了埃克尔的脸。

他凝视着那张脸，埃克尔被吓得僵住了。

“是啊……俺认得你，不是吗？”他轻语道。“埃克尔，对不对？你之前经常给那些史古革清理粪便。史古革……那俺们是什么时候有过它们的呢？”他停顿了片刻，然后耸耸肩。“没关系。如果俺把你的嘴留给你，那么你必须知道什么时候闭上它。对吗？”

埃克尔的目光迅速投向趴在地上的瓦尔顿，然后又转回到格鲁斯尼克身上。

他点了点头。

“这很好。”格鲁斯尼克微笑道，他的眼睛再次盯向瓦尔顿。“好吧，小埃克尔，俺们还有几个小任务要完成。一点最后的修饰。鉴于你帮俺恢复了思绪，你可以帮上忙。”

那个屁精手里突然多了一个新的注射器。

格鲁斯尼克指向瓦尔顿。“你来负责，屁精？”

埃克尔摇着脑袋，拿起了注射器。他急忙跑向瓦尔顿，那个兽人仍趴在地板上。

“抱歉，头目，”当针头扎进那个兽人的皮肤里时，他小声说道。
