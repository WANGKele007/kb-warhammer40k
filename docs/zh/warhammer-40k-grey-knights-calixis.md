# **卡利西斯星区中的灰骑士**

灰骑士对卡利西斯星区并不陌生，自该星区建立以来，他们就多次在其边界内猎杀恶魔猎物。鉴于它邻近恐惧之眼与光环群星，也难怪该星区会滋生如此之多的异端教派与强大的亚空间居民，更不必说暴君星了，其存在本身始终是审判庭持续不变的关注点。尽管灰骑士在该星区的存在既不庞大，也非长驻，但考虑到帝国内数以万计的次星区以及战团相对稀少的人数，他们此时存在的事实本身就意味深长。这一切都说明了该星区对圣锤修会的重要性。

在该星区的历史中，亚空间生物与审判庭之间曾发生过多次重大冲突，其中数次恶化了到相当灾难性的程度，需要灰骑士进行介入。也许其中最广为人知的(至少在泰坦的殿堂内如此)当属战团与主要恶魔(Arch-Daemon)巴弗灭尔化身的对峙。这头凶兽是名为黑暗之角兄弟会的异端邪教的核心。由于审判庭一系列的调查失败与一场精心策划的误导把戏，一个巴弗灭尔教派得以在世界逆地星上兴盛壮大，在帝国视而不见之际于阴影中恶化。直至巴弗灭尔显化，血腥的跨入现实，吞噬数千无辜灵魂后，危险才被真正意识到。幸得灰骑士迅速抵达并净化了整片大陆，局势才得以控制，而恶魔的物质形体也得以摧毁。灰骑士不会轻易遗忘，尽管他们战胜了恶魔化身，但他们深知它依然存在，潜伏在亚空间的阴影中，等待着再次显化报仇雪恨。届时，灰骑士将完成他们未竟之事。

# **旋向威胁**

在更近的时代，又有一大威胁崛起，亟需审判庭与灰骑士的关注。一个强大的亚空间实体即将打破物质界与非物质界之间的帷幕。它被称为失序之主，这尊大魔直到近期才引起审判庭充分重视，尽管它的历史可以追溯至数世纪前的神话与流言。此前许多骇人听闻且极具毁灭性的入侵都被归咎于这只恶魔的操纵，而且所有线索似乎都表明它更大的计划才刚刚开始显露。为应对这一威胁，泰坦派遣了打击巡洋舰“正义黎明”号及一支由仲裁官马里甘特指挥的灰骑士精锐。通过这艘迅捷且全副武装的舰船，他们依据圣锤修会的情报行动并着手打击星区的各个“热点”，尤其是边缘地带。凭借创纪录的跨星区速度，“正义黎明”号追踪着恶魔的踪迹，并不懈地遏制其后引发的入侵。马里甘特被特别选中来这项任务，因他被奉命为无序之主的天罚，这是由大导师委任授予他的职责。因此，马里甘特誓要追猎这只恶魔，并以神皇之荣耀与战团之荣誉战胜它。这种专注不移曾不止一次让他与卡利西斯秘会成员产生分歧，也使他卷入了多名审判官之间的冲突中心。

# **正义黎明号**

尽管阿斯塔特修会(以及由此延伸的灰骑士)有时会借助帝国海军的服务，但他们也保有自己的舰队。对于一支星际战士战团，这通常包括数艘庞大的战斗驳船、多艘更小更灵活的打击巡洋舰，以及各类辅助护卫舰，使其有能力参与大规模太空战甚至全面的行星入侵。然而，灰骑士却更青睐更小更快的舰船，以便适应他们的任务性质，因其通常需要小规模但快速的反应，所以他们的舰队(驻扎于泰坦上方的阔剑星站)，既有可靠的打击巡洋舰，也有众多其他适合这类任务的虚空船。这些都是全银河中最先进的舰船之一，随时准备将灰骑士送达任何需要之处。

“正义黎明”号便是这样一艘战舰，其规模大致相当于帝国无畏级轻型巡洋舰，但火力和速度却足以应对远大于自身的舰船。它作为灰骑士的集结地运作，携带了足够的装备与武器，使他们远离泰坦也能维持作战数年。正如灰骑士本身，“正义黎明”号也只为单一目的设计：对抗亚空间孽种。因此，它拥有重重防护抵御恶魔袭击，配备了测量物质界与非物质界之间屏障强度的强效装置，并置有封印囚室以关押恶魔俘虏。
