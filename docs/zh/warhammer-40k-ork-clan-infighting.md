# **第十六章**

格鲁提开始理解罗特加德的小伙儿们了。

如果你把他们想作一个兽群那就容易多了。他假定就像史古革，尽管那覆盖了相当多的范围。你有蛇咬们骑乘的大型史古革，还有毛茸茸的小史古革，兽人们用其当头发。然后是那些又大又慢的。还有那种最适合用在一锅迷人炖菜里的。当然那些史古革并不这么想，要说服它们跳进锅里可不容易。通常涉及伤亡。但其余时间呢？它们只是差不多到处闲逛。嚼嚼东西。偶尔互相挡道，发生一点小摩擦，直到其中一个被踩踏得足以避让。

那些高夫是一样的。自从那个大战争军阀向他们下达命令之后，几乎没什么交谈。他们知道战争即将到来，而且似乎对此明显满意。所以现在他们在等着。他曾以为这可能会牵涉更多的打斗，或者一些像在饭堂里那样的调侃和争论。但这些兽人很安静，如果你排除掉古怪的咕哝和偶尔的肠胃胀气，那几乎是无声的。罗特加德认为超出这个范围的任何交谈都是可疑的。

当然，有时一对儿兽人会目光死死对上，像野兽抵角那样。他们会盯着看一段时间，彼此之间逐渐积聚紧张气氛。起初他没注意到，但其他人有。他们为此腾出空间，貌似不假思索，直到两个愤怒的兽人之间再无任何东西。很少会有一方低下目光就此打住。更常见的是，两个都会站起来，阔步向前直至相距几英寸。

然后会来一个头槌。紧接着是一个反击头槌。他们会像那样继续，轮流。随着时间的推移，猛击之间的停顿越来越长。一个兽人甚至可能会跪倒在地，需要片刻时间才能站起来然后发动他的下一次攻击。从来没人扑上去偷袭，或是试图过早地宣布自己是获胜者。受到的打击和给予的打击一样多，都是值得骄傲的事情。而这一直持续到一个小子再也站不起来，瘫倒在地上，失去意识。

对方则会回到自己的座位上。或者有时坐到另一个兽人的座位上，只要它离罗特加德更近。

这是一个好系统。简单。无聊，但简单。而格鲁提开始认为简单就是一种好生活。饭堂*看似*更安全，但那儿总有屁精在伺机推翻他。大概这里的屁精们也有类似的态度，不过他们的高夫主人们不喜欢他们到处乱跑制造麻烦。他误打误撞成了一个高位角色，罗特加德本人的跟班。直到他们抵达战区之前，他已经算是一个屁精能得到的最安全的状态了。

这就是为什么当门缓缓打开时显得如此令人失望。

齐刷刷地，高夫们抬起头望向那个被框在门口的身影。格鲁提想他们的集体凝视一定很吓人，即使是对于一个兽人来说。大概这就是那个身影向后退了一步的原因，眉头紧锁，他的目光从门边扫向聚集的高夫们，其中大多数都从他们的坐处站了起来。罗特加德已经挺直了，手里拿着砍刀。

“你在这儿干什么，血斧？”

那是个血斧。你可以从帽子和厚长大衣，眼罩以及破烂的制服看出来。很少有兽人会穿如此昏暗的东西，这种东西会融入周围的破烂之中，而不是像个真正的兽人那样突兀显眼。提醒你一下，这个血斧看起来并不那么聪明。他没有逃跑，就像格鲁提会做的那样，只是站在那儿，皱着眉头，目光从聚集的人群转向门口。当他说话时，几乎是句耳语。

“可是……俺以为这是血斧地盘？”

“你胆敢声称占有俺们的势力范围！”罗特加德隆隆道，猛冲向前并掐住了这个狂妄之徒的喉咙，将他提了起来。

“不是俺，”那血斧嘟哝道，朝门口点了点头。“俺是影子头目斯利塔，忠于碎骨者和他的Waaagh！议会。但是……别的什么人留下了那个符号……”

罗特加德皱了皱眉，跟随他的目光望去。格鲁提看不见他在瞅啥，在桌子底下不行。但不管是什么，其似乎都让罗特加德感到困惑。当他缓缓放下那名闯入者时，额头上的皱纹加深了，尽管格鲁提不确定这是有意识的选择，还是因为高夫的脑子一次只能专注于一项活动。

“为啥在那里？”他咕哝道。

“大概是巴兹卡特中尉，”斯利塔嘀咕道，揉搓着他的喉咙。“他从来都不高兴那个大战争军阀选俺来加入他的Waaagh！议会。可能是更改了标志来迷惑俺，希望俺会在这里犯愚蠢的错误，然后你会踢烂俺的脑袋。”

“俺特么应该踢烂你的脑袋，就因为你擅自闯入！”

“那正是他所指望的，”血斧回答道。“他不想俺作为战争军阀。告诉过他这是碎骨者的意愿，但他说他不在乎什么碎骨者的命令。说他不过是另一个高夫，而且高夫们太过愚蠢，啥也管不好。”

“你说什么！”罗特加德隆隆道，抓住了他的衣领。

“令人恶心，不是吗？”斯利塔啐道。“俺告诉过他高夫们有多么强硬，罗特加德如何是银河系里最强大的兽人，除了那个大战争军阀之外。他说……好吧，俺不想说。”

“告诉俺！”

“他说你又小又弱不禁风。公平地讲，他没近距离见过你，所以-”

“是吗？好吧，他会的！”罗特加德咆哮道，将斯利塔猛甩出去，然后冲进了走廊。“他在哪儿？”

巴兹卡特中尉正变得越来越不耐烦。

他们本应该在门外塞*监控*的。他现在意识到了。不过他不想将其打开，当他的陷阱被如此小心地铺设时不想。一把棒棒雷被装配在门打开时引爆。两队小子驻扎在两边，他们的突突准备就绪。斯利塔会闯进来，被爆炸震得踉跄，然后被哒咔倒下。但愿，他还能活得足够长，让巴兹卡特幸灾乐祸。当你幸灾乐祸时，一次击杀才更令人满意。

他从来都不喜欢斯利塔。总假装好像他比其他人更优秀。还有那在其他每个人都忙于建立指挥链的混乱事务时，偷偷溜走并躲起来的神经质。恢复秩序。执行纪律。敲碎脑袋。

他们可能在最后那部分上有点过头了。

尽管如此，几乎一半的兽人活了下来，巴兹卡特中尉是现在的头目。玛戈特中士已经被*不光彩地解散*进了一台等离子发生器里，部分原因在于野战列兵莫尔的及时赶到。可能太过及时了，出现在战线后面，然后射杀了玛戈特的部队。一直佯装糊涂，在地板上淌口水。那杂碎比他显露的要聪明得多。

莫尔此刻就在那儿，站在他旁边。他的突突无疑令人印象深刻，多管，弹药带拖在地板上。巴兹卡特对他的表情不太确信，舌头从嘴角耷拉下来，鲜血从他脑袋的伤口渗出。好吧，*伤口*算说轻了 – 锯齿状的疤痕延伸到他的整个头盖骨，好像他的头顶是栓接上去的。

帽子。他应该搞一顶帽子。

当然，一顶帽子会令他看起来有点过于像头目了，而非二把手。可能值得往那个方向也塞几发子弹。就在他杀掉斯利塔之后。

外面有动静。脚步声。它们声音很大，叮当作响。反常，因为斯利塔是个偷偷摸摸的类型。不过，他的抵达来得还不够快，因为小伙儿们已经焦躁不安了。诡诈。巴兹卡特明智地把自己安置在了后面，一面坚固的实心墙护住了他的背后。他可以看到他的小伙儿们交换目光，或是回头越过他们的肩膀望向他。他们正在产生想法，但暴力的前景帮助把这些想法推出了他们的脑海。他们一直等着，一直偷偷摸摸的。现在他们的奖赏即将到来。那道门随时都会被打开。然后砰！

至少，那是他所预期的。奇异的是，那道门另有决定。作为替代，它被从铰链上扯下，然后猛扔进了房间。当棒棒雷引爆时其只飞出去几英尺，那铁门砸进他们队伍的同时，飞溅的弹片泼洒在了他的小子们身上。

片刻间一切都明亮，且喧闹，以及十分烟雾弥漫。他什么也看不见，但那并不重要。门口在烟雾中某个地方。他们只需要足够的哒咔。

“射他！”他吼叫道，举起他自己的手铳并扣压扳机。那把枪有种迷人的后坐力，其熟悉的砰砰声伴随着类似的刺耳嘈杂响动，此时兽人们都将他们的火力对准了曾经那道门所在的位置。并且他们击中了什么东西，从那些撞击和咕哝声判断。还有许多的乒乒声，仿佛子弹在弹开。

奇怪。斯利塔通常不会穿戴他的防弹夹克以外的盔甲。

“好了，够了，”巴兹卡特厉声发令道，他向前推进，仍用手枪瞄准着被烟雾笼罩的门口。“感觉怎么样，你这小矮个儿？以为你极度聪明，试图去巴结碎骨者。但俺才是聪明的那个，而你太愚笨了看不透俺的陷阱。”

有趣。透过烟雾看得见一个影子。他一直以为对方会倒下，可其只是变得更大。或者可能更近。不论是哪一种情况对方都很庞大，就像穿着超重装盔甲。

“你们这帮小畜生！”

那不是斯利塔的声音。斯利塔的声音很轻，滑溜得像一把上足油的戳戳。而这个声音更像是一把锤子。

那暗色的轮廓迈步向前，从正在消散的烟雾中显现。

巴兹卡特僵住了。“哦，卧槽。”

一只装甲爪抓住了他的喉咙，将他撞向墙壁，他的双脚悬空晃荡着。他所面对的那张脸不是斯利塔的。首先其有着巨大、狰狞的长牙，嗜血狂怒的双眼，以及几处渗着血的枪伤。

绝对不是斯利塔。因为，从他眼角的余光，巴兹卡特看到这杂碎从那个笨重兽人的后面走了出来，正咧着一张恐怖的笑容。他去了氏族之外，骗那些愚蠢的高夫替他动手杀戮！这个杂碎！这个讨厌的，精明的杂碎！

“让俺介绍一下自己，”斯利塔说道，向聚集的血斧们点了点头。“俺是斯利塔·大戳戳。俺是Waaagh！议会的成员。俺是碎骨者·玛格·乌鲁克·斯拉卡的影子头目。根据先知的命令，俺们要向加巴尔发动战争。需要一些小伙儿去完成它。有谁感兴趣的？”

巴兹卡特几乎看不见血斧们，他的视线被罗特加德龇牙低吼着的脸挡住了。但他听到了赞成的咆哮，还看到就连那个小不点儿尼比特也向空中挥舞着拳头。如果可以的话，他本也会加入其中。有谁会冒着在大得吓人的高夫战争军阀面前显得不忠的风险呢？

那抓握正在变紧。他必须做点什么。莫尔！他的枪足够大，能在罗特加德身上留下凹痕，或者至少引起他的注意。可那白痴却张大嘴巴站着，口水从他的嘴里往下淌。

“莫尔！”不出声地说道。“动手！干掉他！”

莫尔迎向他的目光。他笑了，慢慢地摇了摇头，然后放低了他的武器。

“听着，”巴兹卡特喘着气道，转回向罗特加德，声音因那铁爪而哽噎。“这不是你想的那样。俺只是-”

“你说俺傻？讲俺不能思考？”

“不！不，俺仅仅-”

“你再也不用思考了！”

巴兹卡特感觉到脑袋周围的抓握更紧了。一股可怕的嘎吱嘎吱的疼痛，一阵骨头破碎的断裂声。然后什么都没有了。
