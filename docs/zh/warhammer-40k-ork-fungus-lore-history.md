先說結論：1999年的三版設定

 歐克獸人是初版行商浪人時期就有的種族，這陣子找資料的時候看到有個說法是其實歐克綠皮最開始的設定是能正常繁殖的，後來才改成真菌生物，這個我就有點好奇，所以開始翻找資料，我們先看看一版的資料，一版關於獸人的背景書有三本：Waaargh: Orks 、 'Ere We Go和Freebooterz，我們三本一本一本找看看。

**Waaargh: Orks**

 一版其實就寫了歐克獸人綠色皮膚的成因是因為與真菌共生所致，智慧小子 ( Brain Boyz ) 將這種綠色引入獸人與地精 / 小鬼頭 ( Gretchin )的基因結構中讓牠們能與真菌共生，藻類賦予獸人厚實、蠟質般的膚質，能抵抗環境侵蝕，讓獸人皮膚強韌而有韌性，隨著獸人年齡增長這層藻類會變得更厚、更粗糙，讓老獸人的外貌更為兇惡，而且獸人有兩顆心臟一顆還兼當消化器官。

 所以一版就有了綠皮膚、史奎格和獸人生態系的概念了，但這時候還沒提到繁衍的設定，另外比較有趣的設定是一版的時候就有了歐格林，而且如果歐克部落先找到沒有加入帝國的歐格林就可能拉這些歐格林入戰幫，這些歐格林對「歐克文明」保持著一種奇特的優越感，其觀點近乎人類並帶著極大的興致觀察歐克的各項活動。

**'Ere We Go**

 這本比較像是補充說明，所以沒甚麼關於生態系或歐克基因的說明，倒是有個有趣設定，一版的血斧氏族甚至可以雇用帝國防衛軍 ( Imperial Guards )，倒反天罡了屬於是。

**Freebooterz**

 這本同樣是補充，主要是講其他氏族和太空獸人的事情，順帶一提恐虐綠皮、渾沌變種綠皮和基因竊取者綠皮都是這本的內容，總之一版的時候已經有歐克獸人的種族劃分，同時確定了牠們是跟真菌共生的生物，但是還沒有提到繁衍方式。

 那我們再往後翻，時間來到1993年的二版，這個版本還帶有點行商浪人時期，畫風和4版相比略顯魔幻，真的有時代的味道，同時這個版本才開始有聖典

 二版的獸人介紹就能看到歐克獸人的社會體系，甚麼小鬼頭、屁精、史奎格都有，而且皮膚已經是綠色的了，血也是綠的，其中帶有一種共生藻類，能透過血管分泌物質來分解並重組受損的組織，甚至重建主要器官，然後二版就寫到獸人是基因武器這點。

 所以二版我們能知道延續一版獸人的共生藻類設定，但還沒看到關於繁殖的部分，而且有提到史奎格始終會隨著綠皮部落出現，但沒有人知道他們從哪裡來的 :P

 1999年的三版的情況就不同了，雖然內容和設定上比起前幾本很少，但後面有兩頁是帝國人員分析歐克獸人的資料，其中就有提到歐克獸人的繁殖方式。

 這邊就直接整理了幾個重點：

 1. 歐克獸人和藻類共生，所以綠皮的再生率快，肢體和器官都能隨意移植，排斥率僅有0.0023%，歐克落後近乎沒有的醫療科技完美適配他們的體能。

 2. 帝國研究後知道歐克獸人是被高度基因改造的倖存種族。

 3. 綠皮的孢子就像人類皮膚細胞那樣是無意識脫落的，但歐克們的鼻子能聞到，從中獲得地位、年齡等多種資訊

 4. 孢子落在合適的環境下時就會進化，一般是需要潮濕黑暗的位置，洞穴和森林是歐克類生物孢子最成功的繁衍地，但即使在最乾旱的條件下也有相當數量的孢子會落在適合發育的地點，歐克類生物一旦達到所需的成熟度並不會單獨出現而是會在短時間內湧現，歐克類生物的藻類細胞包含多種歐克物種的基因鏈，因此單一類型的歐克類生物仍能獨立繁衍出整個社群，所以從獸人、地精、屁精到史奎格都可以從同一個來源產生，在同一區域定居並按比例生長。

 史奎格最先出現且繁殖最快創造了充足的食物來源，隨後屁精迅速跟進並開始整理區域，接著地精抵達為隨後出現的歐克建立一整套繁榮社群鋪路，在孢子著陸後的一年內歐克類生物可能就已輕易地蓬勃發展。

 5. 歐克類生物在生命週期的後期會產生更多數量的孢子，並在死亡後進行最後的大量釋放，如果研究正確那代表舊戰場和從歐克手中解放的世界在後期極易受到再次感染。

 6. 孤立的孢子即使落在宜人的環境中通常也只會演化成簡單的真菌，極少數演化成高等歐克類形式並成功孵化的個體通常也會在極短的時間內（幾小時而非幾天）枯萎死亡，同時在已有歐克定居點周圍的孢子同樣有這一現象，不知為何綠皮的孢子能確保了殖民過程的均勻擴散。

 7. 處於休眠狀態的歐克類生物幾乎無法探測，僅有一片普通的真菌或藻類生長顯示出異樣，剛出現的歐克類生物幾乎處於最成熟的狀態，類似人類的青少年，在短時間內該歐克類生物將具備成年體的所有特徵，包括說話能力以及對相當複雜的機械和動力程序的理解。技能似乎是被基因工程植入歐克類生物體內的。
