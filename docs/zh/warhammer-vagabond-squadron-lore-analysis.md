# 第一部分

## 第一章

在卡斯（Cass）和欧洛夫（Orlov ）前往苏申宫（Suchen Palace）的路上经过时，四名士兵正被鞭打。

他们是海尔坎（Hyrkan）人，而他们的同伴在被迫观看。该营，大约有四百人，在围绕着阅兵广场的三面以两排列队着。他们都穿着全套装备，在执行着惩罚的下午的炎热中明显被热得难受。三只脚的框架由海尔坎中士携带的礼仪式警棍的柄部制成，然后罪犯被剥去上身的制服，并从手腕处系在身上。

营里的传令兵（drummer boy）用电击连枷（electro-flails）执行着判决。每一次击打时那刺耳的噼啪声像刀子一样划破潮湿的空气。四人裸露的背部已经红肿。

“感谢王座，海军不鞭打飞行员，”欧洛夫对卡斯说。

“我们太有价值了，”她回应，病态的好奇攫住了她的注意力，她和欧洛夫绕过阅兵敞开的边缘穿行，朝后面的宫殿主门走去。

一名海尔坎中士喊出每次抽打时的次数。在他旁边，该团的高级政委正注视着，确保传令兵们没有对他们的战友手下留情，或者他们的手臂也没有开始疲劳。还有几名初级政委像黑衣的掠食者般，在围观的营队的前排来回逡巡，审视着士兵们的面孔。他们一边确保没有人移开视线，一边寻找着任何投向自己或团军官的恶意目光。

有罪的四个人都被分配了皮革咬片用来咬住，但其中一人弄掉了，于是在每一次颤栗的鞭打时，都开始哭嚎起来。卡斯看到几个旁观者皱眉。她很好奇他们被判了多少鞭刑。

“我好奇他们做了什么，”欧洛夫沉思道。

“可能是用错误的方式系了鞋带，”卡斯说。

其中一名初级政委看着他们。卡斯与他对视，直到他们绕过紧挨着大门前面的列队后方。

门口有两名暴风忠嗣守卫着，是身穿阿尔菲克九头蛇（Alphic Hydras）的红色甲壳甲的大块头。他们检查了两名飞行员的身份牌，然后敲了入口两下。伴随着生锈的吱吱声，沉重的门开始分开。卡斯和欧洛夫走了进去，把刺耳的噼啪声和痛苦的哭喊留在身后。

苏申宫曾是高沙莱格（High Charag）的官邸，这是授予卡奈三号星的帝国指挥官的当地头衔。它只是分布在伊斋河谷（Eji Valley）的众多皇室住所之一。几个世纪前，这颗星球的统治者会花时间在各地之间巡回，监督着帝国权威的落实。如今，像苏申这样的宫殿已成过去的时代的遗迹，近百年无人居住。

直到防卫军的到来。

宫殿建筑群的周围有围墙，在主宅前方是一个内院，较低的次翼与三翼建筑分列两侧。墙壁曾经是白色的，但因岁月而剥落和变色。尤其是屋顶，看起来是曾经辉煌非凡的由大范围的多层红瓷砖组成的五格棱角结构，尽管许多层已经缺失，并且在裂缝中竖起了鸟巢。皇室轮廓的残余被安装在上面的一根通讯桅杆和一个预兆盘进一步打破。

不过，这一切仍带着某种褪色的宏伟感。某种意义上，这让卡斯想起了她家乡，在帝皇级战列舰（Emperor-class battleship）*神圣训令（Mandatum Divinum）*上的某些地方。

庭院中央被一座精致的石制喷泉所占据，雕刻如九头龙。卡斯猜想，曾经会有水会从它每一个张开的嘴里喷涌而出，但水早已干涸，水盆也裂开，并在阳光下炙烤着。那尊兽形雕像依旧在庭院中凝视着，带着永恒的石头的和解。两名防卫军的参谋官正懒散的坐在旁边，共享着一根烟棍（lho-stick）。两人几乎没去看刚过来的人。

卡斯和欧洛夫在前往中央建筑的路上经过他们。外面的热量酷热的让卡斯的深蓝色飞行服糊在身体上，但在院子里，气氛令人窒息。强烈的温度容易引发偏头痛，她能感觉到太阳穴和眼后开始隐隐作痛。自近两年前的入侵开始以来一直在星球上作战的飞行员表示，随着雨季的到来，天气本应转为潮热，但目前还没有任何迹象。上一次降水已经是泰拉标准日历的一个多月前。很适合飞行，但不适合存在，至少不是在能享受空气再循环机（air recyc）的驾驶舱或居住点隧道的外面。

另一名忠嗣守在主门口，但在他们穿过时只是用眼盯着两名海军军官。里面几乎没有任何缓解——一台仅有的断断续续的再循环机单元，看起来像是从轨道上某个飞船的舱房里拆下来的，正被安置在门口内侧，努力让这个空间感觉上能不太像个熔炉。卡斯强忍着没有在它的前面逗留。

苏申的入口大厅与外观相符，剥落的墙壁，和散落着破碎的灰泥和害虫粪便的瓷砖地板。几幅旧的挂毯还挂在上面，展示着夹杂着卡奈神话中的野兽的狩猎场景，已经褪色到几乎难以辨认。

周围没有其他人在场，并且——除了空气再循环机的喘息声——两名飞行员在裸露地面上匆匆脚步声之外，似乎只有在卡奈这片地区无处不在的细长昆虫嗡嗡作响。

欧洛夫在前面带路，他们登上了大厅尽头的双层楼梯，然后右转沿平台走。他们经过几个房间，前往东翼。门都被加固的防弹板取代，但大多数都被放到一边，让进出门可以畅通无阻。曾经任何精美家具或者接待贵宾的王室贵族如今都已不复存在，取而代之的是堆积成山的印有军务部印章的箱子，由几位穿袍子的文员默默的在数据板上盘点着库存。在卡斯和欧洛夫经过时，没有人从他们的工作上抬起头。

一名男子在东翼门口等着他们，满脸通红，且身穿的橄榄绿色参谋部制服已经汗流浃背。他向欧洛夫敬礼并自我介绍。

“联队指挥官（Wing Commander）欧洛夫，我叫拉斯克中尉（Lieutenant Rask）。哈瓦利中将（Lieutenant General Haval）在等你。”

“那你带路吧，”欧洛夫说着回敬了敬礼。“我可不想让将军久等。”

拉斯克带他们穿过另一条走廊。在这里，宫殿丢开了王室的荒废与破败气息。他们现在经过的房间里，帝国战争机器的指挥单元的匆忙正交织在一起。信号操作员坐在吱吱叫的交流中心的通讯库前工作，而卡斯则在一个战略室里捕捉到了个简报活动，瞥见高级军官们围着全息场的绿色光芒聚集一间被百叶窗挡住光的房间里。他们经过更多匆忙的工作人员和助手，手里拿着一叠叠文件或写着战术和战略读数、点名表、信息小册子和每日命令的数据板。伊斋河谷或许只是卡奈的三个战线中的第三顺位，但苏申宫总部仍负责统筹协调超过四十多万星界军的男女士兵。

而卡斯正被带入了这一切的核心。在从巴杜克空军基地西部（Barduk Airbase West）出发的路上，她曾试图审问欧洛夫，她的联队指挥官兼直接上司，但他辩称自己一无所知。他唯一声称知道的是来自哈瓦利将军的召唤与中央集团军（Army Group Centre）有关。光是这点就对卡斯来说听起来很糟糕。

他们来到走廊尽头的一扇加固的门口，门口由另一名忠嗣守卫，他点头示意他们通过。拉斯克带他们进屋，然后在他们身后关上门。走廊里的喧闹声突然被切断。

卡斯以前曾见过哈瓦利中将，但只是在高层的简报会上简略的见过面，并且从未在她猜测是他的私人办公室里见过。任何曾经在屋子里的旧家具都被移除，取而代之的是帝国防卫军熟悉的实用型家具。房间远端有一张沉重的指挥桌，内置了为镶有纯洁印记的微型全息显示屏供电的发电机，桌子正对着一排卡斯认为是通向内院的窗户，但大部分窗户已被防弹板和沙袋遮住。一张巨大的地图占满了右侧的墙上，详细标示了伊斋河谷及贯穿其中的大河，以及位于河谷东西两侧高原上的两个蔓延的人口中心——乌申（Ushen）和托尔城（Torr City）。地图上布满了不同颜色的图钉，卡斯的目光本能的被吸引到自己所在位置以北——河谷更远处的对岸的那一小簇蓝色标记上，停留了片刻。中央集团军，被切断在伊斋河以北。

房间里已经有三个人影在等着他们。其中一个是像拉斯克一样的工作人员，徘徊在一旁。另一位是哈瓦利中将，站在指挥台后面。他来自塔兰（Tallarn），仍穿着一名高级别的沙漠突袭者（Desert Raider）的制服，一件袖子宽松的尘土黄的沙漠罩衫，头戴浅蓝色*的舍玛（shemagh）*头巾。他的身体结实，但开始变得肥胖。他留着一撮油亮的无可挑剔的白胡子，与他黝黑的脸庞和在左脸颊蔓延的鲜活的粉红疤痕形成鲜明对比。

房间里的第三个人是空军中将贾凯拉（Air Marshal Jakyra），依旧和平时一样憔悴且面无笑意。她一直面对墙上的地图站着，双手背在身后，但当卡斯和欧洛夫进来时，她转过身。

一看到她，卡斯的心情就骤然沉落。如果整个帝国海军航空兵（Aeronautica Imperialis）在卡奈三号星的指挥官被从*神圣训令*上的战略室被叫了下来，那意味着任何他们即将参与的事情都已经远超严重了。

“欢迎，欢迎，”哈瓦利友好的说，回敬他们的敬礼。“放轻松。很高兴再次见到你，联队指挥官。这位一定是卡桑德拉·埃尔扎（Cassandra Elza）上尉。我认出你了。”

“从上次的常规简报吗，长官？”卡斯问道。

“而且因为我把了解自己指挥的部队都是谁当做我的职责，尤其是像流浪者这样有功勋的部队。”

卡斯露出一个微笑，但什么也没说。她离开巴杜克西部并不是来寒暄的，但哈瓦利出了名的喜欢给命令裹上一层人情味。

但贾凯拉就不一样了。卡斯在将军讲话时感受到了她的目光，但拒绝与她对视。现在不是对峙的时候。

“空军中将贾凯拉告诉我，你们的中队还在整修中，在乌申那场惨败之后，”哈瓦利说。“一件糟糕的事。你们损失了一架战机，对吧？”

“是的，长官，”卡斯说，想谈点除了乌申插入以外的话题。“但我们快恢复了。整修进展顺利，我的机组们也渴望行动。再过四十八个标准小时，我的中队工程先知告诉我，他的最后的修复祝福（repair-benedictions）就将完成。”

“你可能没那么多时间了，队长，”贾凯拉站在地图前说道。

卡斯终于与她对视。她身材高挑，面容清癯，其实与卡斯颇为相似——据说她们是非常远房的表亲，这在*神圣训令*的飞行员行列中并不罕见。她身穿全套的空军中将制服，一件着深蓝色夹克，白色衬里，带着锁甲样式的肩章，胸前别着帝国海军航空兵的金色徽章——一只展翅的、风格化的“AI”字样。她一定得热得要命，虽然她除了脸颊微微泛红外，没有表现出任何异常。

“我们一如既往的听从你的调遣，空军中将，”卡斯对她说，然后又看向哈瓦利。将军温暖的微笑着。

“这只是流浪者中队为什么保持它获得的名声的原因之一，”他说。“而你们的飞行员们将获得他们渴望的任务！”

将军从办公桌后走出来，站到贾凯拉旁边，到了地图前面，而卡斯则努力不去想她刚才说的几乎所有话都是谎言。

“你知道中央战斗群目前面临的情况吗？”他问道。

“大致上，是的，”卡斯回答，用她从一生的简报交流中学到的简短且简明的语气。“在伊斋河谷开辟第三战线以分散兽人对占领的乌申和托尔城的兵力的尝试已被停止。中央集团军目前被切断，被包围在伊斋河以北。除此之外，我对最近的战术的发展不太了解。”

“战略员（Strategos）估计，中央集团军将在下周内被击败，最晚。”哈瓦利说，他的语气变得阴沉。他指了指卡斯注意到的已经在地图上标记出的那一堆绝望的蓝色图钉。它们被一片绿色的海洋包围，伊斋河在它们背后。

“没有可行的渡口吗？”卡斯问道。“没办法让他们过河吗？”

“全部被摧毁了，主要是通过空袭。兽人的空中存在非常强大，正如你清楚知道的。唯一正面的是中央集团军的抵抗正在从城市中吸引出异形的军力，但我本希望能在不出现近二十万兵力和战争机器的毁灭的情况下实现这一点。遗憾的是，这正是我们现在面临的现实。”

卡斯很想问是否真的没有希望去发起进攻，然后把被困的军团救出来，但她还是闭了嘴。这不是她的职责，况且，哈瓦利肯定早就考虑过这样的行动了。不管为何，这似乎是不可能的。

“这是件糟糕的事，长官，”卡斯转而说，心知这根本不足以道尽其中万一。

“它是的，而我将要你加入其中，上尉，”哈瓦利说。

这正是卡斯一直害怕的时刻。她保持她表情的镇定，目光注视着将军，尽管她觉得自己内心逐渐变得冰冷，并且她的双手在背后逐渐紧握。

“我已经和高级助理以及空军中将谈过了，而我们一致同意对口袋阵地内的空投将具备战略价值，”哈瓦利说，语气更像是简报式的，因为说出了他显然知道卡斯不会喜欢的话。“流浪者中队尤其是最佳选择。我们会安排体面的空中掩护送你们进去。一个简单的投递并收集（drop-and-collect），快进快出。如果你们明天早上出发，你们将在当地时间午夜前回到巴杜克西部。”

“我明白了，长官，”卡斯回答，试图但未能掩饰住声音中的冷漠。“我们只部署流浪者中队和我们的空中掩护？”

“是的，”哈瓦利说，然后在她开口问出前就回答了显而易见的问题。“现在，你可能在想，由一个瓦尔基里中队执行的一次补给不足以维持口袋阵地的完整，而你说得没错。恐怕中央集团军面临的问题不仅仅是后勤问题。但一个像流浪者这样的精英部队被看到为我们陷入困境的士兵提供援助，并拍照下来出现几张漂亮的照片——这本身就有其价值，无论是对那里的士兵还是这里的士兵。我相信你明白士气的重要性，尤其是在这种时候。我们不能被看到抛弃了河对岸的部队。”

*即使你在抛弃他们，你这个冷酷的混蛋，*卡斯心想。她回想起在外面发生的鞭打，发现自己在好奇那些人会怎么评价士气。

“我们有着陆区坐标，一个飞行计划吗？”她问，试图把怒气发泄到作战细节上。“补给清单？燃料和弹药通行证？中央集团军的最新呼号和数据握手？”

“这些将在接下来的几个小时内供应，”贾凯拉补充道。

“谁负责提供上空掩护？”

“来自911联队的比克斯（Bix）的雷霆（Thunderbolts），云骑士（the Cloud Knights）。”

“你给她简报了吗？”

“我们说话的时候她应该正在赶来的路上。”

卡斯用了一会控制住自己，然后爆发了。也许察觉到她的自律外壳有多接近到要崩溃，哈瓦利又开始说话。

“上尉，你可能会松一口气，这次任务不只是个宣传活动。我还有第二套命令，一个不会出现在你标记的指示里的目标，但应该被当做和卸载物资一样的重要。”

哈瓦利向他的助手挥手，助手匆匆走过来并递给他一块数据板。卡斯做好了心理准备。他们现在还能要求她做什么疯狂的事？

她拿起数据板，读了一遍，然后又重新读了一遍。

它比她害怕的事情还要糟糕。她感到一阵纯粹的厌恶涌上心头。

“这些指示清楚吗，上尉？”哈瓦利小心翼翼的问。

“我想是的，长官，”卡斯说，几乎勉强咽下了厌恶。

“你要让他们明白，这些命令直接来自中央指挥部，”哈瓦利说。“他们必须服从。这些不仅仅是我的指示。这里还有其他力量在起作用。”

“我是否应该把这些命令当作真正让我的中队被派往伊斋对岸的理由？长官。”

“是的，队长。它们也必须保持绝对的机密，暗红色代码。保留那块数据板，以备在你需要时用它证明你拥有我全部授权，但在时机到来之前，你不能与任何人分享。这同样适用于你的机组。你在着陆前将不会告诉他们这些指示。在他们看来，你唯一的目标就是投放补给，并且被看到在做那些事。”

“我明白了，”卡斯说着，把数据板塞进飞行服里。

她还想说更多。她想告诉将军他是个傻瓜，也想告诉贾凯拉她会害死他们所有人。她想为他们的懦弱去诅咒他们。她想问他们，当关键时刻来临时，她该如何告诉她的机组们，他们真正去那里是为了什么，他们真正冒着生命危险去做什么。

她想求他们不要去，不要把她派出去。不是再一次。

她反而敬了个礼。

“我们会办成的，长官，”她说。

“这就是我召唤流浪者中队的原因，”哈瓦利说，脸上满是松了口气的笑意。“贾凯拉会确保今晚前将完整的简报资料送到巴杜克的你们的分区。还有其他问题吗？”

“没有，长官。”

“那你可以解散了。愿神皇保佑你前行，艾尔扎上尉。”

“贾凯拉想害我死，”卡斯毒辣的说着，大步走回宫殿内院，欧洛夫跟在后面。“她大概是自己想出的这整个愚蠢的计划。”

“我很怀疑，”欧洛夫说，语气带着和解。“据各方说法，哈瓦利对中央集团军的局势感到心烦意乱，并渴望任何能减轻败绩的痛苦的东西。显然口袋里的情况简直是噩梦。王座，这场攻势已经造成超过十万条生命的代价，而这还只是最初几周的事。这些尝试让人觉得像是在乌申的高层拔掉他的插头前挽回颜面。正如他所说，还有其他力量在起作用。”

他没有明确说明“其他力量”是什么意思，卡斯知道不去逼问他，至少不是在总部这里。

“所以我和我的机组们将要赴死，好让将军演个戏挽回面子。他有没有想过，当他最好的瓦尔基里中队被炸成伊斋河岸边燃烧的废墟时，他在高级指挥官中的形象会受到多大损害？”

欧洛夫一言不发，但卡斯知道他在让她发泄。他从她还是初级侧炮手时开始就是她的联队指挥官，还有任何贾凯拉都不具备的——当他下命令时清晰且深思熟虑，而不是把她和她的飞行员当成防卫军士兵那样给出最后通牒。作为联队最资深的上尉，卡斯比他指挥下的任何人都更亲近他，并且她欣赏他的领导风格。她知道*神圣训令*上的其他联队长觉得他太宽松，但他们并不负责主舰的瓦尔基里。

“为什么不派别人去？”卡斯问他，她的语气依旧炽热。她知道自己不该问这种问题，但在哈瓦利面前对自己的克制之后，她忍不住反击这一切的不公平。“贾凯拉知道在乌申上空发生了什么。才是一周前。她难道没厌倦让我的飞行员们丧命吗？”

“他们特意要求的你，”欧洛夫说。“你知道这些事情是怎么运作的。”

“我知道，”卡斯苦涩的承认。

大门外，海尔坎人正行军离开广场。当他们排队经过时，惩罚游行的受害者被从支架上解下来。其中两人昏迷不醒，而另外两人无法独自站立。他们的背部被打的血肉模糊。

看起来其中一名传令兵也昏倒了，要么是因为高温和劳累，要么是因为他被迫去施加的惩罚的残酷。团政委正用铅笔把笔记写在一个小黑皮本上，站在一旁，看着医疗兵忙着扶起像等待在烈日下被觅食的腐肉一样的倒下的士兵。

“还高兴你是个永远感受不到鞭笞的海军飞行员吗？”欧洛夫带着一丝幽默问道。卡斯皱起眉头。

“我宁愿那样，也不愿为将军的虚荣而死，”她说。“最糟糕的部分将是告诉我的机组。”

“他们现在处于待命状态，不是吗？”欧洛夫问道。

“是的。当他们知道这一切时，我们可能得向海军请愿，只为流浪者中队引入飞行员的鞭刑。”

欧洛夫发出毫无幽默的轻笑。“沃恩上尉肯定会最难受，不是吗？”

“让我来担心豪尔·沃恩，”卡斯阴沉的说。
