# **本文摘选自 Noah Van Nguyen 所著英文小说《Elemental Council》，该译文作为练习仅为个人与交流使用，不用作商业用途**

“有点奇怪啊，” 情报分析员一边说，一边敲了敲界面上的控制器。“档案显示家门上存在着第二位以太。她的位置没有公开。文件访问已被锁定。”

诙谐的钛星语散发着诗韵的涟漪，就像一曲永无止尽的歌谣，在艸呙作战基地的信息舞台上汩汩流淌。我于是问道：“日志里当真什么都没有吗？”

这位蓝皮肤的分析员将身体向后靠了过去，他的袖子显得格外的松垮。他抚摩着宽阔的额头，将未能充分生长的手指卷了起来。“在一份名为'塞拉'的文件里有些东西。它的访问（权限）也被锁住了。”

我对塞拉再熟悉不过了，但让分析员知道这一点，那将会是一个错误。“想要了解这第二位以太，需要多久才能获得许可？”

“我不确信。就算你在回来之前就提出了申请，那也需要加急处理才行。维修网络计时站点的后勤申请让联合军团的行政资源忙得不可开交。当然了，这一点你很清楚。”

往昔的记忆在我眼前一一浮现，加密站的破碎碟形中继器和被热熔炸弹摧毁的天线基座，其中还夹杂着凝化于喉中的苦涩烟雾。我无法想象人类帝国会及时纠正这种情况。然而在艸呙的短暂经历让我明白，只要将意志力应用的足够集中，那么万事皆有可能。

崇晨指挥官冷冷地站在指挥官的廊座上，她双臂交叉，显得威风凛凛。当我们的目光相汇时，她略微颔首，以示敬意。

我于是问道：“也许指挥官能帮帮忙？”

“她似乎确实拥有访问代码。我敢确信，你可以去问问她。她会用打破常规渠道的方式来告诉你。但你们俩在联合军团的议会中都有一席之地。这是你们的特权。”

我亲切地回答道：“我正是这么想的。感激不尽，钋'拉。”

“为了上上善道，菲欧'欧。”

**PS：文中的 “我” 是艸呙联合军团的将作大匠兼土氏的最高领袖菲欧'欧·塔'奥·弗伦'达·法伊斯·丹塔'瓦雅/Fio'o T'au Vren'da Fais Denta'vaya。**
