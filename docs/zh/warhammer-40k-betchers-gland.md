貝徹腺體 ( Betcher's Gland ) 是星際戰士改造手術中的第十七道手術，由兩個完全相同的腺體組成，植入位置可以是在下唇內、唾液腺旁側或是硬顎。

 上圖標出硬顎在哪，這種腺體的運作方式類似於毒蛇的毒腺，能夠合成並儲存致命毒素，而星際戰士本身則對這種毒素具有免疫力，星際戰士能夠吐出一種接觸後可使人失明的毒液，這種毒液同時具有腐蝕性，只要給予足夠的時間甚至能夠腐蝕掉金屬。

 這項功能其實挺微妙的，算是星際戰士各項超人能力裡比較難體現的功能，但是比起其他更冷門的功能（例如能減少輻射傷害的變色皮膚和防高溫防低溫甚至能在真空環境下提供一定防護的體表粘膜）又因為夠特殊所以不少人知道，儘管冷門還是時常被人拿出來說這功能到底要幹嘛。

 老實說酸液口水相較於甚麼超人聽力或超強嗅覺等等功能雖然不容易表現，但小說裡有出現的場合其實不少，至少比甚麼變色皮膚和黏膜來的多，至於為甚麼要加這項功能我也感覺很神奇，屬於是可有可無但莫明有趣的技能，另外我看討論時有人說酸唾液方便消化常人難以食用的食物，這方面的紀錄或資料我是沒找到啦 :P

 設定裡帝國之拳和黯鴉守衛的貝徹腺體已經完全失效，Index Astartes IV寫到黯鴉守衛可能是數千年前採用加速基因採集技術所留下的副作用導致種子劣化，他們的汗腺改進器官 ( Mucranoid ) 和貝徹腺體兩個都自然失效。

 帝國之拳則是貝徹腺體和蘇安腦膜 ( Sus-an Membrane，受重傷會進入假死狀態 ) 兩個功能失效，2023年補充的原因是HH時期為了加速徵兵刻意將這兩道手術延後，後續資料暗示錯誤排序的植入程序可能永久損壞了使這兩個器官運作所需的基因程式。

 理論上這些功能都是在HH時期就已經失效，因此後續拆分的戰團都會缺失，例如四版軍書裡黑色聖堂裡就有說因為是帝拳子團所以這兩個器官失效，這東西屬於一個迷糊仗，一來GW自己亂補設定沒考慮小說，二來現在有了原鑄星際戰士，器官是否缺失介於有與沒有之間，別想太多 :P

 扯遠了，總之這東西在小說裡出現的次數其實比我想像中還多，但平常不可能拿出來用，應該說吐口水這招不管是攻擊距離和傷害都挺幽默的，絕對不像甚麼主動技能到處吐，理論上大家都帶著頭盔的情況下不可能為了吐敵人特別脫頭盔，先別提能和星際戰士近身肉搏的敵人是否會怕酸液，就說這口水怎麼吐到對方吧。

 大部分案例都是在絕境時刻真的退無可退才用這招，銀色顱骨戰團甚至把這招稱為致命咬殺 ( Killing Bite )，小說【靈魂獵人】裡塔洛斯對付刺客時就用這招把刺客弄瞎：

 這名午夜領主一口唾液吐在她臉上，接著猛力將她甩了出去。

 她已經很多年不曾尖叫了，並不是因為疼痛對她而言有多麼陌生，甚至也談不上出乎意料，這一次並不是肢體被俐落地從身軀上斬斷，而是她的雙眼正在眼窩之中溶解，她從未經歷過如此劇烈的痛楚，所有的感官都被徹底吞沒。

 即使身陷劇痛之中她仍想像著那個可恨的午夜領主穿著笨重的動力甲踉蹌退開，正因她這一瞬間的無助而暗自得意，她猜對了，在黑暗之中塔洛斯愉悅地品味著她的尖叫聲，更為甜美的則是酸性毒液侵蝕她那雙美麗藍眼中的柔軟組織時所發出的細微而悅耳嘶嘶聲。

 另一個案例則是出自小說背叛者，吞世者的藥劑師卡格斯 ( Kargos ) 在競技場裡時常用口水噴人，因此得到了濺血者 ( Bloodspitter ) 的名號。

 小說『The Purging of Kadillus』裡暗黑天使的審訊牧師玻瑞阿斯也用過這招：

 玻瑞阿斯朝獸人臉上啐了一口，這並非毫無意義的挑釁，星際戰士的唾液中摻雜著來自舌下貝徹腺體的酸性化合物，獸人猛地後退，皮膚灼痛起泡。

 HH小說『Pharos』裡極限戰士的新兵 ( 後來成為帝皇之鐮首任戰團長 ) 奧伯戴伊 ( Oberdeii ) 和機僕對練差點被反殺時也用過這招：

 他的喉嚨緊縮閉合，為了保存氧氣他的生理機能開始全力運作，機僕發出咆哮，宣洩著程式所賦予的狂怒。

 奧伯戴伊的血管根根暴起，臉龐漲得通紅，他感覺自己的眼球彷彿隨時都會爆裂，情急之下他朝機僕的臉上吐了一口唾液，這一口吐得並不好——由於喉嚨緊縮，他無法有效地擠壓貝徹腺體分泌毒液，也無法將腺體產生的毒液有力地噴射出去，酸液只能化作一片四散飛濺的液霧，噴到了機僕臉上。

 機僕頓時失明，踉蹌著向後退去。

 最後是鋼鐵之蛇 ( Iron Snakes ) 戰團的普里亞德（Priad），小說『Brothers of the Snake』裡中段普里亞德訓練新兵時被毒蛇咬到，結果他的身體把毒液存在貝徹腺體裡：

 接著那股灼燒般的不適逐漸緩和，疼痛消退了，傷勢留下的唯一痕跡只剩下他腿上的結痂組織以及硬顎內腫脹的貝徹腺體，他高度精密的身體系統並沒有將致命毒素中和，反而將其捕捉起來送往口腔中的腺體內儲存。

 這是個好兆頭，至少在一段時間內，這名鋼鐵之蛇戰鬥兄弟也能像自己戰團之名所指的蛇一樣，以咬噬注入毒液，按照戰團的慣例他們並不會主動練習如何使用這些腺體，他們認為這種手段怯懦且粗鄙不堪，然而如果因為某種意外而獲得了使用它們的機會，那就會被視為神皇賜下的祝福。

 被蛇咬傷而中毒被認為是一件幸運之事，是一種極其特殊的吉兆，也是戰團兄弟會中每一名成員都渴望得到的徵兆。

 還沒結束，後來他遇上暗黑靈族的執政官，在近戰中處於劣勢身負重傷被壓制在地，直到他想起了毒液，等到對方炫耀摘下頭盔時來個絕地反擊：

 初族領主單手握矛繼續死死壓制住他的閃電爪，同時抽出一柄咬刃匕首準備給普里亞德致命一擊，那對並列的刀刃高高舉起。

 就在最後一刻普里亞德想起了自己得到的那份祝福，當初在賽迪德斯地峽獲得那個幸運吉兆，蛇毒至今仍儲存在他的體內，他現在就是一條準備出擊的毒蛇。

 他收緊位於硬顎中的貝徹腺體，那裡正儲存著綠背蝰蛇的毒素，接著猛然一口將毒液吐進初族領主的雙眼，初族領主發出淒厲的慘叫踉蹌著向後退去，雙手瘋狂抓扯著自己的面具。

 總之這招比想像中來的有用，但多數情況下只是打個措手不及，星際戰士彼此纏鬥用這招就很難有效果，拿去吐敵人倒是有奇效，誰能想到打到一半會有人吐一坨硫酸出來。

 幽默的話也是有幾個橋段，例如小說【Prince of Crows】最後面賽維塔和一群午夜領主被暗黑天使抓住時的段落：

 他們最初把他扔進去的牢房，是一座相當傳統以強化鋼鐵打造的囚牢，賽維塔只花了不到十五分鐘就靠著酸性唾液將其中一面牆腐蝕溶穿。

 當一名守衛前來查看他的情況時他只是伸手指了指牆上那個仍不斷發出嘶嘶聲的洞，那個洞已經大到幾乎足以讓他整個人鑽過去了。

 「我猜是老鼠幹的，」他說，「很大的那種。」

 暗黑天使把他從那間牢房轉移出去，將他和幾名戰鬥兄弟一起扔進了一座力場牢籠裡，很顯然他那些兄弟也都跟他一樣，都把各自原本的牢房給毀了。

 小說【Blood Gorgons】裡也有類似的橋段，渾沌戰幫鮮血戈爾貢 ( Blood Gorgons ) 的成員巴薩巴斯被抓住時同樣用口水來處理鎖鏈：

 巴薩巴斯掛著認命的表情，開始用牙齒啃咬綁在手腕上的鎖鏈。

 那是由粗重的工業用鐵環連成的鎖鏈，一開始冰冷金屬撞上牙齒所帶來的衝擊令他心頭一驚，但他強忍疼痛繼續用力啃咬著金屬，星際戰士的牙齒雖然厚重且高度鈣化，能夠咀嚼那些常人難以消化的蛋白質與纖維，但終究還是咬不動鋼鐵。

 等到他那高度鈣化的琺瑯質開始迸裂時巴薩巴斯的口腔早已幾乎失去了知覺，他開始大量分泌唾液，任由貝徹腺體在啃咬過程中不斷淌出酸性黏液，他凶狠地撕咬著手腕上的鐵環。

 終於，被酸液腐蝕軟化的金屬「啪」的一聲斷裂，但他剩下的臼齒也全部崩裂了。

 小說【Storm of Damocles】的橋段也挺幽默的，死亡守望的利奧納斯被鈦星人抓住，加入鈦帝國的人類前來審訊並勸降他：

 「帶回哪裡？」

 「到時候你就知道了。」

 利奧納斯笑了起來，儘管這讓他痛得厲害，甚至令鮮血從嘴裡湧出，「瞧瞧妳害我變成什麼樣子了。」他說著，吃力地想抬起一隻手擦去嘴邊的血。

 「你會理解的，」她說，「否則我們就只能把你交出去。」

 「交給誰？」

 「交給其他人，」她說，「我們已經取得了優先處置你的權利，但還有其他人，他們更年輕也更加莽撞，他們也想找機會親自對付你，他們可不會像我們這麼客氣，如果你願意順從一切都會簡單得多。」

 聽到「順從」這個詞，利奧納斯直接朝她吐了一口唾液。

 酸液正中她的整張臉，她頓時放聲慘叫，踉蹌著向後退去。

 小說【Broken Sword】裡有幾乎一模一樣的橋段，同樣是星際戰士被鈦星人抓住，同樣是被投靠鈦星人的人類審訊，只是這次的角色換成了前審判官審訊黯鴉守衛：

 那名叛變的審判官伸手探向我的頭盔，我猛力左右扭動，但他死死抓住我，手指迅速按下隱藏的卡榫，解除了頭盔的鎖定密封裝置發出一聲嘶響，失去頭盔的隔絕後燃燒與焦肉的氣味頓時以最濃烈的程度撲鼻而來，接著他將我的頭盔完全取下，以審視評估的目光低頭打量著我。

 如果我的動作能夠再快一點我就能扭斷他的脖子，我試著抗衡那些制伏我的人的力量，卻依然無法起身。

 如果黯鴉守衛的基因庫中至今仍完整保有帝皇所賜予的全套恩賜，那麼我現在就會朝他的臉上吐出毒液，但我沒有貝徹腺體。

 我的一些戰鬥兄弟確實擁有這個器官，他們是以其他戰團向泰拉繳納的基因種子什一稅所培育出來的（譯者註：這個我就不懂了，非黯鴉戰團的種子拿來給黯鴉用？）但我屬於血統更加純正的一類；在我的基因之中融合了更高比例源自科拉克斯本人的遺傳物質，為了這份獨特的榮耀，我所付出的代價就是某些能力上的缺失。

 這是我有生以來，唯一一次為自己缺少這個器官而感到後悔。

 最後一個則是小說【Spear of the emperor】，阿瑪迪斯受了重傷只能躺在手術台上靜養，他的侍從在一旁照顧他：

 「主人，您受傷了，傷得很重。」

 「我的嘴，」他說，「能替我擦一下嗎？」

 在我的記憶中這還是第一次他用近乎疑問的語氣下達命令，我照他的話去做，用一塊無菌布擦拭他的嘴角，接住一小股從唇邊淌下的帶血唾液。

 布料頓時發出嘶嘶聲並冒起煙來，一陣火燒般的劇痛猛然竄過我的指尖，我咒罵了一聲失手丟下那塊布。三根指尖已經開始流血。

 「唔……原諒我。」阿瑪迪斯說道，他用舌頭探觸著口腔深處，同時因疼痛而皺起了臉，「我不知道自己的唾液裡混入了酸液，我控制不了我的貝徹腺體。」

 他始終注視著我，看著我用清潔溶液沖洗自己剛添上的傷口，技術上來說這應該算友軍誤傷。

 總之大概是這樣，說沒用也不是沒用，只能說確實是非必要功能，但不得不說危及時刻有奇效
