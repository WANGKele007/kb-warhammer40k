想做這主題是因為一直很有興趣，前陣子在reddit上看到一篇寫得很詳細的文章，從初版開始分析四神與亞空間的設定，總之我先講我自己搜到的簡單資料拿出來分享，沒有對錯，算是一個新的討論，算是我個人的精簡版。

 首先我們先來說說，到底甚麼是亞空間？ 

 這邊引用八版渾沌惡魔的軍書內容，亞空間是由凡人翻騰的情感具現化而成的抽象存在，它不受時空法則束縛，是一片由純粹能量與無定意識構成的混沌景象，永遠在無限可能中變動，在亞空間中相似的思想與情感會像水流沿著峭壁匯集，它們形成痛苦與慾望的溪流、仇恨的漩渦與驕傲的洪流，自時間之初起，這些潮汐與波浪便不斷流動於亞空間這個鏡像領域之中，而其力量之強甚至孕育出由非現實本質構成的存在。

 最終這些本能而無形的存在獲得了初步的意識，混沌諸神由此誕生——由凡人的激情與恐懼構成的巨大靈能存在，祂們即為毀滅之力，每一位都是塑造祂們的情感的映照。

 到這裡我們知道，情感能影響亞空間，正是人們 ( 應該說生物們 ) 的相似情緒在亞空間匯聚，最終孕育出了混沌諸神，隨著不斷增長的情感洪流滋養了混沌諸神使祂們的力量日益壯大，四神各自有自己代表的情緒，這邊統一用八版的軍書內容：

 恐虐是憤怒之主，顱骨的收割者。他是憤怒的化身，是無止境支配與毀滅衝動的具現，恐虐的要求很簡單：鮮血，還有更多鮮血，每一條因憤怒而奪走的生命都會增強血神的力量，他甚至青睞那些屠殺同袍的戰士，因為他們理解了一個更高的真理——恐虐不在乎血來自何方，只在乎是否流下。

 納垢是偉大的腐化者，是瘟疫與疾病之主，是腐敗本身的源泉與建築者。他體現了一個真理：無論事物看似多麼堅固與永恆，都終將走向衰敗，而創造的過程本身，也只是毀滅的開端，儘管他創造了宇宙中所有曾經肆虐的感染與疫病，納垢並非一個陰鬱的死亡與苦難散播者，而是一位充滿活力、象徵生命與歡笑的神祇。生命源於腐敗。重生源自腐壞，正如希望誕生於絕望；最偉大的啟發往往來自最黑暗的時刻，在危機之中，凡人才會真正受到考驗並被迫超越自我。納垢正部分體現了這種認知與人們對其的無意識反應。他是對疾病與腐敗的潛藏恐懼，是死亡不可避免的現實，也是由此激發出的反抗意志。

 奸奇是宇宙中的操縱者；他以所有生命對變化的需求與渴望為食，大多數凡人都夢想著繁榮、自由與更美好的未來，這些幻想並非只有貧困或無力之人所有——即便是行星總督與艦隊上將也會夢想更多財富或渴望擺脫自身的責任，所有這些夢想都構成了強大的變革動力，而國家的野心更能形成改變歷史的力量，奸奇正是這股力量的化身。

 色孽是歡愉之主，是一位致力於追求世俗享樂並顛覆一切端正行為的黑暗神祇。他是執念之神，是萬事無度的主宰 ( the Master of Excess in All Things ) ，從暴食到色慾，再到自大狂妄。凡人只要被自身無法滿足的欲望所支配，黑暗王子便潛伏於陰影之中，低語、誘惑，並享用靈魂的盛宴。

 其中色孽是比較容易被忽略的一神，比起慾望更重要的是過量無度，這點後面會說明要記好 :P

 不過怎樣的情緒才能夠滋養混沌四神呢，這裡我找了兩個例子，第一個是惡兆方舟：安格隆 ( arks of omen angron ) 裡的八個小故事，說明了怎樣的行為能夠滋養恐虐，可以當成一個參考依據：

 他們為榮耀而出擊。

 在一座自異星叢林中升起、被風暴拍打的階梯金字塔頂端，一名機械霸主 ( android overlord ) 揮動著發光的刀刃，他那身披金甲的敵人身首異處，無力地翻滾著從階梯上墜落，就在此時，霸主的追隨者為這場又一次不可避免的勝利高聲讚頌。

 他們為自由的希望而出擊。

 監工再次揚起鞭子，但這一次，勞役奴隸88-雙4已做好準備，她用另一隻手抓住那瘦削監工的手腕，將臨時製作的尖刺武器猛力刺入他的下顎，起義就此開始。

 他們因仇恨而出擊。

 幫派中已有三人死亡，執法者用霰彈槍將他們逐一冷血處決，但他沒能解決戈夫，而現在他正仰躺在排污的骯髒泥水中，被雨水沖刷著，戈夫騎壓在他的胸口，透過破碎的面罩，執法者與戈夫四目相對，神情毫無悔意，伴隨著失去同伴與痛苦的怒吼，戈夫雙手高舉短斧，狠狠劈下，將斧刃深深嵌入執法者的臉中。

 他們以殺戮者之姿出擊。

 在塞克・梅格拉的一條陰暗後巷中，一名披著斗篷的身影匆匆前行，肩膀因遠方傳來的尖叫與槍聲而緊縮，他沒有注意到門口潛伏的癮君子，但當刀刃劃開他的喉嚨時他感覺到了，他接著感覺到對方的手在翻找他的口袋，接下來他再也感覺不到任何事物。

 他們出於職責而出擊。

 艾因希爾爐衛知道，她的攻擊必須精準到分毫不差，那名墮落者的目標不是她，而是她所守護的格林尼爾，但他絕不可能傷害到這位活祖，敵人裝甲伺服器的低鳴聲暴露了他的行蹤，他突然自陰影中撲出，猩紅的目鏡閃耀，但她早已準備就緒，她的震擊護拳重擊在對方胸甲上，將陶鋼、融合的骨骼以及那對毒性心臟一同粉碎。

 他們在憤怒中出擊。

 鬥坑中的混戰持續已久、傷痕累累，但最終挑戰者倒在血泊之中、全身破碎，為了徹底發洩對這名挑釁者的怒火，歐克獸人雙手舉起巨石，猛然砸向敵人的頭顱。

 他們為復仇而出擊。

 一名野性戰士無視四周舞動的亞空間火焰，舉起帶著寒霜色澤的戰斧，猛然劈向死敵的頸部。當巫師戴著頭盔的頭顱滾落地面時，殺手發出毫無悔意的狂喜吶喊：「為了芬里斯！」

 他們懷著信仰而出擊

 恐懼無法阻止她的憤怒，她在忠誠士兵的人群中奔跑高聲讚頌神皇，並將雷射槍射向叛徒的隊列，她衝上泥濘的坡地直撲敵陣，緊跟著年邁的牧師約西亞，一名叛徒舉起自動槍瞄準她，但為時已晚，「為了帝皇！」她怒吼著，將刺刀深深刺入異端者的胸膛。

 上述八個例子可以看到，你的目的不重要，哪怕你為了帝皇殺人恐虐還是會獲得能量，因為重點是情緒，甚至不用是人類甚至不需要感到憤怒，任何有情緒的生物都能影響亞空間，只要流了血恐虐就能獲得力量，比較有趣的是第一個不確定是不是死靈族的霸主砍了禁軍 ( 畢竟寫的是安卓霸主 )，如果是的話那真的挺猛的，各方面來說都是。

 第二個則是小說【Fabius Bile: Manflayer】裡帝皇之子奎茵 ( Quin ) 和法比烏斯．拜爾之間的對話，出自第十九章的前段：

 「不，你根本沒在聽。」奎因向前傾身。

 「在我的朝聖之旅中我學到了很多，無論輸贏，諸神都會以我們的行為為食，一個人撫摸一隻流浪動物，他那點善意帶來的愉悅滋養了色孽；一個女人打了哭泣的孩子，她那可怕的快感滋養了恐虐、一個軍需官考慮自殺，納垢則以他的絕望為食。」

 「一位仁慈的戰略家製定了不流血的勝利計劃，奸奇對此很滿意。」他抬頭望向天空，一片灰濛濛的，毫無生機， 「懷言者以為諸神渴望崇拜，但諸神除了用我們的悲傷填飽肚子之外什麼都不關心，無論有意無意，我們都成了野獸的獵物。」

 這個段落裡我們也能看到做事的目的並不是重點，任何行動所產生的情緒就足以滋養四神了，哪怕你摸個流浪狗產生的愉悅都能被亞空間吸走然後被色孽拿去吸。

 這個就會有個經典問題：如果我在殺人過程中感到愉悅，那我是滋養了恐虐還是色孽？同一種情緒或行為是不是同時餵養兩種混沌神？從我目前的理解上述的情況是可能發生的，八版軍書有個小故事：

畏懼黑暗王子

 在四神偉大遊戲 ( the Great Game ) 的所有複雜關係之中，最引人注目的或許是色孽與其兄弟諸神之間的關係。

 沒有任何存在能像無度之主 ( the Lord of Excess ) 那樣放大恐虐的怒火；因為色孽所代表的世俗享樂與慾望，正不斷滋養著血神對無差別屠殺的渴求，僅僅提及色孽或祂的陰謀，就足以讓血神領域中的火山全面爆發。

 雖然恐虐是唯一公開對黑暗王子抱持敵意的神祇，但納垢與奸奇在祂面前同樣感到不安，儘管按照四大混沌神的一般力量排序，色孽通常被視為位於最末位，即使是他們，也能感受到祂無與倫比魅力的吸引力，對這位年輕的兄弟既被吸引，又心生排斥。

 這部分原因在於所有混沌神本身都體現了色孽所象徵的「無度」，恐虐體現的是嗜血，奸奇代表陰謀算計，而納垢則象徵瘟疫的蔓延，每一種執念都可能被黑暗王子以一句低語般的承諾引導並納入祂的意志之中。

 潛藏在每位兄弟神心靈深處的是一種懷疑：黑暗王子的影響力正在迅速擴張，並且有朝一日，色孽或許會在力量上超越他們所有人，帶著這樣的想法與色孽建立的權宜同盟往往極為短暫。

 表面上看這或許只是因為祂反覆無常、隨時可能倒向另一方而令人難以信任，但也有一種說法認為黑暗王子的對手其實畏懼祂對他們所擁有的那種隱秘影響力。

 就連三神自己都可能影響色孽，那也不用提凡人的情況了，簡單說你砍人恐虐會開心，你用計砍很多人奸奇和恐虐會開心，但你砍人砍上癮色孽會開心，這時候恐虐可能就不太開心了，九版軍書裡還能找到其他例子：

 色孽由需求與渴望而得勢，亦由凡人沉淪於偏執、並在各種形式的誘惑中屈服而壯大，雖然他有時被描繪為四大混沌神中最弱者，但在許多方面色孽的力量只是比其地獄手足更為細微而陰險，更甚者，其腐化汙染滲入凡人一切所追求與所渴望之物。

 因此色孽完全可能從那些乍看之下似乎徹底獻給其競爭神祇的個體與行為之中汲取力量，例如一名嗜殺、持刃的角鬥士，表面上看來顯然是恐虐的僕從，然而在那名戰士對完善劍技的偏執渴求之中，在她對每次勝利的驕傲，以及對自己贏得的崇拜與讚譽的貪戀之中，她其實是在無意識地崇拜色孽。

 同樣地一名狡猾的貴族以精密陰謀擊敗政治對手，看似是奸奇的信徒，然而憑藉其宮廷生活的奢華與過度，更不用說他偏執地要用越發馬基維利式的陰謀困住對手——他同樣在強化黑暗王子。

 無論是飢餓勞工對食物這般無可責難的渴望，或是虐殺者對施加痛苦這般扭曲的執念——凡人慾望一旦走向極端，皆會增長色孽的威能在第四十一個千年這般黑暗、暴力且絕望的時代，這些能量如潮汐洪水般高漲。

 最後總結一下上面提的一長串東西：

*一、*生物的情緒會影響亞空間，四神是受生物情緒匯聚之後而生的

 二、四神吸收的是情緒，情緒本身沒有善惡，目的不重要，不管是你有意為之或無意識產生的都算

 三、四神間也擔心力量被對方吸走並互相提防

 四、哪怕你以為信另外的神甚至不信神，你的情緒還是會滋養對應的神祇

 最後的最後小聊一下另一個常見的問題，為什麼沒有正面情緒的神祇？不過相信看完上面那串也大概能知道端倪了，情緒並無善惡之分，而正面情緒其實也都被四神佔走了，也有另一個可能是亞空間原本有不同情緒的小神祇 ( 例如喜悅之神 ) 但相互吞併後最後剩下了四神，畢竟現在還是有幾個渾沌次級神存在。

 又或者那些都只是四神的不同面向罷了，就好像不同文明不同種族都可能有自己的戰神，但拜了之後最終都會被恐虐吸走也說不定 :P
