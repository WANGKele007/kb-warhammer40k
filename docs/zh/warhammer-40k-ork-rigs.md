# **狩猎战车**

狩猎战车是一种坚固耐用的大型废料拖车，作为兽霸小子狩猎活动的一部分，由喷着响鼻的奔踏史奎格拉着跑。五大三粗的兽霸小子挤满了战车平台，他们死死扒住车体，由着这辆拼装怪车在巨兽的狂奔中颠得左摇右晃。一旦发现猎物，车上的兽霸小子和屠夫小子们就会扯着嗓子发出狂喜的嚎叫。接着，那头永远怒不可遏的奔踏史奎格被小子们驱向猎物，蹄子越踏越快，势头越来越猛。在此期间，车上的兽霸小子们乱糟糟地端起手铳，朝着目标方向一顿乱射；屠夫小子炮手也不闲着，他们有的操作重型抛射炮朝猎物轰出爆破弹，将其炸残或震晕，有的用刺叉炮射出巨大的倒刺矛，矛后拖着长长的锁链。当猎物被长矛扎透、被兽人惹毛时，这场狩猎就来到了最危险、也最让兽霸小子感觉过瘾的阶段。再凶猛的巨兽也扛不住奔踏史奎格势大力沉的一撞，当这艘横冲直撞的陆行驳船一头撞上目标时，小子们立刻恶狠狠地跑下战车，扑在猎物身上又砍又锯又扯，把猎物撕了个粉碎。

# **杀戮战车**

杀戮战车跟其他兽霸小子大车的造法差不多，同样又大又沉，武装到了牙齿。车上一般装着一门重型抛射炮和一门狰狞的刺叉炮。一帮急不可耐的屠夫小子挤在车上，手里攥着长柄砍刀，刀刃上带着狠毒的倒钩。凡是没被奔踏史奎格或车轮碾碎、他们又够得着的东西，都适合拿砍刀来开膛破肚。每辆杀戮战车最显眼的部位就是车顶那座怪怪塔，部落里的一头怪怪小子站在塔上，嘴里颠三倒四地念叨着神谕似的怪话。怪怪小子总是满口胡言乱语，时不时瞪大眼睛朝大猎物指指点点，还会扔出几团爆裂的能量束，或是引导最野蛮、最原始的Waaagh！能量，把车上的小子们煽动起来。怪怪塔能让怪怪小子待在一个对其他兽人来说稍微安全一点的地方，可即便如此，那些就爱搭杀戮战车去打猎的兽霸小子照样被同伴当成一群不要命的疯子。这帮小子一兴奋，涌出来的Waaagh！能量有时连怪怪小子都吃不消，不过话说回来，怪怪小子的幻视带大伙找到上等猎物的次数，要比他让大伙的脑壳一起爆炸的次数多多了。
