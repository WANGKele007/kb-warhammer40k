在中古战锤的世界里，旧世界是以帝国为中心的一片大陆，露丝契亚、震旦、奥苏安等地都被排除在外。这里幅员辽阔，派系林立，无数势力在此明争暗斗。

旧世界的北方、西方、南方均被大洋包围，东部则是世界边缘山脉。大部分地区都是温带气候，从北部的凉爽温带到西部和南部的温暖温带。旧世界的大部分土地都是荒野，低处是大片沼泽和湿地，高地则是荒地和沼地，森林十分稀少，村落与城市犹如海上的孤岛。

旧世界的主要成员是帝国、巴托尼亚等人类国家。帝国位于中部，西边是巴托尼亚，北边是基斯里夫，南面是埃斯塔利亚王国和提利尔城邦，东南方则是边境亲王。除了人类，许多非人类种族也居住在旧世界，比如黑色山脉的矮人和艾索洛伦森林的木精灵。

以下是旧世界的主要势力：

# **帝国**

约2500年前，一位名为西格玛的勇士统一了旧世界的几个部落，又击溃了来犯的外族，这便是帝国的起源。领土广袤、人口众多，两千多年来，帝国一直是旧世界最强大的国家。

*帝国地图，可以看到北边的基斯里夫和西南边的巴托尼亚*

帝国并非中央集权国家，而是分为11个半独立的行省。这些行省分别对应2500年前被西格玛统一的部落，如今已语言相通、文化相似，靠着共同利益联合而成为现如今的帝国。行省由各自的选帝侯负责统治，皇帝也从这些选帝侯中选出。

实际上，帝国的居民并非只有人类。希尔瓦尼亚几乎被吸血鬼完全占据，但法理上它归属于斯提尔领，因此仍是帝国的一部分。旁边的穆特领也是半身人的自治区，半身人的长老甚至和选帝侯一样有选举皇帝的投票权。

帝国信仰的主神是西格玛，但尤里克、塔尔、曼纳恩等神明的信徒也大有人在，教派之间争斗不休。

*虽然西格玛教会和尤里克教会水火不容，但西格玛本人其实是尤里克信徒*

# **艾索洛伦**

巴托尼亚东南部的艾索洛伦森林是树人和木精灵的家园。对人类而言，这是一个神奇而可怕的地方，邪恶的灵魂在树丛中游荡，危险的猛兽在一旁虎视眈眈，连树木本身都可能充满敌意。

*木精灵与树人并肩作战*

古老的树人是这里的土著，也正是他们构成了艾索洛伦森林。5000年前，由于战争，精灵被逐出旧世界，一些想要留在旧世界的精灵便躲进了艾索洛伦森林。这些精灵和树人相处融洽，结下了深厚的感情，并演化成了如今的木精灵。

# **边境亲王**

边境亲王是旧世界东南部一些城邦和小型公国的集合。这里地处旧世界的边界，极易受到绿皮、野兽人和其他势力的攻击，城邦内部也时常动乱，因此很多帝国和巴托尼亚的罪犯都会来此隐居，也有很多当地人翻山越岭前往帝国讨生活，帝国的“战争之犬”雇佣团就有很多成员来自这里。

# **巴托尼亚**

巴托尼亚位于帝国以西，以灰色山脉为界。帝国历977年，在湖神仙女的启迪下，勇士吉勒斯打退了绿皮的入侵，并统一了当地的数个人类部族，宣告了巴托尼亚的建立。

巴托尼亚奉行严格的阶级制度。骑士富有且受过良好教育，终日追求虔诚、英勇等美德；农民则每天挣扎在生死线上。什一税是巴托尼亚社会的集中体现：不论农民生产出什么，都只能留下其中的一成，剩下九成则要上交领主。

*湖神仙女，湖中女神的代言人*

在名义上，巴托尼亚是旧世界的第二强国，仅次于帝国。但相比于帝国百花齐放的科技树，只有农民军和骑士的巴托尼亚军队未免有些磕碜。巴托尼亚人鄙夷“懦弱的”火药武器，而热衷于传统的骑兵战术，他们的骑兵被誉为旧世界最强，而其中的圣杯骑士更是被称为是人类的终极战士。

信仰上，巴托尼亚人可以对其他神明表示尊敬，但湖中女神是巴托尼亚唯一合法的信仰。

# **埃斯塔利亚和提利尔**

埃斯塔利亚和提利尔都是多个城邦组成的松散同盟，没有国王、皇帝这样的统一领袖。埃斯塔利亚的主要城邦有马格里特和托巴罗，提利尔则有卢西尼、米拉格连诺等。

埃斯塔利亚的城市建筑坚固，防御工事精良。两个最大的城邦，北海岸的比尔巴利和南海岸的马格里特，都是港口城市，它们之间的明争暗斗已经持续了几个世纪。提利尔人是熟练的商人，除了狡猾的阿拉比人，他们几乎能在交易中够欺骗任何人。在战争中，提利尔通常依靠雇佣兵而非自己的军队。

尽管语言相似、位置接近，埃斯塔利亚人非常讨厌被当成提利尔人，而提利尔人也是如此。

* 焰阳骑士团，主要据点位于提利尔和埃斯塔利亚，在帝国也有分支*

# **基斯里夫**

基斯里夫位于旧世界最北端，气候严寒，环境恶劣，经常受到混沌入侵。这里的大部分地区都是广阔、空旷的冻土平原，混沌荒原刮来的狂风畅通无阻地肆虐其上，少量的森林则被精灵、绿皮占据。

但环境带来的并非都是负面影响。据说基斯里夫的土地本身具有生命，当外敌入侵时，整个基斯里夫都会奋起抵抗。恶劣的环境也造就了基斯里夫人的独特个性。前沙皇鲍里斯曾言，他只信任敢于大发雷霆的人，因为粗鲁、暴躁只是表象，而重要的是内心的正直和忠诚。

# **玛丽恩堡**

玛丽恩堡是韦斯特领的首府。韦斯特领曾经是帝国的一部分，但在帝国历2429年宣布独立。作为贸易城市，玛丽恩堡的贸易对象遍布各地，从浩瀚洋到利爪海，再到瑞克河沿岸的阿尔道夫和努恩。

*《全面战争：战锤3》中，帝国皇帝需要打击帝国分离势力，而这一行为会恶化与玛丽恩堡的外交关系，三者的关系不难推测*

长期以来，玛丽恩堡一直是旧世界最大、最繁荣的贸易城市，许多商业行会的总部也设在玛丽恩堡，一些人甚至称它为“黄金之城”。商店的橱窗里摆着世界各地的奇珍异宝，产地从帝国到巴托尼亚，甚至旧世界之外的奥苏安和震旦，只要是世上有的，几乎都能在玛丽恩堡买到。

# **萨图沙**

萨图沙是提利尔南部的一个小岛，这里天高皇帝远，是海盗和各路罪犯的王国和避风港。岛上土地肥沃，岩石林立，盛产葡萄、橄榄和小麦，周围的水域也物产丰富，为居民提供了稳定的食物来源。

*萨图沙的海盗鱼龙混杂，有人类、矮人，甚至有吸血鬼*

如今，岛上的海盗实行民主统治，定期选出一名海盗王子作为头目。虽然海盗王子掌握着最高权力，但只会在最极端的情况下行使，毕竟这些海盗非常重视自由。现任的头目是臭名昭著的海盗公主，艾蕊娜萨·盐怨。毫不夸张地说，她比所有前任海盗王子都要残忍，而且她是迄今为止在位时间最长的统治者。
