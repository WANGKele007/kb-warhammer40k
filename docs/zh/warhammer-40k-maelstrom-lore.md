大漩渦和巴達布戰爭可說是40K粉絲必看的戰役，不僅是荷魯斯叛亂之後資料最多的大規模星際戰士叛亂事件，同時也說明黑心修倫是如何一步步墮落致此的開端，不過在巴達布戰爭後這裡到底發生了什麼事？

 今年年初的戰役書－The Maelstrom: Lair of the Tyrant主角正是黑心修倫，其中也稍微提到了大漩渦的現況，這裡就把戰役書的年表事件和大家分享一下。

 先說一下為甚麼帝國要在巴達布死嗑，以前的IA第九本都有提到大概的原因，大漩渦本體的直徑約有數百光年，而其周圍受到影響的區域則延伸達數千光年，周圍區域一般會用大漩渦區 ( Maelstrom Zone ) 做稱呼，過去是僅次於恐懼之眼的亞空間風暴，這片區域光是已知恆星星系就多達一千多個，帝國對這片區域的掌控力十分低下。

 當地除了有渾沌勢力外還有不少異形勢力和各種海盜盤根錯節，但這片區域自遠古時代便漂流自銀河核心的殘骸，其中蘊藏著大量珍貴礦物、稀有同位素以及來自銀河核心的未知晶體，此外許多早已失落於歷史的古代科技遺物也仍然散布其中，因此週邊勢力和帝國都不可能放棄這片混亂地帶。

 M40開始這片區域的情況逐漸惡化，一直到M41.557年，巢都世界希格納克斯 ( Cygnax ) 在渾沌戰幫的影響下叛亂最後引爆飛彈自毀，帝國在當地的平衡破壞，因此成立了大漩渦守望者 ( The Warders of the Maelstrom ) 負責平定與監視大漩渦區，後面的事情大家都知道了...

--

 這邊我們看看今年的介紹，關於大漩渦區的介紹跟舊版類似，由於此處蘊藏著豐富的珍稀礦物與特殊化學資源，同時也存在一些極為罕見適合進行能量採集的特殊恆星，帝國以及其他勢力長久以來都被吸引而來，而區域內少數適合居住的世界，也逐漸發展成為重要的航運、資源加工與軍事防衛樞紐，作為開發這片資源寶庫的基地，所以帝國不可能放棄此處，帝國放棄了其他勢力就會進來進而威脅帝國。

 巴達布戰爭後最先是處刑者戰團的人發現大漩渦出現了一名新的海盜領主，自稱黑心，後來太空野狼發現紅海盜 ( Red Corsairs ) 的身影並交戰，M41.938年一支由火蜥蜴帶領的帝國艦隊遇上了紅海盜，連領頭的火蜥蜴戰團長Neh'Tar都被殺了，只留下一名倖存者被丟回帝國境內，紅海盜要他帶回一則訊息：「大漩渦不受帝皇律法約束。」

 另外帝國騎士的雷射脈衝砲 ( Las-Impulsor ) 其STC最開始被渾沌搶走，後來有個自由之刃騎士帶著艦隊搶了回來。

 大裂隙展開後這片區域就更加混亂了，除了前面提到的渾沌勢力和異形之外，泰倫蟲族十版軍書裡提到入侵巴爾的蟲族艦隊失敗後四處逃竄，部分流竄到了這片區域，數百艘生體艦艇自漩渦中心的虛空中翻滾而出直接衝入紅海盜的海盜艦隊之中。

 白色疤痕為了報復紅海盜對母星切格里斯的入侵行動，集結部隊反打了紅海盜的據點，結果在撤退時被紅海盜伏擊，戰團長朱巴．可汗 ( Jubal Khan ) 被俘，目前已被救出，還是白色疤痕的戰團長，只是他的身心皆遭受了極其殘酷的折磨，這個算是八版就有的事件了 :P

 最後是大漩渦區域內一個名為齊爾德維爾裂谷（The Zilldwyre Crevasse）的地方，其深處一道如燈塔般的閃光開始閃爍，任何凝視它的領航者（Navigators）感官都會受到干擾，而一支沃坦聯盟的親族採礦船艦隊自深淵中緩緩浮現，它們拖曳著一條條奇異的黏液痕跡，船身覆滿無法辨識的徽記，紅海盜的監測人員推測，它的航向很可能正是獸人據點所在的方向。

 現階段大漩渦裡面甚麼都有，無數的異端、異形和變種人盤踞其中，除了被追殺逃入其中的混沌勢力和到裡頭找活接的異形傭兵之外還有些勢力是主動殺進去建立據點的，有些是為了掠奪當地豐富資源，有些則把漩渦視為向外發動戰爭的基地，無數獸人海盜部族在此建立據點；寂靜王的顧問則認為自稱海盜之王並篡奪薩內赫王朝的塔斯薩已將自己的瘋狂帝國擴張至漩渦中許多防禦薄弱的墓穴世界；沃坦聯盟的許多氏族也會前往被漩渦捲入的星球與異常區域進行資源採集；靈族海盜則是利用魍道在其中掠奪。

 順便介紹大漩渦目前內部的區域劃分吧，先說一下大漩渦內還是有少數孤立的帝國據點，它們都極為隱密且脆弱，例如斯克羅姆與奧布拉圖斯這樣的世界只是最近才因漩渦持續擴張而被納入其中，此外大漩渦中也存在受到嚴密防護的審判庭據點，其中最著名的便是虛無堡壘（Null Bastion），同時也有死亡守望隱藏於暗處的秘密要塞。

 最上方的腐蝕邊疆（The Rad Marches）整片區域完全充斥著數不盡且不斷變化的邪惡污染，這些污染不僅改變物質本身，更連能量、重力乃至空間本身都受到扭曲，使這些原本被視為宇宙基本法則的力量，也遭受無止境的變異侵蝕。

 左下的哀寂深淵（Mournhollow）其中可能藏著一個古老的靈族世界，但星語者無法偵測其中的區域。

 維納托里亞破火山口（The Venatorian Caldera）是一道橫跨數十光年的巨大混沌裂痕，這裡充滿了殘骸、破碎的世界，以及數不清的異形海盜集團，這道巨大傷痕很可能源自某場規模驚人的科技災難。

 右上角的大裂傷（The Great Lesion）其中至少有一個重要的紅海盜據點，已知存在的少數星系被認為只是真實數量的一小部分。

 咆哮渦流（The Howling Gyre）則是個神祕地區，機械教的賢者也無法確認區域內那種被認為會導致虛空艦艇巨大結構內傳出詭異噪音的次原子共振現象究竟是什麼，紅海盜與休倫對此處的掌控力極為有限，前面提到的帝國虛無堡壘就在其中，懷言者的惡魔世界加爾梅克 ( Ghalmek ) 也在此處為懷言者與紅海盜產出大量的戰爭裝備。

 順帶一提這裡頭有個名為科科洛斯 ( Cocholos ) 的墓穴世界，六版的時候這裡被惡魔屠了一遍死靈族滅光，現在改了設定，這裡是沃斯凱克王朝唯一殘存的墓穴世界，可能是上頭的反亞空間設施逐漸劣化所以被惡魔入侵，地底深處不死的太空死靈與惡魔之間正持續爆發著慘烈而無止境的戰爭，然而墓穴群中仍有大片區域保持沉睡狀態，沃斯凱克王朝最珍貴的寶藏至今仍封存在那些寶庫之中，也因此成為太空死靈與各種異形掠奪者共同覬覦的目標。

 右下角的帕拉凱爾螺旋（The Parachyre Helix）其現實宇宙本身已遭到嚴重扭曲，任何航向規劃幾乎都失去了意義，在虛空海戰中計算射擊或推算軌道飛行路徑都只是徒勞無功，弔詭的是由於帕拉凱爾各星系之間存在許多劇烈變動的特殊航道，使得跨星系航行反而比漩渦其他地區更加安全

 齊爾德維爾裂谷（The Zilldwyre Crevasse）同樣匪夷所思，經過探測這並非真正的裂口，而是現實空間本身的一道摺疊，只是其規模已達天文等級，裂谷邊緣散布著大量星系群，它們都是受到裂谷深處異常重力牽引而聚集於此。

 最後就是整個大漩渦中最邪惡、最黑暗的權力中心：暴君之冠（The Tyrant's Crown），其中包含了約二十三個星系，對遭俘叛徒的審訊結果則顯示，這裡其實只是暴君休倫眾多根據地中的其中之一，想透過一次斬首行動徹底摧毀休倫的權力核心幾乎不可能。

 裏頭同樣有幾個重要據點，例如紅海盜最大的船艦基地新巴達布（New Badab）；前往暴君之冠最主要但最危險的航道破碎海峽（The Broken Narrows）；數十條亞空間航線交會形成的重要亞空間樞紐地獄之虹（Hell's Iris）；阿巴頓贈送給休倫的黑石要塞也潛藏海盜要塞（Corsair's Keep）之中，但紅海盜無法啟動它僅能作為基地使用；最後則是卡哈法斯特錨地（Kharfast Anchorage），此處是位於深空中的重力異常區，擁有非自然的熵增穩定性，數百年來成為受損船隻藏身的理想避風港，紅海盜奪取船支後便會拖拽於此改造，這裡最奇特的特性就是太空廢船和各式廢船都會偶然漂流至此。

 大概是這樣，其實沒啥變化，真的要說就是蟲子、死靈和沃坦聯盟都來了，然後這裡跟以前一樣亂，海盜勢力滿天飛那種。

 另外這本書的結尾有提到基里曼打算赦免過去巴達布戰爭被罰遠征的三個戰團：慟哭者、螳螂勇士和處刑者戰團，這三個戰團都得集結部隊並做好戰鬥準備，印象中好像螳螂勇士已經有PSM支援了，條件是得進到漩渦內幹掉休倫，文中的審判官準備啟動保險機制，只要這三個戰團有奇怪的舉動就會一起消滅。
