省流：個人推測是機器人或仿生人之類的，總之跟帝國的星際戰士是兩回事

 這個算是老話題了，具體出處是小說「Blades of Damocles」第七章結尾和第八章，裡頭還不是二連長的西卡留斯 ( Sicarius ) 跟著幾位星際戰士闖進了土氏族的研究設施，裡面模擬了不同的星球環境外還有不同種類的敵人，一行人在模擬叢林裡遇上了機械克里特人，後來遇到了鈦星人的假星際戰士，我這邊就節譯一下：

 「該死的，我們是同一邊的！」努米托從沙地上掙扎爬起，大聲喊道，聲音中充滿了震驚與抗議，另外九名身分不明的極限戰士正向他們的位置靠攏，爆彈槍已抵肩瞄準。西卡留斯橫劍以待。那是鈦星人步兵的射擊姿勢，絕非阿斯塔特修會的戰術動作。

 這些人並非盟友，這也不是一場誤會：這是鈦星人扭曲科學的產物。

 西卡留斯一眼看穿了戰局。在中距離處，來襲的突擊戰士身影正迅速逼近，趕上了前方的戰術小隊。他們奔馳在粉碎的琥珀與鏽蝕黃銅構成的荒野上，躍過斷垣殘壁。西卡留斯記得腳下琥珀碎裂的嘎吱聲，那是他第一次與鈦星人交戰時留下的鮮明回憶。這片戰場完美複製了維斯珀廷郊區的荒涼景象。然而現在，他要對抗的卻是自己的「弟兄」。

 帶著一絲滿意的西卡留斯注意到努米托仍在遲疑，既然如此，那就由他來領導，履行他天生的使命。

 當那名被繳械的戰士正伸手去拿爆彈手槍和手榴彈時，這位中士已跨步逼近。他能聽見手榴彈插銷滑出的細微金屬聲，空氣中充斥著前方星際戰士開火的轟鳴聲，但西卡留斯已切入那名失去武裝戰士的防線。

 他伏低身軀，將肩膀抵在敵人的胸甲下把對方整個人扛離地面，同時揮劍橫斬，切斷了對方握著手榴彈的手腕，隨著一波爆彈齊射，他感受到這具「臨時盾牌」劇烈顫抖，爆彈在對方的動力背包與厚實血肉中炸開了巨大的坑洞。

 當那隻握著待發手榴彈的斷手落向塵土時，西卡留斯用裝甲靴尖猛力一踢，手榴彈飛向前方陣容緊密的爆彈槍戰士們，分秒不差地爆炸，在破片風暴中將其中五人掀翻在地。

 這正是極限戰士們所需的契機。

 西卡留斯小隊穿過納托羅斯在牆上開出的缺口，呈扇形展開發動集體衝鋒，安提里昂小隊留在門外的隊員提供了掩護射擊，爆彈槍口在昏暗中閃爍，他們的射擊精準無誤，又有三名來襲的偽造戰士頭頸中彈，倒在塵土中。

 殘存者發起反擊，一發爆彈擦過西卡留斯的大腿，引發膝蓋舊傷處的一陣劇痛，他將痛苦轉化為憤怒的咆哮，舉起那具垂死的星際戰士殘骸充當盾牌發起衝刺，敵方的突擊小隊此時已躍至近前，動作詭異地整齊劃一，西卡留斯看著這一幕，感到純粹的厭惡。

 這簡直是對極限戰士戰術教義的低劣模仿，徒具其表且毫無真正的戰術自覺。

 「中士，他們是機器人嗎？」格拉維烏斯喊道，語氣中帶著困惑。

 「那些是仿冒品 ( Simulacra ) ！」西卡留斯怒吼道，「全力擊殺，絕不留情！」

 虛假的突擊小隊在飛行中以爆彈手槍開火，鏈鋸劍轟鳴作響，四名先前被手榴彈炸翻的戰士已重新蹲踞，保持著步槍兵的持槍姿勢。

 「跳！」凱托羅斯在敵人齊射前大喊，格拉維烏斯與維萊坦躍過低角度的彈雨，動力盔甲的伺服器增強了他們的力量，即使噴氣背包近乎耗盡，他們仍躍過五英尺高，落地後毫不停歇地繼續衝鋒，凱托羅斯迅速從側翼切入，火焰噴射器吐出一道長長的鉕油火舌，將最近的四名戰士捲入火焰。

 易燃且黏稠的燃料附著在動力甲上，如工業熔爐般劇烈燃燒，三人倒在紫色的火焰波浪中，凱托羅斯滿意地哼了一聲，隨即掏出一枚反裝甲手榴彈反手擲向第四人，那名戰士正欲轉身舉槍，手榴彈便已炸開，撕裂了他的半個軀幹，將他掀翻，黑色液體與綠黃色的潤滑劑從他胸腔的裂口中噴湧而出。

 「如果這就是鈦星人眼中所謂『帝皇最頂尖的戰士』的水準，」格拉維烏斯說道，「難怪我們能在這顆星球上勢如破竹。」

 「勢如破竹？」努米托反問，「你怎麼知道的？」

 「我們可是星際戰士，」他答道，表情帶著一絲輕微的冒犯感，「死亡天使。你該以此為榮，努米托。讓這份榮耀指引你的信念。」

 努米托戒備地回頭看了一眼那通往模擬叢林、邊緣焦黑的塑膠大洞，埃昂斯安正駐守在那，這個大個子像機僕一樣巋然不動，但努米托仍隱約覺得鈦星人的飛彈隨時會劃破長空。他轉回身面對格拉維烏斯，挺直脊背。

 「我之所以是中士而你不是，格拉維烏斯兄弟，很大程度上是因為我絕不讓自滿干擾我的警覺。」

 「然而你的小隊現在只剩下四人，而我們還有七個。」

 「注意你的語氣，格拉維烏斯，」努米托警告道，「況且，你們那邊看起來更像是六個半。」

 ( 小打岔，誰說星際戰士沒有幽默感的 )

 不遠處科尼德正用多洛電漿手槍那嘶嘶作響的槍管，灼燒自己斷腿處殘缺的傷口，「我聽到了，中士，」他咬緊牙關說道，「藥劑師德雷科斯在需要他的時候跑哪去了？我把這傷口搞得一團糟。」

 「會沒事的，」西卡留斯說，「繼續弄吧。」

 丹圖里斯放下武器，用戰鬥刀從一名倒地的偽造星際戰士身上鋸下了一截小腿，鏈鋸劍是極具破壞力的武器，目的是眨眼間絞碎肉體與骨骼，它們是為了殘殺與屠宰而生，即使在精通劍術的人手中也不是理想的手術工具。

 「科尼德，」丹圖里斯抹去那截回收小腿膝關節上最髒的黑色黏液，將它遞給隊友，「至少形狀是對的，要不把它綁上去？或許能幫忙分擔點重量。」

 科尼德對戰友的樂觀報以微笑。「謝謝你，丹圖里斯。我會用夾板把它固定住。如果必要的話，我就拿這個當枴杖，」他指著自己的鏈鋸劍說，「記得嗎？拿手杖總比拿枴杖好。如果老瑞特里庫斯大叔都覺得這法子行的話……」

 「……那還真是稀奇了。」丹圖里斯輕笑著接話。他伸手拉起科尼德，將兄弟扶正，「只要飛到空中，這條腿就不那麼重要了，」他繼續說，「雖然落地時會很痛。」

 「但我們飛不起來，」埃昂斯安像座雕像般嚴肅地守著，目光鎖定地平線，「就算把我們剩下的燃料全部湊在一起，也裝不滿祭壇上的一個聖杯。」

 「別那麼肯定，」凱托羅斯說道，他正從那些偽造突擊戰士的噴氣背包上撬下裝甲板，整齊地擺在自己周圍，維萊坦逐一檢查，扔掉一些，留下其餘的，凱托羅斯將一根燻黑的手指伸進噴氣背包的燃料槽，蘸出一滴液體聞了聞，甚至還用舌頭舔了一丁點，他那張緊繃且毀容的臉扭曲得更厲害了。

 「是鉕。或者是很接近的東西，嚐起來......事實上還更純淨一點。」

 「我們絕不能使用敵人的裝備！」馬格羅斯抗議道，「這是異端行徑，想都別想，在我擔任極限戰士的二十八年裡，我從未......」

 「對，沒錯，」西卡留斯說，「馬格羅斯，你對異族的憎恨值得讚揚，也完全正確。我們不會用被污染的異形科技來替代由我們技術軍士祝福過的裝備。」

 一陣尷尬的沉默，經過這段時間激烈的入侵作戰，許多極限戰士已精疲力竭，動力甲嚴重受損，彈藥儲備也幾乎見底，戈洛坦和凱托羅斯尤其急需補給，前者胸部曾被脈衝炸彈擊中，裝甲佈滿裂紋，一旦再次遭到撞擊必會崩潰；後者則被燒得連裝甲外層都炭化脫落了。

 「事實上，」維萊坦說，「我做了一些檢測......嗯，看來這些是帝國裝備，具體來說，是第三連和第六連的動力甲，雖然被動過手腳，但功能完好，不只完好，大部分都處於絕佳狀態。」

 「第三連和第六連，」努米托說，「我們曾在達摩克利斯灣另一端的維斯珀廷與他們並肩作戰，難道鈦星人剝下了我們遺留在那裡的戰死者裝備，好讓他們的模擬更逼真？」

 「理論上是這樣，」維萊坦道，「事實上也很有可能，在激烈的戰場上我們的藥劑師只能回收陣亡者的基因種子，其他東西則無暇顧及，鈦星人完全有理由去解析甚至仿製帝國的軍武物資。」

 「太噁心了，」馬格羅斯說，「褻瀆我們神聖的裝備，用它來武裝那些培養槽裡長出來的冒牌貨，這已經夠糟了，竟然還讓它們來對抗我們？簡直令人難以置信。」

 「從某種科學的角度來看，」維萊坦說，「這非常合理。知己知彼。」

 第八章前半段都是在講說帝國星際戰士對上假星際戰士的戰鬥場面，極限戰士這邊在剛經歷戰鬥、被偷襲 ( 應該說撞進敵人隊伍中 ) 且人數相當的情況下全滅了十個假星際戰士，自己這邊最大的傷亡應該是其中一名成員的腿被打斷。

 裝備上從上文來看是鈦星人回收了舊的星際戰士裝備 ( 第三和第六連的 )，總之西卡留斯他們是能直接用的，裝備差距也不存在，整段看來這些假星際戰士也不是複製人，流黑血和砍了有火花來看應該是類似仿生人之類的東西，這也不奇怪畢竟前一章才打過機械克里特人，這邊節錄前一章的段落：

 不潔的液體再次濺滿他的裝甲，他身體的一側完全被這東西染黑，極限戰士的紋章被奇怪的油漬遮蔽。

 那味道不只是鮮血，還有潤滑油、長鏈合成物和微型液壓油，這些克魯特人看起來像是有血有肉，但其體內寄宿著異端的機器智能，與其說是活生生的感官生物，倒更像他們在孵化室遇到的那些無人機。

 鈦星人做這些東西目的也很單純，從這段來看是要測試而已，極限戰士這邊看到之後也有相同的推測，總之看下來沒啥陰謀論甚麼要搞自己的基因戰士或混進帝國內部，單純把他們當靶子練習用而已，戰鬥力不好評價但看得出跟真正的星際戰士差了不少。
