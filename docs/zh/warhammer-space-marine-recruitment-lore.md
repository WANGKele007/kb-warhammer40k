簡截易懂的標題，開頭我們先說說星際戰士徵兵的流程，這部分只能說個大概，因為戰團的自主性和文化迥異問題或多或少都有自己戰團的儀式，總之看個大概就行。

 星際戰士的新兵招募並沒有一定的規定，一般戰團會從母星或母星周圍的世界招募，而艦基戰團通常會在太空的特定星域漫遊，定期從幾個受青睞的世界中招募，但大多數戰團都傾向從惡劣環境中挑選優秀的候選者，死亡世界到巢都底層的角鬥場都有可能，挑甚麼人也沒規定，此外戰團會傾向從野蠻世界、巢都或是封建世界這類環境動盪且保留尚武文化或是強調弱肉強食的世界招募，可能會配合一些很誇張的儀式，當然也是會從文明世界招募，只是相對較少。

 第一階段的候選者或是受試者會被稱為有志者 ( Aspirants )，不同戰團的招募過程差異很大，像聖血天使的徵選儀式弄得很像慶典，黑色聖堂則是要有志者自己想辦法到戰團要塞，通常在第一階段的招募就會刷掉很多有志者了，無論是死亡、基因檢驗不合格或是無法完成儀式等等。

 太空野狼則是狼牧師會在野外遊走觀察芬里斯上各部落間的爭鬥從中挑選適合的人選，帶回修道院在改造前會先進行莫凱考驗 ( Test of Morkai ) ，有志者會先植入狼之螺旋 ( Canis Helix )，能夠控制自身變異的才能接受後續改造，不然就到野外當狼人了。

 一般是通過儀式的有志者們才會進行第二階段的改造手術，改造手術這階段他們都還是凡人，戰團會開始往他們體內塞一堆有的沒的最終變成超人類，這中間還有化學治療、催眠、洗腦和體能訓練，手術最後一步就是在皮下植入黑色甲殼 ( Black Carapace )，我不確定是特例還是通則，但十版軍書裡還是有保留這點，戰團會在改造後的有志者們先成為偵查新兵進行一次測試，這些改造了但還沒完全改造的戰士會被稱為新血 ( Neophyte )，通過測試的新血才有資格植入黑色甲殼成為真正的星際戰士。

 所以說一直到新血階段其實都算是考核，到了新血都有可能被刷掉，甚至有人跟真正的星際戰士就只差了黑色甲殼，在這之前有以下幾種常見的下場：

**死亡**

 考慮到戰團文化和招募過程，招募儀式九成以上都會是非常艱辛 / 血腥暴力的活動，與其說是挑選最優秀的戰士不如說是篩選掉不合格的人，很多種死法等著候選者，死在前往徵選地點的路上、前去討伐某個野獸時被殺，母星上玩部落衝突時被當菜切、角鬥場吃雞失敗等等，星際戰士數量稀少但帝國的生命夠多，唯有最精銳者才能成為死亡天使。

 另外【Angels of Darkness 】有個片段，三個年輕人接受暗黑天使的儀式，第一個人躺上去接受手術採集體液樣本，他撐了過去，下一位男孩看到手術台的血跡就退縮了，牧師帶到外頭跟他說你這樣使你的家人蒙羞，他們會被部落唾棄活不過這個冬季的，接著給了男孩一個體面的榮耀：用手把他的脖子折斷，他會告訴他的家人男孩死於審判過程，免去家族的汙辱，接著迎接下一位男孩。

 要知道對大部分世界和帝國人民來說成為星際戰士是莫大的榮幸，例外大概是帝國之矛戰團，一般來說如果失敗了也不會是多大的恥辱，但在某些世界可能就不是好事，如果死了就好說，總之就是這樣，你不體面有人會幫你體面。

**惡魔宿主**

 大概是驅魔人 ( Exorcists ) 戰團限定的了，這戰團的特色是測驗時會讓新人接受弱小惡魔的附身長達12小時，也因此驅魔人戰團對付惡魔時有更高的抗性與抵抗力，不過大部分都會有身體上的突變必須隨時清除，至於那些失敗的人就沒這麼好運了，通常會被永久附身、變成惡魔宿主或是渾沌卵等等，這些突變之人關在戰團母星保守秘密，這其實比死還糟糕。

**機僕**

 部份在儀式或改造手術中失敗的候選者會被改造為機僕，這裡不是說全部的失敗者都會，這個得看戰團文化和必要性，以暗黑天使為例他們有很多招募世界 ( Recruiting World ) 會定期在各星系間巡航來挑選適合的年輕人，不過如果改造失敗就會被清除記憶改造成機僕，考量到每個星際戰士戰團內的機僕數量肯定有很多戰團都會這麼作。

 太空野狼也有類似的行為，太空野狼的鋼鐵牧師 ( Iron Priest ) 會偽裝成鋼鐵之神和凡人打交道，芬里斯上的鐵匠都會信奉鋼鐵之神，那些特別有天賦的鐵匠便會進行朝聖之旅面見鋼鐵之神，通過測試的鐵匠便能夠加入太空野狼隨後送往火星成為技術軍士，失敗者則會被關進地牢改造成機僕，作為他們浪費鋼鐵牧師時間的懲罰，餘生都將以此身償還...

 此外極限戰士和黯鴉守衛也這麼幹過，漫畫裡的極限戰士還派機僕當有志者的測試關卡，測驗下一批有志者的資質是否足夠。

 啊對，我看Reddit討論有人提到新血失敗後被改造成機僕，但我暫時找不到出處所以看看就好，有知道的可以補充一下。

**戰團侍從 Chapter Serf**

 如果改造失敗或是有證明其價值但未通過儀式的存活者就可能成為戰團侍從，這個每個戰團都有，從極限戰士到暗黑天使都有類似的侍從，比較常見的是改造手術其中幾項失敗 ( 尤其是植入黑色甲殼 ) 的改造者，他們已經比凡人強壯但未能比肩星際戰士，就可能被派到戰鬥相關的職位。

 以前也介紹過戰團侍從，這個職位可大可小，可以理解成幫阿斯塔特修士們執行戰鬥以外的一切事物，小到煮飯幫盔甲雕刻，大到管理據點修道院保衛領地當艦長，每個戰團的侍從用途和待遇都不同，但是成為侍從至少比變成機僕好，考慮到有部分人是可能只剩下一兩道手術沒完成，侍從的戰鬥力不會比凡人低。

 例如星際戰士的船艦，除了負責指揮的軍官和管理引擎的技術軍士外，剩下的除了機僕就是侍從，所以無論是使用炮台、日常清潔一直到艦隊接舷戰都靠侍從，這些侍從對他們的超人類主人狂熱地忠誠，並被灌輸了戰團教派中許多較低層級的教義，他們都受過訓練並能獲得比一般海軍船艦上更優良的武器，這使得他們在接舷戰中成為令人恐懼的對象。

 說到這個就不得不提驚世駭俗的優生學計畫，這個案例出自Rynn's World (Novel) — The War for Rynn's World (Omnibus), Part One, Chapter Three，緋紅之拳 ( Crimson Fists ) 的戰團長Algernon Traegus利用落選但並未失去生育能力的候選者與基因相容的女性交配繁殖，以培育出更適合的緋紅之拳戰士候選人，然而該計畫最終未能取得預期成果。

 以前我們討論過關於星際戰士的生育能力，至少從這個例子來看還沒完全進行手術或是進行到某個階段的受試者可能保留著某種程度上的生育能力，當然也不一定是有性能力也可能是還能取精繁殖，但是結果很糟這點也不確定是生不出來還是生出來的後代跟普通人一樣。

**行星防衛軍 / 輔助軍**

 前面提到過星際戰士的改造過程十分漫長，但凡中間任何一步失敗就可能落得殘廢甚至死亡的下場，但也是有些例子只是單純改造失敗但身體和心智正常，除了侍從之外另一個可能就是編到戰團母星的行星防衛軍內，不過這可能是換種形式的侍從，因為星際戰士的領地多數不需繳什一稅 :P

 太空野狼就會把這些人編成名為卡爾 ( kaerls ) 的行星防衛軍負責保衛芬里斯，順帶一提這個傳統可能是從30K時期的芬里斯輔助軍－芬里斯近衛 ( Fenrisian Kaerls ) 演變而來。

 極限戰士的情況比較特殊，極限戰士是少數戰團疆域極大且世界科技水準高的戰團，而且還得區分30K時期和40K時期，30K時期就名為守夜者 ( Vigil Opertii ) 的影子組織，沒通過測試的有志者就可能加入這裡負責應對奧特拉瑪疆域內部的威脅，這個組織42K時期仍在運作，但不確定是否有改組或改變運作方式。

 馬庫拉格有個青年軍 ( Juventia ) 組織，有點類似卡迪安人的白盾，年輕人一般會先加入青年軍接受訓練，極限戰士如果要招募新兵也會先從這裡找起，青年軍的成員後續一般會加入奧特拉瑪輔助軍 ( Ultramar Auxilia )，但並不是保證錄取。

 30K時期奧特拉瑪還有戰鬥學院，短篇小說【IN THE GRIM DARKNESS】裡頭有提到奧克魯達學院 ( occluda scholum ) 每年招募一萬五千名學生，部分學員會在訓練過程中死去，畢業的數千名學生中大部分會成為輔助軍的軍官或是高級官員，其中只有二十名能成為星際戰士，到現在十版軍書裡還是有提到極限戰士的疆域內有許多學院 ( academies ) 讓各地的青年在此接受訓練並競爭，這些人大概率沒被選上成為星際戰士也能成為輔助軍。

 帝國之拳也有類似的組織，金甲輔助軍 ( Auric Auxilia ) 就是從未經過測驗的有志者組成的，負責保護山陣號，大裂隙展開後有幾千名卡迪安士兵為了感謝帝國之拳協助他們撤離母星而加入了輔助軍。

 起源戰團 ( Genesis Chapter ) 有個新現星輔助軍（Newfound Expeditionary Auxilia）同樣是從有志者和戰團侍從組成的，仿造奧特拉瑪輔助軍打造，用於協助起源戰團的作戰。

**回家**

 雖然看起來很不可思議但確實有戰團會這麼做，聖血天使的招募儀式有分階段，第一階段是有志者需要先到天使之殞 ( Angel's Fall ) 集合，這時候戰團就會先進行考核了，出自小說【Dante】，他們將受試者分類，有一批是絕對不可能通過也不需要再嘗試的人，直接給放回去了，第二批則是不能當星際戰士但可以當侍從，可以自由選擇要留下還是回家，第三批則是可以參加第二階段吃雞大賽的五百名有志者。

 另外在小說【The Devastation of Baal】裡有個小孩是試煉的時候摔壞腦子被送回家，從他父親的敘述來看是有道第三階段挑戰之地的，他本身基因檢測沒問題但因為摔傷所以被刷掉，後來等到基里曼前來救援後人力真的太缺所以但丁下令所有年齡合適且基因代碼匹配的巴爾青年都會被改造為新兵 ( 先不管測試，能以凡人之軀協助作戰活過蟲族圍攻已經很厲害了 )，這小孩因為可以治療所以跟其他小孩最後都被帶走。

 極限戰士漫畫裡有個例子是貴族請了個失敗的候選者來當家教分享經驗 :P

**儀式守衛**

 這個可能是聖血天使獨有的過程，同樣出自小說【Dante】，通過初試的五百名有志者接下來會進行為期九天的體能測驗，看敘述像是在一個競技場內場外有民眾能觀賞，在這階段失敗的人同樣可以回家或當侍從，九天過去之後留下來的有志者們其部落會受到聖血天使的獎賞。

 第十天後會進行第三輪測試，有志者會長途跋涉一同前往挑戰之地在堡壘內接受真正的測驗，這個階段失敗的有志者就無法離開了，將保守秘密永遠待在這裡並守護這座堡壘。
