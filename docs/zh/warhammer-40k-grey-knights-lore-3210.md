# **疯狂瘟疫**

**在941.M41年，一名孤身审判官的鲁莽行为释放了一种古老邪恶，想凭她的智谋较量万变魔君伊克'萨尔'迦尼克斯。面对以恶魔之名散播的疯狂，灰骑士集结了三个兄弟会，至高大导师卡尔多·德莱戈亲自率领他们投入战斗。**

圣锤修会审判官萨弗·森吉尔毕生都在探寻万变魔君伊克'萨尔'迦尼克斯的秘密。在得知恶魔拥有预见之力后，森吉尔逐渐沉溺于执念，坚信自己能为帝国窃取这份力量。数十年来这位审判官搜遍银河寻找与万变魔君相关的受诅咒器具与亵渎造物。最终，在一艘飘荡的异形废船中，她发现了低语者的骸骨——一种早已灭绝的异形生物，曾被伊克'萨尔'迦尼克斯附身。她希望借这遗骸召唤恶魔，并将其束缚于自己的意志。

自帷幕之外，伊克'萨尔'迦尼克斯凝视着森吉尔，既含轻蔑又带嘲弄。万变魔君早已预见这一切，早在审判官出生的数世纪之前，早在它附身低语者之前——便已经知晓，并为这个妄图篡夺它力量的凡人准备了陷阱。

借着伪装成瘟疫之父，伊克'萨尔'迦尼克斯将大魔*卢尔贡引诱向审判官，许诺给他一条进入凡域的道路，如此他便能传播瘟疫之神的礼物。通过复杂的咒法与巫术，万变魔君将联结自己与低语者骸骨的命运丝线剥离，并把它们缠在卢尔贡身上。

*：然而后面转手就写成恶魔亲王了。

当森吉尔念完本应唤出伊克'萨尔'迦尼克斯的咒文时，卢尔贡取而代之被拽入现实，为囚禁伊克'萨尔'迦尼克斯设下的结界，在这陌生而强大的恶魔面前焚烧崩解。森吉尔的意志，纵使强大，却在卢尔贡的灵能伟力下崩溃，大不净者随即渗入她的灵魂，完全占据了她。随着烛火熄灭黑暗降临，森吉尔双膝跪倒，发出歇斯底里的狂笑，而她的侍僧们则瘫倒在地，自耳鼻流出脓液。

然而卢尔贡却被囚禁在了审判官体内，因为森吉尔的意志足以束缚这头恶魔。盛怒之下，卢尔贡在宿主身上唤起一场剧毒疫病，尽管这同样被伊克'萨尔'迦尼克斯的魔法所侵染。它所带来的并非脓疱、溃烂与渗液创口，而是纳垢与奸奇的亚空间巫术交织产生的一场疯狂瘟疫，瘟疫之神的腐烂能量与命途变更者的诡计彼此融合。不出一小时，审判官的舰船，“朝圣者”号，便被疯人们占领，人们抓挠自己的脸，啃食自己的皮肤或是把自己抛进冰冷的真空中。数月后，当“朝圣者”号飘入内政部的中枢星系德西马勒斯时，船上只剩下披着森吉尔皮囊的卢尔贡，以及少数几位早已疯掉的审判官侍僧。卢尔贡利用审判官的密码向德西马勒斯主星通讯求救。一周之内，疯狂瘟疫就感染了星系中的每一座世界。一个月之内，德西马勒斯的内政部领主们便为卢尔贡所奴役，而恶魔的腐朽已经染指十余个世界的总督阶层。

# **虚空战刃**

在银河系的另一端，泰坦堡垒之内，预言者们感知到德西马勒斯星系传来的扰动，如同现实被不断撕裂出伤口。根据他们的警告，卡尔多·德莱戈召集诸位大导师并阐述了他镇压入侵的计划，在雅努斯雕像的石质目光之下。由于没有时间集结整个战团，德莱戈命令泰坦上所有的灰骑士武装起来。部分大导师质疑这种战略的明智性，担忧泰坦从未处于如此疏于防御。最终是大导师瓦尔达·奥里孔，灰骑士智库的领袖，说服了议会。奥里孔研究了预言者的预言与帝皇塔罗的预兆，全都暗示这场瘟疫更明显的来源背后潜藏着一个古老敌人。大导师认为这个敌人正是万变魔君伊克'萨尔'迦尼克斯，一头长期躲避战团的恶魔。奥里孔还在占卜中揭露了审判官森吉尔与这场瘟疫的关联，以及低语者骨骸的秘密。大导师们一致同意消灭这头恶魔的机会不容忽视。第三、第五和第八兄弟会随即离开泰坦，仅留下少数净化者守望净化大厅，以及少到危险的灰骑士负责防御。

灰骑士打击巡洋舰辟开非物质界航道，在数日内跨越了五万光年，亚空间驱动被逼至公认公差之上。当舰船从亚空间跃入德西马勒斯上空，他们立即就遭到了攻击。行星上空的夜幕迸发出夺目的闪光与烈焰，随着轨道防御平台倾泻出风暴般的宏炮火力与鱼雷齐射。轨道平台充斥着互相交战的奸奇与纳垢恶魔，许多都占据着疯人的残破躯壳，早已陷入旷日持久的内战，直至灰骑士抵达。德莱戈当即作出反应以确保轨道炮台被压制，他选定修士连长斯特恩与第三兄弟会完成这项任务。趁德莱戈与其他兄弟会乘打击巡洋舰牵制防御力量，斯特恩率领战斗兄弟们进攻“虚空战刃”号，这座德西马勒斯的关键轨道要塞。

伴随一道冷光闪耀，灰骑士终结者出现在“虚空战刃”号的指挥甲板上，背靠背准备迎击他们敌人的冲锋。从指挥站与占卜仪平台，数十双被恶魔盘踞的眼睛盯向他们，破败的嘴唇在烂牙前蜷起，而宿主们蹒跚着向新敌人扑来。因为命令是尽可能保留虚空之刃的运转能力，斯特恩指挥部下压低风暴爆弹枪以免损坏任何重要系统。战斗兄弟们口中念诵着对帝皇的誓言，举起力场戟冲向敌群。

又有六支灰骑士终结者小队传送到“战刃”号的关键任务区域，杀入恶魔与被附身的船员当中。很快，这座虚空要塞血迹斑斑的走廊与污秽覆盖的舱室中，便回荡起利刃切入血肉的钝响，以及恶魔狂怒与痛苦的嚎叫。

在德西马勒斯地表的内政部枢纽尖塔的王座室中，卢尔贡透过森吉尔的双眼注视着图像记录仪上的屠杀。垂涎着脓液期盼灰骑士到来，恶魔亲王将目光投向挂在厅墙上的骸骨，思忖着他对伊克'萨尔'迦尼克斯的复仇已近在咫尺。不过，就目前而言，卢尔贡只能满足于屠杀灰骑士，于是他向亚空间发出呼唤，召集自己的军团投入战局。

斯特恩扫视着自己制造的屠杀，身体碎体几乎覆盖了每一寸甲板。他将目光投向数据密会与休眠机仆，提醒兄弟们德莱戈的意愿是让这座要塞为灰骑士所用。

甲板突然间在斯特恩脚下震颤，令他摔倒在地。他一时愣神，震惊地看着一只巨型机械爪撕开舱壁，将他的一名兄弟撕碎成血雾。一台磨魂者从破碎的塑钢爬进指挥舱，半是恶魔，半是机器。它巨大的机械腿占据了整个房间，而它病态的绿色血肉渗出涓涓黑血。

斯特恩猛冲向前，高举剑刃，而他的兄弟们则用长戟劈砍它的肢体。怪物似乎对攻击毫不在意，它居高临下地逼近斯特恩，一只巨爪扫开他的剑刃，另一只则将他按倒在地。受制于野兽的亵渎力量，斯特恩深陷困境，无法挥动剑刃。绝望之中，斯特恩把风暴爆弹枪对准指挥甲板的观察窗，并用通讯向兄弟们发出警告。当装甲玻璃向虚空爆裂时，磨魂者被吸入了太空。斯特恩一度被拖过甲板，巨兽的爪子仍紧紧钳着他，幸亏兄弟们行动迅速把他拽了出来。站在这已无空气的舱室中，被他们的盔甲锁固在甲板上，灰骑士瞄准了飘远的恶魔，用灵能炮、爆弹枪与灵能火焰将其轰碎。随着它最后的本质消散于冰冷真空，斯特恩发出了讯息：“战刃”号是他们的了。

# **以帝皇之名**

轨道防御静默后，卡尔多·德莱戈率领第五与第八兄弟会降落在德西马勒斯主星地表。战团智库们已经准确指出灵能顽疾的核心在行星北极大陆上的内务部枢纽尖塔。德西马勒斯位于五个星区中央，是帝国控制昆托星区交汇处的中心，在此有百万灵魂统治着无数亿兆子民。轨道图像的阴影处显示德西马勒斯的地表——一座庞大、绵延的城市，已经被疯狂瘟疫吞噬。烈火在破碎的居住塔残骸中失控燃烧，被附身的市民在街头混战，或是用割碎的人体搭建渎神偶像。恶魔悄然追踪着少数幸存者：那些免于疯狂的男女，却要遭受昔日同胞制造的恐怖。

由于卢尔贡与瘟疫引发的亚空间能量波动，德莱戈无法直接传送到枢纽尖塔，因为他的终结者小队在非物质界中迷失或在要塞墙体内重新实体化的风险实在太大。因此，至高大导师着眼于尖塔附近的一处地点，那里仍有帝国抵抗力量在坚守。通过疯人们宣泄的混乱通讯广播，灰骑士探测到一个低如细语的信号，正吟诵着对神皇的赞美诗。在一座辉煌不再的帝国大教堂的残骸废墟中，一支修女会分殿仍在奋战。朱红之手修会将疯人与恶魔拒之门外，颂祷宣讲器向敌人高奏帝皇圣言。

大修女卢娜莉亚和她的姐妹们已经抵挡了疯狂瘟疫数日。唯有修女会的信仰一直阻止疯狂感染修道院，只因魔疫传染的媒介是谎言和怀疑。即便如此，近千名修女中如今也只剩不到两百人，许多人都被迫把爆弹枪当作钝器使用以节省弹药，同时还要抵挡受感染民众的进攻。当卡尔多·德莱戈携一百名灰骑士伴随一阵金光出现在她身后时，卢娜莉亚当即感谢帝皇赐予她们救赎。片刻之间，那些银甲巨人就清扫了大教堂的城墙，将那些魔物赶回阴影笼罩的废墟中。随着最后一声爆弹枪响渐息，卡尔多·德莱戈走到大修女面前，用泰坦之剑向她致敬，借以表彰她姐妹们的英勇。卢娜莉亚摘下她凹陷的头盔，抬头望向至高大导师，将汗水浸湿的头发从脸上拨开。战斗兄弟和修女们看着两人低声交谈，直到卢娜莉亚默默地重新戴上头盔，然后命令修女会准备推进到废墟中。接受了这将意味着她们的死亡，每一位战斗修女都念诵了一句祈祷，然后在她们的大修女周围列队。

区域肃清后，德莱戈召来了支援单位，重型登陆艇与风暴鸦炮艇从轨道上呈弧线下降，掠过这座残破城市的地平线。兰德掠袭者与无畏落地时碾碎了古老的街道。两支兄弟会随即分头行动，各自执行任务。至高大导师已经制定了一项计划，不仅要击败卢尔贡、终结疯狂瘟疫，还要将伊克'萨尔'迦尼克斯逼出阴影。德莱戈登上领头的十字军型兰德掠袭者，而战斗修女们则登上她们一直用作固定炮台的犀牛。第八兄弟会与修女会一齐隆隆驶入废墟，其余灰骑士则动身打击尖塔周围的目标。

# **鲜血与信仰**

此时完全发觉入侵者的卢尔贡，召集起他的魔群前来摧毁他们。从这座受诅之城的每处角落，纳垢仆从们纷纷骚动起来。野兽与携疫者、纳垢灵与被感染的市民——全部蹒跚、蠕动、踉跄着涌来防守尖塔。在领头的兰德掠袭者中，德莱戈可以看到空气中逐渐密布胀蝇，而狭窄的街道也渐渐挤满了流泪、化脓的形体。他命令坦克直接碾过它们，它的武器向人群播撒死亡。兰德掠袭者的机魂饥渴咆哮，载具毫不停歇地继续前进，将恶魔的血肉碾入地面，并逼退了兽群。当他们快速穿行于巷弄间时，德莱戈瞥见战斗修女的犀牛在并行道路上犁穿了恶魔。修女们紧附在运兵车的侧面与车顶，用爆弹枪精准地向混战开火。

从魔群中，一名满身脓液的军锋闯入视野，身侧环有七头庞大的纳垢兽。兰德掠袭者撞上野兽时骤然停下，受祝钢铁与亵渎腐肉相互角力。就在坦克挣扎脱身时，军锋猛冲上前，将一柄锈蚀刀刃刺入车体。本该能抵御激光炮的装甲在刀锋下腐蚀崩解，就在突击坡道开启的瞬间，坦克的引擎爆炸成了烈焰云团。

由于靠近坡道，德莱戈被爆炸掀飞，重重摔落在数码外的地面上。灰骑士们奋力挣出残骸，但每有一人爬出，便会被数十只恶魔压倒。德莱戈拔出泰坦之剑，起身为兄弟们杀开一条血路。在身后某处的道路上，德莱戈能听到爆弹枪开火的声音，但他已经无暇顾及，恶魔正从四面八方朝他袭来。如同尸体上的苍蝇一般，废墟中活跃起纳垢之嗣，成千上万的恶魔列阵对抗着十余名灰骑士和他们的至高大导师。

德莱戈毫不动摇，继续推进，用剑刃、拳头与灵能火焰摧毁恶魔。一柄锈蚀刀刃砍中德莱戈的背甲，随即腐烂的手指紧紧抓住他的持剑臂，一只携疫者的朽烂面孔离他面甲仅有数寸，正咳出剧毒痰液，成群的纳垢灵啃咬着他盔甲的密封。至高大导师感觉自己正一寸寸地没入恶魔秽物的汪洋，他的兄弟们不过是亚空间孽种翻腾巨釜中的几点银色。然后，一道微弱的赞美诗传入他耳中。他起初以为那是通讯回音，但那音量逐渐增大，直到德莱戈听清那是众多声音在齐声赞颂帝皇。一阵风暴般的受祝爆弹火力粉碎了魔群，这些诅咒生物在修女会的怒火与信仰面前纷纷退却。由大修女卢娜莉亚率领，她的盔甲破碎且血迹斑斑，幸存的修女们冲入废墟，周身金光环绕，用喷火器和热熔枪近距离击退纳垢恶魔。魔群在新的攻势下退缩而去，德莱戈终于辟出通往兄弟们的道路。然而，战斗修女为德莱戈争取到的不过是片刻时间，亚空间孽种已经集结起来准备再次进攻。因为深知真正的敌人潜伏在枢纽尖塔内，德莱戈转向卢娜莉亚。大修女点头应允，理解并接受她的姐妹们将以生命为代价，为灰骑士争取再多片刻的时间。转身背对进行着最后抵抗的修女会，德莱戈继续向尖塔推进。

# **疯狂尖塔**

枢纽尖塔的恐怖防御使得直接强攻无法实现，因此德莱戈早已派遣第五兄弟会瘫痪极地城市的能源供应。战斗兄弟穿过废墟杀入被恶魔占据的反应堆与传导主接点，将它们逐一摧毁，并关闭了如哨兵般环绕尖塔矗立的巨型光矛炮塔。随着炮火沉寂，灰骑士得以集中突破封锁堡垒大门的恶魔结界。五支灰骑士终结者小队紧密列阵，两侧各有一台天罚恐惧骑士，由卡尔多·德莱戈亲自率领，沿着宽阔的坡道向枢纽大门攀行。伴随灵能火焰环罩头盔，战斗兄弟们将自身力量联合成一道无声脉冲，指向他们的指挥官。作为法术的聚焦点，德莱戈将这股灵能能量传导为烈焰长矛，所过之处尽数焚毁。大门前那些未倒在恐惧骑士炮火与利刃之下的恶魔，亦被火焰席卷，随着实体形态爆开，伴随湿漉的破裂声消散。如同尸体腐烂的胸腔般，枢纽的大门爆裂开来，喷涌出洪流般的纳垢灵与难以名状的秽物。恐惧骑士踏过齐膝深的毒潮进入尖塔，他们的武器灼热燃烧开辟出道路。

灰骑士杀过尖塔内如肠道般的隧道与大厅，卢尔贡也派出无数爪牙阻拦他们前进的每一步。最终，德莱戈站在了王座室的大门前。正是在这里，至高大导师命令他的兄弟们驻留，尽管他们强烈抗议。德莱戈明白，吸引伊克'萨尔'迦尼克斯进入战斗的唯一方法，是向它展现一个诱人到无法忽视的对手。于是，卡尔多·德莱戈独自进入了卢尔贡的所在之地，他冷漠地注视着森吉尔宿主布满血丝的双眼，她的血肉被栖身其中的惧物扭曲得肿胀可怖。德莱戈同样注意到了低语者的骸骨，正散落在大厅各处。

在恶魔与灰骑士举剑之前，地上的骸骨便开始躁动，闪烁的亚空间巫术在它们之上游走，而伊克'萨尔'迦尼克斯的刺耳狂笑回荡在室内。森吉尔宿主呕出灰色蛆虫，蹒跚着向那残骸扑去，卢尔贡在其眼后翻涌愤怒。德莱戈屹立不动，等待着奸奇恶魔显化，任由纳垢亲王试图实施复仇。骸骨乘着灵风聚拢合一，化为低语者高耸的鸟类形态。卢尔贡尝试攻击那骸骨造物，但被囚禁在森吉尔宿主内，他只能受制于所披血肉的孱弱。通过骸骨引导魔法，伊克'萨尔'迦尼克斯攻向卢尔贡，远古恶魔的利爪撕入死去审判官的腐烂血肉。如同被剖开的鱼，宿主栽倒在地，超自然的脏腑倾泻满地。

随着卢尔贡被暂时解决，活化骸骨转向了德莱戈，伊克'萨尔'迦尼克斯的影态开始在其周围凝聚成形。它抬手给房间大门施下妖法，将德莱戈与他的兄弟们隔绝开，随后才完全显化向至高大导师尖声啸出挑战。德莱戈的回应是触发传送讯号(homer)，斯特恩与三十名灰骑士终结者伴随一阵光化闪烁化为实体。现在恶魔的尖啸转为了愤怒与挫败：它未曾预见到这个。率领这些战士的凡胎，仿佛是遮蔽它视界的黑色裹布，他的命运已经为他者所有*，不知何故连他自身的恶魔预知都无法窥见。伊克'萨尔'迦尼克斯无瑕思索自己如何被算计，灰骑士已经发起冲锋。万变魔君弃骨而去，遁回了亚空间，但在此之前，它切断了将卢尔贡与破损的森吉尔宿主绑定的灵能纽带。

*：是谁啊，姆'卡你有头绪吗

随着血肉爆裂卢尔贡自森吉尔宿主中爬出，显露出它完整、可怖的形态。德莱戈别无选择，只能将注意转向这尊纳垢恶魔，用泰坦之剑的惩戒打击率先进攻。卢尔贡激烈抵抗，巨爪击碎陶钢与骨骼，并将敌人淹没在大团腐物中。然而，他并非卡尔多·德莱戈与修士连长斯特恩联合之力的对手。斯特恩念出放逐真言，将恶魔掷回亚空间并斩断了它的归路。随着卢尔贡与伊克'萨尔'迦尼克斯离去，瘟疫被击破了。整个星球乃至更远之处，那些褴褛凡人从失常噩梦中醒来，对先前发生的一切毫无记忆。低语者的骸骨被灰骑士仔细收集并带回了泰坦。德莱戈则立誓下次他与万变魔君狭路相逢时，绝不会容它再有逃脱的机会。
