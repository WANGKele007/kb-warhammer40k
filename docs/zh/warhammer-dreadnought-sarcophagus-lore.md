眾所周知無畏機兵並非機器人，而是由重傷的星際戰士負責操作，他們除了是威力強大的戰爭兵器之外無畏機兵也是戰團珍視的聖物，是戰團與自身過往及傳承之間最直接的連結，被安置進無畏機兵之中是一項極其崇高的榮譽，也是星際戰士所能從自己戰團獲得的最高榮譽之一。

 但實際上無畏機兵能分成兩個部分，分別是外部的機甲和內部的石棺 ( sarcophagus )，石棺本體其實就是個生命維持艙，殘缺的戰士浸泡在維生液體之中，他的神經會與心智脈衝傳導線路連接，藉此接收外界的感官資訊，駕駛者仍能如同自己擁有血肉之軀時一樣看見與聽見外界。

 實際上可以拿先鋒軍的不敗者機甲 ( Invictor Tactical Warsuit ) 來理解，八版開始的星際戰士軍書裡就提到了不敗者機甲是救贖者無畏的簡化版，中間的駕駛員穿上動力盔甲後連接系統來控制，所以無畏機兵其實就是裝上石棺的不敗者，不敗者就是去掉石棺的無畏。

 這裡拿模型來參考，救贖者無畏中心那個就是石棺，從小說【靈魂獵人】可以看到，一般情況下是把石棺放置在靜滯力場內，等到需要時才會將石棺與外部的機甲組合，過程得花上好幾個小時：

 鏗鏘作響的起重機將那具巨大的石棺從追思殿堂大理石地板上的靜滯坑中緩緩吊起，負責操作起重設備的是一群機僕，他們的單一任務性具備機械般精確無誤的動作正是這場再甦醒儀式不可或缺的一環。

 塔洛斯注視著那具龐大的棺槨，它由鉑金、青銅與黑色陶鋼打造，其大小相當於兩名身著全套終結者裝甲的星際戰士，隨著石棺脫離靜滯坑的固定裝置被緩緩吊至半空，一條條管線、輸送管與纜線從下方垂落，每一條都有其神聖的用途，這些如纖維長蛇般的管線不斷滴落冷卻液，在如此漫長地浸沒於靜滯力場之後，水珠開始於這片宛如墓室般陰冷肅穆的空氣中凝結。

 第一利爪的眾人懷著無聲的敬意，看著石棺被運送穿過整座大廳，然後在預先設定好的精密程序控制下緩緩下降，另外幾名機僕早已等候在下方，他們聚集在一具高聳的裝甲軀殼周圍，其高度足足有阿斯塔特三倍之高，機僕原本的雙手早已被工業用機械鉗與各式技術工具取代。

 此刻那些機械肢體正不停地在龐大的機體上忙碌進行最後的準備工作，以便將正在下降的石棺安裝至這具機械軀殼的正面。

 無畏機兵。

 光是這個名字便讓塔洛斯感到一股冰冷的寒意流過血液，然而，與眼前真正存在的事物相比——

這個名字根本算不了什麼，無畏機兵：人與機械最極致的融合，一名阿斯塔特英雄的殘軀，被封存在華麗的石棺之中，永遠浸泡在羊水般的維生液體裡，懸停於死亡邊緣，而被囚禁在其中的那份意識，則操縱著一副近乎堅不可摧的陶鋼軀體，一具能夠行走的戰爭機器。

 小說【無所畏懼Know no Fear】也有類似橋段：

 特勒梅克魯斯是第十三軍團中最新加入的無畏機甲，他屬於蔑視者型，尚未經歷過實戰，在馬格拉格的艙室內他們例行復甦時喚醒了他一次，他體內的植入時鐘顯示他已經沉睡了兩年，技術神甫們告知他，一項軍事行動正在進行，他將被重新安裝到機體中，運往卡斯部署，並在戰爭爆發時再次被喚醒，這場戰爭的對手是獸人，特勒梅克魯斯有很多疑問，但他們又讓他回到了催眠治療的夢境中。

 有一點挺有趣的是特勒梅克魯斯無論是軍團士兵或是無畏機兵來說都算新兵，而且他每次都是莫名被喚醒機械神甫或其他無畏前輩開導他後就直接關機讓他睡覺 :P

 順便補充一下，小說背叛者裡有提到為甚麼蔑視者無畏機兵仍要裝上頭部，這有助於將駕駛員的意識集中向前，神經感覺輸入/輸出中留下仍然活著的印象，他們看到的景象和生前一樣：以人類的視角出發，鐵壘型和救贖者型表示頭部是啥？

 機會難得順便補充一下，技術上來說無畏機兵不是星際戰士限定的，因為無畏機兵的駕駛要求也沒說要經過改造或有黑色甲殼，反而會將多餘的器官摘除後放入其中，The Horus Heresy Book One - Betrayal裡提到原形無畏機兵在統一泰拉的過程就投入了，戰鬥修女用的贖罪機甲原理上類似無畏機兵 ( 但是贖罪機甲不用切器官 )，禁軍也能使用無畏機兵，但一般是蔑視者型甚至更高級了。

 喔對了，我看到有個說法是說禁軍的無畏可以不用進入長期睡眠自由活動，我是沒看到具體出處但挺有可能的，畢竟禁軍已經不能用正常人類來看待，禁軍有全無畏組成的亡騎衛士 ( Moritoi )，也有那種從野獸之戰甚至大叛亂末期 ( Calaxor ) 進無畏到42K還在打的，以星際戰士來說這種已經是個狠人，但是禁軍那邊似乎很正常 :P

 接著要進入主題了，那麼無畏機兵是否可以更換呢？

 這裡的＂更換＂有兩種意思，一個是原本機兵損毀後換到另一台機兵上，這個肯定是沒問題的，前面有提到無畏機兵原則上分為外部機甲和內部石棺，所以機甲的部份可以更動，例如維修或是更換武器都可以，只要石棺沒事就能繼續使用。

 另一個就是從Ａ型號的機兵換到Ｂ型號上，例如從鐵壘換成蔑視者，從背景來看這個也可以，目前能找到具體更換的案例有兩個，一個是暗黑天使的鋼鐵使者泰圖斯 ( Ironbringer Titus )，這位是大遠征和大叛亂時期的人，可以參考小說恐懼之翼 ( Dreadwing，2018 ) 第二章的片段：

 尊貴的泰圖斯矗立在它面前，身軀被封裝於鐵壘型無畏機甲那厚重如巨板般的精金裝甲，以及稜角分明、彼此垂直交錯的裝甲結構之中，漆黑如墨的機體上裝飾著六芒星徽記，此外還遍布著大量獨特的紋章與圖案，這些標誌所指涉的，是那些歷史極為悠久的騎士團與兄弟會——它們的存在遠早於卡利班被納入人類帝國之前

 一襲樸素的白色罩袍，從這具龐大戰爭機器的腰胯關節處垂落，在氣流中微微飄動，泰圖斯原本使用的蔑視者型無畏機體早已犧牲於戰場之上；然而，保存著他凡人殘軀的石棺卻安然無恙，並被妥善安置於戴亞馬特的大將軍砲戰爭引擎之中，在那些戰爭機器被移交給佩圖拉博之前，泰圖斯的石棺便已被取出，送回了「無敵理性號」。

 上述片段其實就說得很清楚了，原本蔑視者機甲被打爆了，石棺沒事，後面還能裝到鐵壘型上。

 順帶一提LEX上有寫到小說【Fallen Angels】還有提到另一個橋段，暗黑天使的部隊被叛軍圍困時為了啟動一挺攻城砲 ( 不確定是不是上面提到的大將軍砲 )，直接把提圖斯的石棺連接到攻城砲上頭控制爆打荷魯斯之子，這也說明石棺是能夠脫離機甲外殼使用的。

 另一個則是鋼鐵之手的弗努斯 ( Furnous )，這個是有明確更換型號的，六版時期他是神聖無畏 ( Venerable Dreadnought )，42K時期突襲某個採礦世界時後變成了救贖者，這個應該是單純把石棺移到新的外殼上，不然真的氣笑了，冰冷的戰團先烈變成溫暖的電池，怕不是為了給無畏謄空間。

 所以無論是同型號或是跨型號都可以，只要石棺還在就沒事 :)
