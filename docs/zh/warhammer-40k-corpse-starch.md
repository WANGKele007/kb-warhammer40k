屍體澱粉 ( Corpse-Starch ) 這個東西大家一定不陌生，這簡直是帝國物盡其用的最佳寫照，畢竟官方自己也使勁玩梗，生是帝國人死了包餛飩，戰友好吃，不過這食物具體到底是啥大家可能也不是很清楚，今天來作個簡單介紹：

**一、屍體澱粉甚麼時候開始有的？**

 這東西從1995年出版的Necromunda Sourcebook就有登場了，書中說明巢都人民主要的食物是工廠生產的化學營養劑、藻類或用屍體澱粉製成的，這應該是最早有明確提到屍體澱粉這個字的出處，一直到現在都有出現。

**二、屍體澱粉真的有加屍體嗎？ **

 從2023年出版的規則書【Imperium Maledictum】介紹來看，屍體澱粉這種乏味的灰色糊狀物散佈在帝國遍處的某些巢都世界以及那些較為不幸的星界軍軍團中，它能夠同時處理無數死者並為倖存者提供營養，其生產過程受到嚴格監督，最終產出一種統一的餐食，摻入任何物品或不同人員參與都無法撼動其本質。

 所以，對，屍體澱粉真的有加屍體。

**三、屍體澱粉怎麼做的？**

 白矮人2019年12月 ( 449期 ) 有提到屍體澱粉是如何製作的，會有個蛋白質回收機 ( Protein Reclamator )，把屍體 / 肉類 / 某些不幸掉進去的人絞碎加工而成，對於大名鼎鼎的涅克羅蒙達（Necromunda）巢都裡人民來說屍體澱粉是他們的主要蛋白質來源，儘管他們不是很樂意吃這些東西。

 GW介紹涅克羅蒙達的模型也有提到，在涅克羅蒙達上有個屍骸公會 ( Corpse Guild ) / 蒼白商會 ( Mercator Pallidus，高等哥德語 ) 專門負責生產與貿易屍體澱粉，他們會派出「屍骸收割隊」去收集供應各個巢都「屍磨工廠」所需的原材料，這些隊伍充當著死肉的勘探者，獵取著成堆適合回收的「新鮮」遺體，當幫派之間爆發戰爭時，這些屍骸收割隊便會趕赴現場收割新鮮的屍體。

 至於為甚麼要吃這東西，2019年出版的【Necromunda: The Book of Peril】關於屍體公會的介紹就說得很清楚了：

 1. 涅克羅蒙達上每日產生的屍體數量眾多，不清除的話巢都會被屍體和其產生的疾病所摧毀。

 2. 對巢都來說這些屍體是不錯的蛋白質來源，若沒有這些屍體澱粉，巢都將在幾週內餓死。

 所以並不是說甚麼屍體澱粉是錯誤理解或者不一定加屍體，而是屍體澱粉本身就是為了處理屍體物盡其用拿來吃，我的猜測是類似雪國列車 / 末日列車 ( Snowpiercer ) 裡的蛋白加工棒，屍體是主要材料。

**四、人們是否知道屍體澱粉裡加了屍體？**

 至少負責收屍和負責製作的人知道，但帝國或者公會不會明晃晃的說「喔對你的兄弟姐妹上一餐被你吃了」，比較像是心照不宣，儘管名稱就叫屍體澱粉，不過這可能類似很多食物的俗稱或惡名，只不過這個是真的加了屍體，蒼白商會自己也說了：

 「大眾最好不要知道他們所消費之物背後的真相，因為許多人會發現，為了我們這項偉大工作之必要性，他們的理智會被擊垮，屍磨者正是如此：他們是看見了真相，現在卻在異端懷抱中尋求慰藉的意志薄弱之徒。」

 小說【Fire Made Flesh，2021】裡公會成員討論的內容：

 「據說他的胃口不僅限於那些重組後的死者血肉。他手下僕人的流動率高得驚人。」

 「偉大的人物總有些古怪癖好，」英蘇萊說。

 「我的觀點不變：一名屍骸公會成員被看到往喉嚨裡塞垃圾時會樹立一個壞榜樣，話說回來，那到底是什麼？」

 「赫特魚（Hetelfish）。」

 「魚？」英蘇萊說著，輕微地乾嘔了一下，「竟然有人吃那種東西？真噁心。」

 「我們必須嘗試不同的風味，這樣我才能把這些知識帶回我們自己的廚房，你嚐過我的合成格洛克斯牛排嗎？它現在在巢都城非常流行。」

 「我吃過，但不怎麼喜歡。裡面幾乎吃不出屍體澱粉的味道。」

 「這多少就是它的賣點，」索羅回答。

 「那些較富裕的工人喜歡這種幻覺，讓他們覺得自己的晚餐事實上並非由人類遺骸殘渣和巢都真菌研磨而成的灰色糊狀物。」

 「有些人就是不願接受現實世界本來的樣子，那不是我的問題，」英蘇萊聳聳肩回覆道，「在這裡用餐一定很貴。」

**五、這東西會不會有影響？**

 上面已經提到結果了，涅克羅蒙達上有個屍磨教派，主要在屍體澱粉產線上的工人和屍體公會內蔓延，這些工作到瘋掉的工人被恐虐蠱惑跑去殺人，後來發現比起屍體澱粉新鮮的血肉更美味，涅克羅蒙達各大公會和家族都知道他們的存在，這些屍磨者過去曾經佔領過一個巢都逼大家吃生肉，最後是封閉起來等他們餓死。

**六、只有涅克羅蒙達巢都吃這東西嗎？**

 雖然關於屍體澱粉的資料絕大多數來自涅克羅蒙達的相關規則書，但一開始的RPG規則書裡就說了，這個難吃的東西散佈在帝國某些巢都世界以及那些較為不幸的星界軍軍團，後面關於什一稅的部分也有提到：

 每個巢都世界通常擁有一到四個專屬的農業世界以確保其民眾有足夠的食物，隨後再輔以各種在該星球上生產的穩定物資，例如屍體澱粉、營養膏 ( nutrient paste )、各種真菌以及養殖藻類。

 更之前的RPG規則書【Dark Heresy Core Rulebook，2008】裡也有提到：

 無數巢都人所呼吸的空氣是從上方的尖塔回收，並抽送到其餘部分；空氣向下過濾得越深，就變得越發苦澀且充滿毒性，甚至連水也是從上層巢都的排放物中蒸餾而來的，而食物則是工廠生產的，有時以藻類為基礎，或由屍體澱粉旋製而成。

 口糧包 ( RATION PACKS )

 帝國中的大多數食物都經過包裝與加工，通常完全看不出任何可食用的模樣，口糧包的品質差異極大，從簡單且低劣的餐食如屍體澱粉口糧和人工養殖藻類，到帶風味的格羅克斯肉條以及最精良的營養糊應有盡有。

 2020年出版的RPG戰役書【Wrath & Glory: The Graveyard Shift】發生的場景就是在戴思隆 ( Daedalon ) 上的一座屍體澱粉製造廠，很搞笑的是這工廠和國教教堂直接蓋在一起：

**Barastyr Cathedral / 巴拉斯特大教堂**

 巴拉斯特大教堂的建立是為了不斷提醒人們這座墓地衛星的用途；它是帝國建築中宏偉得令人不安的典範，將數千名國教信徒的骨骸融入其沉重的結構中，這座氣勢恢宏的大教堂由一個巨大的大廳組成，定期舉行的佈道會時間安排在聖形修道院勞工的輪班間隙，大廳周圍有許多用於私人崇拜和教會儀式的小禮拜堂與聖所，還有一條環繞著特工抵達的降落坪、通往聖形修道院的迴廊。

**Crypts Exalted / 尊崇墓穴**

 巴拉斯特歷史上最重要人物的骨骸陳列於此處的玻璃混凝土棺木中，其中最著名的莫過於巴拉家族的創始國教教主，尊崇墓穴位於大教堂兩側的耳堂，由巴拉斯特上流階層僱用的十名執法者不斷進行巡邏。

**Priory of the Sacred Form / 聖形修道院**

 聖形修道院是巴拉斯特大教堂的一座巨大附屬建築，也是一處屍體澱粉加工設施，它既是教堂也是工廠，是該城市最大的勞動力僱主之一，大教堂的祭司職責所在，必須祝福所有運送到巴拉斯特的屍體，負擔得起葬禮的人會被送入墳墓。負擔不起的人則被宣布不再是「人類」；他們的靈魂已離去追隨帝皇，而他們的肉身現在則是餵養帝皇子民的肉食。

 這座龐大設施的其餘部分更像是一條生產線，成千上萬的人在那裡孜孜不倦地工作，將屍體轉化為粉狀、乏味的食物，骨骸被提取出來作為建築材料，或者與死者的遺物一起在「紀念廣場」上作為「聖物」出售，顱骨則被送往「伺服顱骨製造廠」。

**七、星界軍內到底有沒有配給屍體澱粉？**

 從上面提到的規則書裡是有但不是普遍發放，儘管大部份關於星界軍的小說都沒提到屍體澱粉，但在GW官方社群的文章，例如以前的軍團刊物 ( regimental-standard ) 或是部分模型的宣傳文裡都會大量提到屍體澱粉 ( 搞笑的是你很難分出來哪些是玩梗還是真的設定 )。

 這本書裡面呈現出來的Soylens Viridians跟屍體澱粉是兩種東西，Soylens Viridians是重組的豆類製成，同樣沒啥味道，機械教人員很喜歡。

 但在遊戲【Necromunda: Hired Gun】中在Soylens Viridians的精煉廠內有個牌子內容很有意思：

 「為了您自身的安全，請勿攝取未經加工的合成豆膏原粉。」本訊息由屍骸公會提供，並經由帕拉尼特執法者許可。

 另外在遊戲【Warhammer 40,000: Gladius】星界軍的食物建築也有提到類似的東西：

 合成豆膏或許能讓人有飽足感、營養豐富且易於在大桶中培育——但作為一種食品，它也有一些缺點：第一，它極其乏味且毫無風味；第二，它看起來就像綠色的黏糊狀物；第三，它是由任何可以獲得的有機物質製成的，一直有傳言稱人類屍體也在選項之內。

 總之如果從小說來看它就是單純用豆類合成的食物，如果結合遊戲敘述就可能是類似屍體澱粉那樣參了屍體、豆類和任何有機物組成的混合物，甚至可能只是另種形式換個名字的屍體澱粉，畢竟帝國很大啥事都有可能，但不能直接把Soylens Viridians跟Corpse-Starch畫上等號，至少目前看這兩個有差。

 簡單作個總結：

 一、屍體澱粉真的有屍體，同時也會加入其他物質。

 二、屍體澱粉的目的是清理屍體。

 三、除了涅克羅蒙達之外其他巢都、世界和星界軍軍團也會食用。
