*记录来源：神圣泰拉，地下实验室，雷霆战士创造计划*

*时间戳：M29，统一战争前夕*

*与会者：帝皇（人类之主），马卡多（摄政），第一批雷霆战士（实验体），无数个消费者（投资人）*

*内容真实性：雷霆战士们临死前说：“值了。”*

# **一**

泰拉统一战争前夕。

帝皇站在地下实验室里，面对着一群科学家。

“我需要一支军队。”他说。“比星际战士更早的军队。比禁军更便宜的军队。比凡人更强的军队。”

科学家们面面相觑。

“陛下，”一个老科学家小心地问，“可是资金不够。”

帝皇点头。

“我知道。”

“没有资金，怎么创造军队？”

帝皇沉默了一秒。

然后他问：“你们知道什么生意最赚钱吗？”

# **二**

科学家们愣住了。

“生意？”

帝皇点头。

“生意。”

没人敢回答。

马卡多从角落里走出来。

“吾主，”他小声问，“您该不会是想——”

帝皇看着他。

“想什么？”

马卡多咽了口唾沫。

“卖那个？”

帝皇点头。

“卖那个。”

# **三**

实验室里陷入死寂。

科学家们看着帝皇。看着马卡多。看着彼此。

“那个？”一个科学家小声问。“哪个？”

另一个科学家指了指自己的裤裆。

“那个。”

第一个科学家的脸白了。

“陛下的——那个？”

马卡多点头。

“陛下的那个。”

# **四**

“可是，”一个勇敢的科学家举手，“陛下的那个……能卖多少钱？”

帝皇想了想。

“很多。”

“多到什么程度？”

帝皇看着他。

“多到能创造一支军队。”

科学家们沉默了。

然后有人问：“谁买？”

帝皇笑了。

那个笑容，几万年后被记载为“商业之始”。

“全泰拉的人。”他说。“每个人，都需要一个梦想。”

# **五**

第二天，帝皇钩子公司成立。

产品：帝皇限量版那个。

金色的。柱状的。一头粗一头细。装在透明的水晶盒子里，盒子上印着帝国鹰徽。

定价：一万泰拉币一个。

广告词：“拥有它，你也能像帝皇一样——统治一切。”

马卡多看着广告词，皱眉。

“吾主，这能行吗？”

帝皇看着他。

“你质疑我的商业头脑？”

马卡多摇头。

“不是质疑。只是觉得——谁会花一万泰拉币买一个那个？”

帝皇笑了。

“你看着。”

# **六**

第一批货，一万个。

上架第一天，售罄。

买家反馈：

“用了之后，我真的开始统治我的家庭了。老婆孩子都听我的。——泰拉平民”

“感觉精力充沛，每天只想征服世界。——某军阀”

“虽然只有一个，但我觉得自己在发光。——某不明真相的消费者”

马卡多看着销售报告，目瞪口呆。

“真有人买？”

帝皇点头。

“真有人买。”

“为什么？”

帝皇想了想。

“因为他们想成为我。”

# **七**

第一批雷霆战士，就是用这笔钱创造的。

科学家们拿着帝皇卖那个的钱，买材料、做实验、培养胚胎。

三个月后，第一批雷霆战士诞生了。

他们比凡人强千万倍。比星际战士早近700年。比禁军便宜无数倍。

帝皇站在实验室里，看着这些新生的战士。

“你们知道，”他开口，“你们是怎么来的吗？”

雷霆战士们摇头。

帝皇指了指自己的裤裆。

“从那里来的。”

# **八**

雷霆战士们愣住了。

“那里？”

帝皇点头。

“那里。”

一个勇敢的雷霆战士举手。

“陛下，您是说是您——生了我们？”

帝皇摇头。

“不是生。是卖。”

雷霆战士们面面相觑。

“卖？”

帝皇解释：“我卖了我的那个。用卖的钱，创造了你们。”

雷霆战士们沉默了。

然后那个勇敢的战士又问：

“您卖了那个，那您现在——还有吗？”

帝皇看着他。

沉默了三秒。

然后他说：“有。卖的是仿制品。”

雷霆战士们松了一口气。

# **九**

统一战争开始了。

雷霆战士们上战场。所向披靡。战无不胜。

泰拉的军阀们被打垮。异形被消灭。叛徒被处决。

每打一次胜仗，雷霆战士们就聚在一起，讨论一个问题：

“帝皇的那个，到底长什么样？”

没人知道。

但他们都记得，帝皇说过：你们是从那里来的。

# **十**

有一天，一个雷霆战士忍不住问马卡多。

“摄政，陛下的那个……真的那么值钱吗？”

马卡多看着他。

沉默了很久。

然后他说：“你知道第一批雷霆战士花了多少钱吗？”

雷霆战士摇头。

“一亿泰拉币。”

雷霆战士愣住了。

“一亿？”

马卡多点头。

“一亿。一万个那个，每个一万块。”

他看着雷霆战士。

“你们每一个，都是用那个的钱创造的。”

# **十一**

雷霆战士沉默了。

他低头看了看自己。看了看自己的手。看了看自己的腿。看了看自己的——

然后他抬起头。

“所以，我们身上，流着那个的血？”

马卡多想了想。

“可以这么说。”

雷霆战士又问：“那我们应该怎么称呼它？”

马卡多又想了想。

“叫它——源头。”

# **十二**

从那以后，雷霆战士们私下里管帝皇的那个叫“源头”。

没人敢当面说。

但每次上战场前，他们都会默默地想：源头保佑我们。

帝皇知道。但不说破。

只是偶尔，他会拍拍自己的裤裆，轻声说：

“谢谢你。你创造了第一批战士。”

那个没有回应。

那个没有回应，但它亮了

# **十三**

统一战争结束后，雷霆战士们被星际战士取代。

他们知道自己会被淘汰。知道自己会死。

但他们不后悔。

临死前，一个雷霆战士拉着马卡多的手，问：

“摄政，那个——还在吗？”

马卡多点头。

“还在。”

雷霆战士笑了。

“那就好。源头还在，帝国就还在。”

他闭上眼睛。

马卡多看着他，沉默了很久。

然后他站起身，走向黄金王座。

走向那个源头。

# **十四**

*记录中断*

*后续记录：*

*雷霆战士们全部牺牲后，帝皇钩子公司也关闭了。*

*但那个，还在。*

*它被供奉在黄金王座旁边。*

*和帝皇一起，守护着人类。*

*偶尔，马卡多会看着它，想起那些雷霆战士。*

*那些用它的钱创造的战士。*

*那些叫它“源头”的战士。*

*那些临死前还惦记着它的战士。*

# **十五**

*上面写着：*

*“我不知道源头长什么样。*

*但我知道，它创造了我们。*

*它卖了它自己，让我们活着。*

*我们叫它源头。*

*我们爱它。*

*——一个雷霆战士”*

*纸条下面，画着一个金色的柱状物。*

*一头粗一头细。*

*歪歪扭扭。但很认真。*

*处理建议：永久保存。不得销毁。不得公开。*
