# **第二章**

“格鲁提！抓住那个该死的托盘！”

格鲁提猛地转过头，发现克拉基特正瞪着他。那干瘪的兽人杂役一只手拿着摆满酒杯的托盘，另一只手恶狠狠地攥着一个结实的长柄勺。

“是，头目。抱歉，头目，”格鲁提回答道，将那托盘顶在头上，耳朵被摊向了两边。很沉，那重量几乎要压垮他的膝盖。“往哪儿？”

“那些高夫，”克拉基特嘟哝道。“马上送到那儿去。他们已经要开始暴躁了。”

格鲁提不敢开口回答，担心这样会把装有真菌啤酒的大壶弄掉。取而代之，他摇摇晃晃地朝大门走去，另一个屁精将其推开以便他能够迅速穿过。他几乎什么都看不见，他的世界变成了膝盖、桌腿，还有偶然热衷于调查他货物的嗅探史古革。

“滚开！”他厉声道，尽可能地表现出恐吓。并不是说这能制止那只嗅探史古革。它猛扑向前，张嘴就咬。如果不是被锁链拴在一个兽人的手腕上，其可能会夺走他的腿。它的主人吼了些什么，一巴掌扇在那生物的脑袋上。它低吼着，牙齿狠狠咬进了他的小腿，引得其他兽人哈哈大笑起来。格鲁提只能辨认出他们的腿，但缺少靴子以及大量的纹身表明这些不是高夫。他退避开来，考虑到他们中任何一个都可能会抢走饮料，那样他将被责备。假如不是被那些傻高夫，那就是被克拉基特，他有一种觉察命令什么时候被耽误了的本领。

不过，他倒不是个糟糕的主人。至少那些饭堂屁精有机会尝到奇特的款待。香煎史古革肠是格鲁提的最爱。每晚结束时总会有一些剩下的，而只要屁精们安静坐着，听克拉基特讲那些东拉西扯的故事，他们通常就能分到一碗。

不过这不是个普通的夜晚。克拉基特已经明确表示过这一点了。太多小子在同一个地方，太多氏族习俗相互冲突。他们需要食物、啤酒、娱乐，否则他们就会自己动手制造这些。而格鲁提可不想成为任何人娱乐的来源。更何况或者晚餐。

“好啦，菲尼克。你准备好了吗？”

那兽人的声音很愉快，近乎友好。格鲁提冒险从托盘边缘瞥了一眼。蛇咬们聚集在一起，看着他们部落中的一个将他的下巴放在桌上，嘴巴张得大大的。他对面是一只相当小的史古革，有着更小的脑袋和异常大的嘴巴。比那兽人还大？很难说，而这就是比赛的重点。那个兽人会享受可口的一餐吗，还是这只咬脸史古革会名副其实？

 吃咬脸史古革比赛是兽人们常见的娱乐活动之一

“俺的啤酒在哪儿？”

那声音并不友好。格鲁提身子一僵，急忙朝那声音的方向走去，无视了咀嚼骨头以及随之而来的欢呼声。那是一名高夫的声音，他很清楚。比其他兽人更深沉，也更愤怒。高夫们之间毫无幽默感。甚至生吞一只咬脸史古革也被视为一场严肃的比赛，而非好笑的酒桌游戏。

他们在哪儿？

这里的兽人太多了，有太多膝盖和屁精在其间窜来窜去，运送着肉、啤酒以及无论什么能让小子们保持平静的东西。但跟那些挤在一起的躯体之间，他突然看见一个涂着黑白方格的护膝。

高夫标记。

 黑白棋盘格常见于高夫氏族的护甲装饰上

“让路！”他咆哮道，尝试让声音尽可能地大，同时强行挤开一条路，快步溜过另一张桌子并躲开了一记心不在焉的脚踢。一个兽人朝他咆哮，但他几乎没听见这声发作，爬上一个被升高的平台，终于来到了那个护膝跟前。它很大，至少是他脑袋宽度的三倍。

“你的饮料，头目，”他说道，伸直他的手臂举高托盘。当其升起时，他的视野也随之扩大，刚好能看到，离他大约五十码的地方，一桌子高夫从装饰黑白方格纹的有角头盔下怒目而视。

他们看起来并不高兴。

诚然，他们从来都没看起来高兴过，所以更准确的说法是他们看起来很生气，大概是因为他们还没收到他们的饮料。反正他们中的大多数，可那个大块头，他们的头目，目光似乎越过了他直直盯着别处。格鲁提顺着他的注视，从托盘下面探出头，越过那装甲护膝向前望去。

但其实没必要。站得这么近，他能感觉到，就像抓住了一根带电的电线。倘若他有只毛发史古革的话，其软毛会立得顶到天花板，假如这可怜的小东西没直接爆炸的话。

碎骨者。他站在了碎骨者面前。

标准屁精的反应是会让自己陷入惊恐之中。事实上他瘫了，在托盘之下无法移动。没有屁精胆敢接近那个大战争军阀，更不用说以如此随意的方式跟他说话了。除了玛卡伊之外，碎骨者的私人掌旗手。他就在那儿，坐在稍微偏离那个大战争军阀随从们的位置，正用毫不掩饰的鄙夷目光瞪着格鲁提。那杂碎是不会帮忙的，毕竟哪个屁精会拿自己的性命冒险去帮助另一个呢？

格鲁提等待着被压扁。但碎骨者却伸出手，将毛哥之吼从他的盔甲上卸下，然后拿起其中一个酒壶，他的目光几乎没落在这个颤抖的屁精身上。他一口气喝光了整壶啤酒，把那容器抛到了一边。

就这样？格鲁提应该退下吗？如果他这么做了，接着把剩下的饮料送去给那些高夫，他兴许能侥幸脱身。毕竟，碎骨者是个高夫。从技术上讲，虽然格鲁提不确定这是否还算数，因为如今他是所有兽人的战争军阀了。

但移开托盘会冒犯到那个大战争军阀吗？几乎肯定，因为他已经伸手去拿另一瓶酒壶了，再次一饮而尽。这也是好东西，是由发酵的史古革和钷素废液提纯而成的。此外，克拉基特还丢了一些那种让你的嘴感到烧灼的辛辣籽果进去。大多数兽人都会至少承认这啤酒的刺激，可那个大战争军阀喝起来却如同狂饮清水。或者空气。

又一只手伸了过来，小心翼翼地拿起一个大酒壶。荒唐。谁竟敢从那个大战争军阀的盘子里拿东西？

“赶紧溜吧，小玩意儿，”一个声音低语道。格鲁提抬起头望去，发现另一个兽人正瞪着他。其脸差不多是碎骨者的镜像，半个脑袋都是金属板，上面镶嵌着一只闪烁深红色光芒的仿生义眼。那应该已经够吓人的了，但肉质的那只眼睛不知怎的更加骇人，直直地看穿他就像刺入内脏的一把戳戳那样清晰。

格鲁提渴望服从，只是他还没来得及动，又传来了另一个声音。一个声音，低得几乎可以算作是耳语。然而其话语让这个房间都为之颤动。

**“他留下。”**

“哦？”那第二个兽人举起他的大酒壶说道。“伟大的碎骨者喜欢这些酿造酒的味道？”

**“不。单薄。软弱。跟大多数一样。”**

“那么，为什么不让这个惊恐万分的可怜小矮个儿赶紧离开呢？”

**“因为俺没说他可以移动。”**

“啊，”第二个兽人叹气道。“俺道歉，战争军阀中的战争军阀。俺只是想保护这个小淘气鬼。站在伟大先知的旁边肯定倍感压力。他的可怜小心脏也许会撑不住。”

**“你为啥在乎，格鲁斯尼克？”**

“俺关心俺们的人，”格鲁斯尼克回答道。“不论多么软弱、卑微、可鄙。一切都有其用处。只要得到正确的引导，全都能变得更进一步。”

**“你的意思是你的手，还是俺的？因为俺总是可以再次把你的扯下来。”**

“不。俺吸取了教训。”格鲁斯尼克轻笑道。“俺的脑袋现在清楚了。俺不会再给你找麻烦，伟大的碎骨者。”

 在《大疯医》中格鲁斯尼克因僭越，被碎骨者扯掉了一只手

那个大战争军阀发出一声闷哼。也许是一声咕哝。听起来他显然半点都不高兴。又取了一个大酒壶，托盘的重量因此减轻了一些。碎骨者将其喝干，看了一眼酒壶，随即用手将其捏碎，把扭曲变形的金属残片扔到了脚边。

**“俺讨厌这个。”**

“这个？”格鲁斯尼克说道。“为庆祝你胜利的这个宴会？你的舰队又碾碎了十几颗星球，将银河系更多的疆域变成了绿色。”

**“算是吧。几乎没怎么被卡住。”**

“是啊。这就是拥有如此庞大军队的问题所在。你和无论你想干翻的什么之间总是有兽人们。即使你冲在前头，最终还是会遇到更多的兽人。真难办啊。”

格鲁斯尼克的笑意都能被听得见。碎骨者嘟哝了些什么作为回应，那声音让格鲁提垂平了耳朵。

“不过，你鼓舞了他们。将他们拉向了你。而他们在一起才最为强大。被他们的战争军阀所联合。”

**“俺知道，小兽医。”**

他声如雷霆。格鲁提听到后不禁颤抖。当兽人们痛饮、摔跤、讲述他们的力量时，周遭满是大笑和咒骂，大酒壶的碰击声和拳头的撞击声，那声音本不该被听见。可格鲁提能看到一双双眼睛投向了王座的高台，并感觉到每当他说话时气氛的变换。

兽人们正在享受他们的胜利。除了碎骨者。

**“够了！”**那个大战争军阀站起身来咆哮道。格鲁提发现自己的目光还逗留在王座上。它是用石头雕琢而成的，并用铁进行了加固。然而，其还是在碎骨者的重量下被压弯了。

他的吼叫带来了沉默。一种大多数兽人都感到陌生的状态，这些生物迷恋哒咔的枪声与引擎的咆哮。但先知的话语源自诸神。没人敢说话。

碎骨者审视着在场的人。他强大的战争军阀们，每个都伴随着其最棒的战士们，全都向王座行礼致敬。向碎骨者。从他的表情来看，他显然对此毫无兴致。

**“所以，你们都在这儿了？”**他说道。**“吃着俺的肉。喝着俺的啤酒。呼吸着俺的空气。因为这一切都是俺的。你们所有人都是俺的。俺是碎骨者。俺即战争！”**

他环顾房间，他的那只好眼睛逐一端详着每个兽人，其仿生的那个则像一颗邪恶的太阳般在旁边灼灼发亮。

**“哪个兽人不同意这种观点吗？哪个兽人觉得他们可以拥有俺？”**

没有人动，大部分兽人突然都专注于他们的大酒壶或者他们盘子里的内容。或者，倘若这两种选择都行不通的话，那就随便什么都可以。格鲁提看见一个恶月正在仔细查看他夹克上的一根线头，同时一个蛇咬小子正在悄悄悉心摆弄一只看着有点困惑的嗅探史古革。

**“没有？没兽人有这种力量？这种聪明？这种胆量？一个都没？”**

没有回应，这很不寻常。通常这样的话语至少会激怒几个兽人付诸行动。不过格鲁提明白。毕竟他是个屁精，而屁精们深知面对一个完全强过你的对手时，站出来是愚蠢之举。哦，他们或许会梦想此景，吹嘘一番，若一个兽人发现自己受伤且孤立无援时，甚至可能趁机加以利用。但没有屁精胆敢公然挑战一个小子。不直接地。那徒劳无益。毫无意义。

出于同样的原因，没有兽人会直面形同必死的碎骨者。并不是说兽人们真的害怕死亡，不过跳进敌人的牙齿和跳进一个酸液坑这两者之间还是有区别的。一个表现出了胆量。另一个表现出了愚蠢。而还有什么比挑战碎骨者更愚蠢的呢？

那个大战争军阀依旧沉默不语，等待着那些永远不会到来的潜在挑战者。

最终，他叹了口气，放低身体坐回了王座，石块在他的重量下嘎吱作响。

**“就……取来那些战利品，”**他说道，他轰响的声音现在平静了。**“向俺展示你们战斗得像兽人一样。”**
