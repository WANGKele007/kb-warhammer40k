# **第十五章**

# **名字**

I

在野狼离开后的几个小时里，我们残缺兄弟会中的大多数人都离开去进行最后的准备。我与卡斯蒂安的联结让我无需费劲便能找到他们，但我现在并不想与他们会合。马卡迪尔、恩克拉多斯与加里奥联入了灵能交流，用冥想来为面对下方的世界做准备。杜梅尼顿，就和我一样，也退去独自待着。我感知到了他的奋勉，全神贯注的炽烈，他正在自己的武装室内练剑。

我没有训练的欲望，也不想浪费时间冥想。我在前往阿米吉多顿的途中已经把所有时间都花在这些消遣上了。现在，有别的东西正吸引着我的注意。

我站在她私人房间的入口前，然后用指节敲了敲舱壁。壁式扬声器咔哒一声激活。

“是哪位？”一个柔和的女声问。

+海伯利昂，+ 我透过门传声。扬声器咔哒关闭，门在润滑良好的机械装置上滑开。

“你好，海伯利昂，”瓦希拉微笑着说。她正背着枪灰色的钷燃料罐。

他们都各自准备着。达福特站在工作台旁，仔细端详他拆开的步枪，用布擦拭备用枪管。卡坦在包裹她的矛柄，梅里克则把改锥探向赛博猎犬的下巴。安妮卡和科洛温正在检查自己的武器。他们坐在房间的对立两侧，只会进一步扩散他们共有的气息。他有她肌肤的气味：她也有他的。这已经不是他们第一次在任务前散发出匆匆交媾的气息了。

我永远都无法理解凡人。

“你还好吗？”瓦希拉问道。

“够好了。”我不确定自己是否喜欢这个姑娘看着我的样子。因为没什么可说的，我就也问她还好吗。

“很高兴能在这里，”她说。最悲哀的是，她是认真的，她还不到十六岁。她对职责的忠诚令人钦佩，但本应当是我们团来承担这些重任，如此凡人便不必再去。每每看到她都会令我深感内疚。

“你是文书人员，”我对她说。“我不明白你为什么要备战。”

“即便是抄写员也是能开枪的，海伯利昂。”

我既未赞同也未反对。安妮卡察觉到了我的窘迫，又或者是我的注意所在，因为她放下了爆弹枪，扬起一边眉毛。

“有事？”

“我们能聊聊吗？”我问。+单独。+

“当然，”她说，然后无声地补充道，“*这里？*”

+这里就行。+

她清了清嗓子，引起她同伴们的目光。“给我几分钟，”她对他们说。他们从我身边走过。只有科洛温在出去时试图与我对视。我无视了他。

等他们离开后，安妮卡走到达福特的工作台边坐下。她的黑发仍披散着：我知道她在参战前会把头发扎起来。

“有什么不对吗？”她问道。

“没什么不对。我有个问题，就这样。”

“我知道你要问什么。”她脸颊上的部落纹身随着微笑弯起。我无法判断她的表情是出于逗乐还是同情——对我来说，要分辨这些细微差别并不容易。

我不得不深吸一口气，让自己准备好说出接下来的话。

“我是谁？”

安妮卡伸手越过桌子，拿起一面数据板。她轻敲屏幕，阅览着读数。

“你确定你想知道吗？”从她的语气来看，她似乎在逗弄我，或者某种程度上觉得好笑。“这可不像你啊，海伯利昂。像这样漠视传统。”

这倒是真的。“我明日将死，安妮卡。”

她的笑容淡去了，就像太阳躲到云层之后。她既有不同我争辩的理智与风度，也没有提出毫无意义的否定。我们彼此对视的时间长到令我开始不适。我也不确定为什么。

“我已经有这些情报了，但还要过几道密码锁。”她说话时的声音更轻，更柔和了。“我需要几分钟来输入所有密码。”

“我会等。”

我在她的房间里来回踱步，就像她过去常常在我的房间里那样。主要的区别是我没有碰任何东西，免得惹她生气。一间接一间，我走过她舱室的单间。达福特的卧室一片狼藉，到处堆着武器和衣服，这让我觉得很奇怪，毕竟他本人是那样衣着完美。瓦希拉的房间几乎没什么家具，只有一张写字台和一个小神龛。卡坦的全是她的气味——也就是说，有汗水、 长发绺与漫漫长夜的味道。

“海伯利昂。”

我回到她那边，胸口有种无法安定的紧绷感。

“你看起来……很担忧。”她说。

“我感觉很不寻常。”我不得不吞咽口水，并握紧双手以免她注意到它们在颤抖。我的喉咙莫名干涩，让说话都有些困难。

“你……你是在紧张吗？”她问，声音轻柔得危险。她的眼睛睁大了。

“这在生理上是不可能的。”

+那……那是什么感觉？+ 马卡迪尔匆忙传声。+发生什么了？+ 我感受到加里奥、恩克拉多斯和杜梅尼顿也同样在向我探寻，试图找到那种疯狂感知的源头。

+一切如常。+ 我抑制自己不受侵扰，将一切内化于心，不让任何一丝溜走。我的心跳开始放缓。

“海伯利昂……” 安妮卡说，声音依旧轻柔。

“赶快告诉我，”我的语气比预期中的尖锐，“拜托。”

她并没有把数据板递给我。相反，她滑下桌子，走向公共房间里的主全视屏，其安装在右舷的舱壁上。安妮卡将数据板滑入插槽，屏幕闪烁着亮了起来。

她向我展示了一个男孩。从那张粗糙图片能看出男孩有十四五岁，尽管图像因为失真而显得颗粒感十足。他很瘦，营养不良，健康欠佳。他的眼睛深暗、自大、多疑。

比这些更重要的是，他看着很疲惫。

不，这是谎言。比这些更重要的是，他看着很像我。

我感觉到自己走得更近，再近，直到我的手放在屏幕上。安妮卡靠着附近的舱壁，看着我注视自己。就算没有去看，我也能感知到她温柔的微笑，还有她的忧伤。

“还有吗？”我问，“除了照片？”

她的回答是输入第二组密码。我从那张模糊的面孔前退后一步，以便阅读滚入视野的文本。

“没有名字，”我说。

“实际上，有，在这里。”她又输入一组密码，调出一个副屏。它显示出了一份审判官基甸·拉文诺的调查审讯报告，详细记录了他的几份证词。

“这里，”她说。

我看向她指的地方。

## **埃弗尔内蒂，泽尔**

这对我毫无意义。我又看向她。“泽尔·埃弗尔内蒂。这是我的名字？”

“没错。”她清空了屏幕，取回数据板。“而且你在几十年前引起了不小的轰动。你陪同着修会最受尊敬的审判官之一，见证了他的那些至暗时刻。”

审判官拉文诺。我知道他。在太阳星域和朦胧星域的审判庭里，有谁没听说过这个名字？他的名声无比显赫，他的著作被认为是数个次星区审判庭候选人的必读书目。

“我不记得了。”

“你难道还期待点别的吗？”

我自己也不知道答案。“我不确定。”

安妮卡摇了摇头。“你记起过一些片段，海伯利昂。试着专注些。”

不适感席卷而来，突然得如同一阵烈风。我不想再继续下去了。

“不。我想我该走了。谢谢你，审判……”

“海伯利昂？”

“黑王座。”我用指节按压紧闭的眼睛，被这段记忆搅恼。“我告诉过你，我总是梦到一个黑王座。一把黑椅子。当然了。”

“它不存在于审判庭之外。我怀疑甚至连泰坦都没有。”

“这显而易见，审判官。”

“感谢你与我分享这些。”

“好奇不是罪过，海伯利昂。我喜欢从旧档案里挑骨头。能让你受益匪浅。”她又对我一笑。“很高兴能展示给你。”

我注视着她——此刻第一次浮现这个念头。“你向我展示这些会招致惩处吗？审判庭会对你采取制裁行动吗？”

安妮卡耸耸肩。“海伯利昂，审判庭不是……组织……以这种方式。它不是由单一议会统治的单一世界上的单一团体。很多外人都不清楚这点。每个世界、星系、次星区和星域都有各自的组织、仪规、档案与政治……你能明白吗？”

“不太能。”我只熟悉骑士团，除此之外一无所知。我实在难以想象一个横跨银河的存在，由数百万互相冲突的灵魂构成，只靠最松散的利益维系团结。这种散乱令我皮肤发麻。

“一位审判官眼中的罪孽，在另一位看来或许是救赎。就像帝国信条：在一个世界，他们把帝皇视为端坐固金的神明崇拜；在另一个世界，祂是通过自我牺牲实现永生的暗喻；再到别处，祂又是太阳神，司掌日光与作物生长——他们会向祂祈求丰收。还有其他世界尊他为真言失传的先知，那些凡夫俗子以祂之名编造箴言，来契合当地民意。更有甚者视他为至高无上的存在，接纳并庇佑人们的先祖亡魂；另有些世界呢？祂又是指引明灯，星炬的源头，一位拥有神力的凡人，其机械为我们的舰船在无尽黑夜中投射航标。”

我从未见过这种文化——我对修道院高墙之外的任何文化都几乎没有宝贵的第一手知识。即便是在档案中搜寻我们净化过的那些世界的资料时，我也只是关注行动相关的内容。

安妮卡将话题更进一步。“所有这些宗教派别都是帝国信条中可以容忍的差异。它们就是帝国信条。银河是如此浩瀚，国教根本不关心那些世界和民族的所作所为——只要他们祈祷的对象是帝皇就行。帝国并非统一的整体，海伯利昂。它就是人类无限、迷失，割裂的多样性。审判庭也是一样的。告诉我，你见过有多少审判官与我没有不同？”

也许她忘了我至今只遇到过四位审判官。我又怎么能知道这些事？它们很少会被记录，只有在日常生活中接触过的人才会视为常识。我在修道院内度过了四十年，而自我升入骑士团的这一年来也多半在亚空间航行中度过，只间隔零星几场战斗。

“当然。原谅我，我忘了你有多年轻。”

我看着她，一言不发。

“明白了。”

“我遇见过许多其他审判官，”安妮卡说，“有的使用原始护身符，有的推崇异形科技：萨满与改革异端都在为同一事业奋战。没错，我们中有些人的确拥有凌驾他人的权威，但归根结底我们是独立的，我们每一个人，权势仅仅倚仗自身影响和结盟对象。我们彼此间的争斗就跟与大敌一样多。审判庭——作为民众想象中庞然统一的终极实体——根本就不存在。它只是一种……*valdelnagh*。一种误解，一种便利的欺瞒。”

我意识到她想做什么。它几乎就奏效了。

“你在回避问题，审判官。你会因此受到惩处吗？”

她笑了，一种柔和的声音。“这就取决于是谁发现了。大多数审判官都不会在意，也知道大多数灰骑士同样不感兴趣。另一些人或许会因此想杀了我，还有些人可能会认为这是新颖的操控手段。这些都不重要。”

我低头看向自己的双手，包裹在那银色陶钢中。“它说我没有灵能能力。他们必须解锁我的天赋让我发挥作用。”

“只有灰骑士才能做到。这就是为什么莉莉丝要带你来泰坦。”

“这是她的主意？”

“报告并没有提及，但我表示怀疑。更有可能的是，她受到了预言者的*sammekull*。”

sammekull。又一个芬里斯语单词，意思是召唤。这确实很有可能。托克里斯又是怎么评价我的？‘你的力量引人注目，甚至早在你处于评估试炼之前’。

耐人寻味。或许当初传讯要走我的正是他。

“至少这解释了为什么我的力量在兄弟们身旁时能发挥得好那么多。”我一直都很疑惑这件事，还有为什么似乎只有我这样。而同胞们对此丝毫不担忧的事实曾让我确信，这只是熟练和信心使然。真相却是：我的灵能技艺是后天才得以培养，而我生来的天赋则更具……汲取性。

我不禁自问是否仍在汲取他们，就像我年少时汲取他人那样？

一个更为冷酷的领悟是，这解释了为什么导师们在我最初的训练中如此踌躇。我可能比自己知道的更接近毁灭。

我回忆起与骑士团其他人的初次交流，当恩克拉多斯与另外两名骑士将我从牢房释放出来时。

“那些符号，”我问他们。“它们是什么？”

“护符。六芒星护符。我们必须确保你并未受到污染。我们也必须确定你对往昔生活毫无记忆。”

第二个声音毫无暖意。“你在这里度过了既定的九十九夜，与此同时我们卜筮了你的灵魂。”

“仪式已毕，”第三个声音，后来我认识的恩克拉多斯，最后道。“我们满意你的纯洁度。”

但那披甲骑士的关节咆哮起来，当他低下头时。“不过仍存有些许疑问。”

我眨眼摆脱了沉思。

“我该走了。”

安妮卡没有提出反对。“如你所愿。我还会在……在我们行星空降前见到你吗？”

我知道她为什么犹豫。她几乎要问出“我还会在你死前见到你吗？”她对我隐瞒这些伤感的想法几乎好笑。我生而为战，生而为死。命运于我既无神秘亦无可惧。

真是番豪言壮语，对于一个想着要面对自己童年就浑身发抖的家伙。这点，最终，令我发笑。

“不太可能，”我说。“如果你要下到阿米吉多顿与野狼们并肩，那么这就是我们最后一次见面。永别了，审判官贾丝都提尔。”

她将手掌放在我的胸甲上——放在那处万魔大典的标志上。

“这书是你们最近似圣籍的东西，对吗？”

我点了点头。“它囊括了我们的仪式和传统，还有……”

她嘘了我。她真的嘘了我。她必须伸长胳膊来做到，把一根纤细、脆弱的凡人手指按在我唇上。这一刻的疯狂差点让我放声大笑。

“嘘，”她说。“要有信心，海伯利昂。你就是被塑造来赢得这种战争的。你们所有人都是。”

我无法想出一个合适的回答。缺乏恰当的话语，我只是微微点头，然后留下她一人。

出战的传唤在九小时后到来。

II

我同卡斯蒂安站在“卡拉贝拉”号的舰桥之上。泰温·卡斯托舰长笔直端坐于指挥王座，身着正式的灰色束腰外衣，被外罩的金纽扣黑夹克衬得更暗。对于泰温·卡斯托，这套装束几乎适于葬礼，倒也正合适。

他的军官们各司其职，自从我们进来后舰桥就被一种沉静的庄重笼罩。每位人员都身穿制服，展现出严苛的整洁标准。就连机仆此刻也调整至低声细语。战舰本身在舰队中保持着完美的位置——泰温已经确保这点。

全视屏呈现着阿米吉多顿最后几座巢都之一周边的俯瞰景象。冥河——其命名就如同这个世界的一切，都取自泰拉神话中的各类冥界——就像是一道劈裂大地本身的蓝色激电。第一批殖民者究竟在这颗星球目睹了什么，才会给它的地标起如此憎恶的名字？我永远不得而知。

全视屏中，我们目睹着规模超乎我想象的军队相互碾压。整营整营的帝国卫队与民兵冲锋又溃逃，跃出堑壕或是坚守战线，全都出自各自内心的冲动与军官吼出的命令。坦克师，成百上千的战争机器，在冲入敌阵或以参差残破的队形后撤时掀起一片尘暴。

他们面对的敌群是凡人、变种人与其它更恶劣的存在。任何男女能在此等大军前坚守的事实，清晰彰显了人类心中无可估量的勇气。就在眼前，我见证了为什么人类应当继承这个银河。再无其他种族能结合如此的美德与智慧。

我承认，当我浮现这些念头时，几乎能想象安妮卡会说我过于天真。即便是瓦希拉听到这种想法也会莞尔，然后提醒我我对自己种族的认知有多贫瘠。

我们看着战争中最惨烈的战斗在冥河两岸进行。从我们这俯瞰，那不过一块横跨地面的黑渍，从屠杀的震中每分每秒地蔓延。从这个高度，加上交战军队升腾的硝烟，几乎所有细节都模糊不清。

通讯流的噼啪声覆盖了沉静，带来地表的声音。我们保持着与三个灵魂的交流联结：第一位，是头领格里姆纳，正在冥河激战；第二位，是安尼卡，她疲惫的喘息被爆弹枪沉重的轰鸣淹没；第三位，是泰瑞玛连长，我们听着他逐队传达兄弟会中已经为最终打击做好准备的成员。

“情况如何，卡斯蒂安？”他的声音刺耳地传过扬声器，填满了舰桥。

加里奥向杜梅尼顿点头，示意他代为回答。“我们正在等待传送平台完成最后的祝圣。最多只用几分钟，第三连长。”

“了解。”泰瑞玛的声音噼啪淡去，声响恢复成头领格里姆纳对他兄弟们的咆哮，以及安尼卡用我听过最污秽的芬里斯语咒骂着。

+有什么好笑的吗，海伯利昂？+

我转向加里奥，无法掩饰脸上的笑意。“想到我们最后听到的声音将会是审判官贾丝都提尔问候敌人的出身，倒是有种古怪的慰藉感。我从未想过自己会这样赴死。”

加里奥嘴唇未动，但我在他眼中看出了同样的笑意。+在此刻确实欠缺几分庄重，不是吗？+

甚至连杜梅尼顿都发出声权当是笑的咕哝。

我们穿上了战术无畏装甲，为我们的披甲身躯增添更显著的重量与质量。卡斯蒂安极少穿戴我们最珍贵的传世战甲投入战斗，而我已经开始怀念动力甲背包上亚空间跳跃装置提供的保障。终结者拥有内载能源——这是它远比标准战甲耐用的诸多原因之一——但我宁愿用这额外的防护换取熟悉与自在。

我现在感觉笨重、迟缓，尽管有包裹身躯的纤维束机械肌肉嗡响着提供额外力量。当泰瑞玛连长最初命令我们穿戴这种盔甲时，连加里奥都提出了反对。

+我的兄弟们与我更希望装备传统战甲投入这场战斗，连长。+

泰瑞玛不为所动。“我们即将坠入地狱之口，加里奥。我们在下面存活的每一秒，都是放逐那东西的契机。披上你们最精良的战甲，第八兄弟会的仲裁官。这是命令。”

于是我们服从了。

舰桥之上，我把头盔举到位，伴随咔嗒声与气压嘶鸣完成密封。

与此同时，战略室的大门隆隆开启。阿克西姆站在门口，他那闪亮的银色身躯两侧是数位身披长袍的技术神甫。

“是时候了。”

III

机器的铿锵声让其余一切都难以听见。我们往传送平台走时，雾气已经在靴边缭绕。我们无人开口。也没有什么可说了。我们早已把细节，诸如此类的内容，捋过不下百遍了，每艘战舰上的每支小队都清楚自己将传送到什么局面。来自地表的最新影像——跳帧、撕裂又负载静电，因为来自于仍在奋战的野狼的头盔——仅仅展示了我们即将面对的简略片段。

我们的部队正且战且退到离河岸两公里的防御工事。我看着某位野狼战士目镜传来的画面，他正举起自己左臂的残肢，接着我听见了他难以置信的咒骂。

首批冲击帝国防线的大敌部队是先遣骑手、斥候与先锋中的乌合之众。即便是敌群先头兵力的攻势也凶猛到足以令阿米吉多顿的军队陷入僵局。

鏖战数小时后，随着真正的威胁终于现身，野狼命令数十万男女后撤，后撤，再后撤。我很少关注其中的战术。我们很少人会：我们的角色是作为直刺心脏的利刃。我们即是战锤，而非挥动它的手。

武器不需要质疑将军的决策，也不必知晓每个兵团在战争中的部署。武器只需要适于掌握，并饱尝敌人的鲜血。

我怀疑我们与整体作战计划保持距离的背后，还有一个更冷酷、更务实的原因。我们不会活过下一个小时，所以整场战役的事态对我们而言意义甚微。我只知道组成帝国部队的大多数兵团的基本情况、部署位置和负责指挥的军官，却无法想象有什么情况会让我需要与他们中的任何人交谈。多数情况下，仅仅是看到我对他们就意味着死亡。诚然，他们终归注定要被处决，在目击了第十二军团之主及其大军后。

对那些坚毅勇气却是这种回报。我发现自己第一次怀疑是否真的有必要去——

加里奥发出念力轻推我的肩膀，来引我注意。+不要想这种事，+ 他警告。+不要质疑我们的主人。这条路通往异端。+

阿克西姆在他能俯瞰平台的高台上输入了代码和坐标。修士们开始吟唱。

+卡斯蒂安准备就绪，+ 加里奥向旗舰上的泰瑞玛连长脉冲。

+收到，卡斯蒂安。+

+记住，+ 加里奥向我们传声。+记住我们必须做什么。+

“为了帝皇，”我们四人齐声回答。

其他人静静等待最后的召唤，看着震颤的头盔图像馈送。心血来潮下，我在注视阿克西姆工作时举起手。

“再见了，阿克西姆。”

他抬起头，那银色面容完美呈现出温暖人心的表情。“慷慨赴义吧，海伯利昂。”

“我正有此意。”

那个命令，当它到来时，是绝对完美的交感时刻。一百零九个脑海意念合一、目标一致，手足联结。我此生从未感觉如此安定、如此正当、如此公义。

泰瑞玛的声音乘着交感，沿着连接我们每个意识的无形丝线幽幽传来。

+残缺兄弟会的灰骑士们……+

我永远不会明白泰瑞玛如何能这样清晰地做到，但我们接下来听到的声音，正是下方世界中头领格里姆纳的长嗥。泰瑞玛将其从野狼的意识中抽出，将那声召唤传递给我们所有人。

我为这声音热血沸腾。雾气渐渐收拢，引擎哀鸣愈烈，而我向着意识连接网咆哮出小队的名字。我并非唯一这样做的人。每一名骑士都向着交感无声呐喊，在世界崩裂为疯狂之前最后一次凝聚我们。
