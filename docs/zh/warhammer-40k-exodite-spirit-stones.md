這陣子剛好在寫蠻荒靈族的介紹，有個設定一直是以前留在心裡的問題，蠻荒靈族到底帶不帶魂石？

 眾所周知靈族目前分成了幾派，方舟靈族、暗黑靈族、丑角、死神軍、靈族海盜和蠻荒靈族 ( Exodite )，普遍情況下暗黑靈族和丑角是不會帶魂石的，但常常誤會的是他們是選擇不戴不是不能戴，因為靈族其實是可以轉換勢力的，某個方舟靈族跑去當丑角或是暗黑靈族跑去當海盜都不是新鮮事，所以要不要戴魂石實際上看他們有沒有需要。

 那蠻荒靈族會不會戴？我們直接看軍書好了，二版靈族的軍書內容：

 這邊先簡單說說，一般的方舟世界上會有個稱為無盡迴路 ( Infinity Circuit ) 的靈骨構造體，方舟靈族都會配戴魂石，死後靈魂會被身上的魂石所捕獲，魂石會被其他靈族帶回方舟放入無盡迴路裡為整個方舟世界提供靈能動力與知識，同時也避免這些靈魂被色孽所捕食。

 蠻荒靈族的少女世界則有世界之魂 ( World Spirit )，功能類似無盡迴路，本質上少女世界是由一張用靈能構成、具有生命意志的巨大能量網路所構成的，因此世界之魂蘊含了所有蠻荒靈族的靈魂，他們會攜帶魂石 ( Spirit stone )，死後其魂石會帶往祭壇，族人會將魂石敲碎讓靈魂與世界之魂合而為一，因此蠻荒靈族會極力保護自己的世界，放棄世界等同於拋棄無數祖先的靈魂。

 所以二版的答案是沒錯，蠻荒靈族也會佩帶魂石。

 四版軍書也有提到這點，再往後的軍書裡也沒啥提到蠻荒靈族，總之從這邊看他們確實是需要帶魂石，死了之後會把魂石帶到祭壇敲碎讓靈魂與世界之魂融合。

 附一下十版軍書裡提到蠻荒靈族的部分，我只找到法文版所以加減看吧，裡面就沒提到魂石了，只保留了世界之魂的設定。

 這點可以參考八版的丑角軍書內容，靈族的靈魂死後會被色孽奪走，方舟靈族用魂石來保護靈魂；蠻荒靈族則採用了同樣神秘儀式的變體，靈魂會回歸世界之魂；暗黑靈族靠著折磨其他生命；丑角的靈魂則是會被笑神帶走所以可以不戴魂石。

 小說【Path of the Renegade】裡有另外的敘述：

 Path of the Renegade，2012

 可以看到某個靈族守衛被惡魔幹掉之後靈魂直接被祭壇中的世界之魂給吞了，而主角的靈魂也渴望能直接投入世界之魂其中，這或許說明如果在少女世界上有世界之魂靈魂直接被他吸走了，有人會說這個是蠻荒靈族不帶魂石的證明，我個人認為這個不衝突，頂多是在少女世界上的靈族不用保護。

 Voidscarred，2025

 靈族主要能分成幾個不同勢力，住在方舟世界的方舟靈族要帶魂石；住在魍道裡的暗黑靈族不戴；丑角有神祇庇護所以不戴；靈族海盜如果是方舟靈族出身的會帶，暗黑靈族出身的可以不戴靠戰鬥來躲色孽，但要是死了就必須回到科摩羅或者被色孽吞了，某些暗黑靈族會找個魂石 ( 參考小說Voidscarred )

來連結，蠻荒靈族本身有魂石，就算沒有當了海盜也得找顆來帶。

 至於魂石來源這個GW到沒說，不過大部分的蠻荒靈族都和其他靈族勢力有往來，少部分方舟世界例如薩姆-漢 ( Saim-Hann ) 和比約-坦 ( Biel-tan ) 則很積極跟蠻荒靈族保持聯繫，魂石是由當初色孽誕生時死去靈族的靈魂凝聚而成，所以即便是方舟靈族找新的魂石也得要到位於恐懼之眼內的舊靈族帝國領域－老嫗世界 ( Crone World ) 尋找才行，蠻荒靈族有魂石並不奇怪，他們本來就和海盜有貿易往來，遊俠也把少女世界當作庇護所並定期巡邏。
