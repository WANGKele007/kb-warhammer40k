哈米吉多顿这个战争世界有着漫长而曲折的历史。在接下来的几周里，我们将深入探讨其持续冲突背后的故事，以及它所处的这片饱受战火摧残的星域。今天，让我们从更广阔的哈米吉多顿星系及其行星开始讲起。

 哈米吉多顿在哈米吉多顿星区中的位置

哈米吉多顿星系——其中包含哈米吉多顿行星——位于哈米吉多顿星区内的哈米吉多顿次星区。这或许能让你对这颗行星的重要性有所了解。

哈米吉多顿本身位于一个拥有 10 颗行星的星系中。总体而言，这里的环境条件与太阳系相似——类地行星和气态巨行星大致沿着圆形轨道排列——但有一个例外。

# **内行星带**

哈米吉多顿星系的前三颗行星不过是被恒星缇斯拉炙烤至极端高温的岩石球体。前两颗——肯布莱特与维里提——完全不适宜居住。其中维里提更是极不稳定，以至于在该区域进行舰队级武器射击会对其结构完整性构成实实在在的威胁。

加瓦尔的荒芜地表酷热难当，白昼时沙粒熔化成玻璃般的物质，入夜后又裂成碎片；然而这里蕴藏着极其珍贵的资源，帝国仍不顾一切地在此开采。其轨道空间站环境恶劣至极，工人们只将其称作“烤炉”。

# **哈米吉多顿**

我们熟知它，我们热爱它。恒星缇斯拉的第四颗行星是个酷热难耐的地方，即便没有那些异形入侵和恶魔袭扰也是如此。我们下周会详细聊聊它，但从行星参数来看，它比泰拉略小，磁场微弱，因此地表惊人的污染程度反倒有助于维持大气层——也算是乌云背后的一丝银边吧！

# **肖辛**

肖辛的地表曾在第二次哈米吉多顿之战后被认为已肃清欧克蛮人，但如今从极点到赤道遍地皆是，被帝国指挥部视为彻底沦陷。它最奇特之处在于其不规则的椭圆轨道——有时运行至比加瓦尔更靠近缇斯拉的位置，在一个公转周期内多次穿越哈米吉多顿的轨道。

旧有的勘测报告暗示，这条诡异轨道背后有一个惊人的解释——该行星的地核几乎已完全偏离中心。真相究竟如何，无人能够断言，因为任何新的远征队都必须杀穿数百万欧克蛮人的重围，方能验证这一发现。

# **圣乔温星港**

第六颗行星历来仅有象征性的帝国海军驻守，但在政委雅瑞克首次将碎骨者·斯拉卡逐出该星后，此地扩建为哈米吉多顿战舰群的母港。这里几乎拥有一支舰队所需的一切：足以停泊最大型帝国战列舰的庞大船坞，为不断补充新鲜军官而设立的海军学院，以及位于伊桑山地下八英里深处的庞大指挥碉堡网络。

# **气态巨行星**

两颗大型气态巨行星坐镇星系中央。较小的那颗名为纳玛拉，自转速度相对较快，使其浓厚大气形成令人目眩神迷、头痛欲裂的漩涡图案。你或许会以为这能阻止人们开采其固态核心中的珍贵资源，但……并没有*。

***要是沃坦联盟在这儿就好了。**

另一方面，格拉茅尔几乎毫无特色可言，根本没有值得一提的固态核心。但它的五颗卫星却并非如此——其中最小的一颗正是几处考古发掘现场的所在地，有传闻称在那里发现了先驱文明的遗迹。

# **外行星带**

佩鲁西达的地表残酷荒凉，毫无宜居之处，但其地下洞穴中却隐藏着一片繁茂而生机勃勃的生态系统——那里的植被能够净化含硫空气，其构造之精妙仿佛为这环境量身定制，以至于一些生物贤者声称，它们确实是在帝国时代之前被人工设计出来的。监测探针记录显示，在第三次哈米吉多顿之战期间，欧克蛮人曾试图在洞穴中定居，却无功而返——这足以证明佩鲁西达对智慧生命而言依然致命。

最后一颗行星是名为依安戴的带环气态巨行星，这里几乎没有值得掠夺的资源，甚至连一颗卫星都没有，无法在星系边缘为侦察舰船提供补给。它唯一的实际价值在于可作为欧克蛮人入侵舰队的隐蔽点和集结地——正因如此，其行星环已被改造为一片庞大的雷区。

# **监测站**

哈米吉多顿星系曾有三座大型监测站负责守卫，分别以该星球最伟大的几位防御者**命名：曼海姆、但丁与雅瑞克。

****其中两位你肯定耳熟能详。第三位是库尔提兹·曼海姆亲王，第二次哈米吉多顿之战中的一位泰坦指挥官。**

这些令人生畏的设施建于第二次哈米吉多顿之战后，人们期望它们能在星系再次遭受攻击时提供早期预警。然而，这三座监测站均在第三次哈米吉多顿之战的初期阶段被摧毁，当时欧克蛮人的舰队正向哈米吉多顿步步逼进。
