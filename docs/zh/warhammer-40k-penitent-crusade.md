之前忘記在哪看到一個問題，如果一個星際戰士戰團被判處贖罪遠征 ( Penitent Crusade ) 的刑罰後能不能跑去某個地方躲一百年再出來？

 先不提為什麼忠誠的星際戰士會有這種想法，我們先來簡單介紹一下贖罪遠征好了，一般來說是犯了大錯或被帝國官方懷疑有墮落傾向等等，自願或者被迫執行贖罪遠征，不一定會派去打渾沌，也可能是派去打異形或派到某個激烈戰區，最經典的兩個案例就是派去恐懼之眼送頭的深淵遠征 ( Abyssal Crusade ) 和巴達布戰爭的三個戰團。

 這個贖罪遠征不一定是以戰團為單位，也可能以連隊 ( 暗鷹戰團 / Shadow Hawks 的第三連就單獨被判過，出自IA13，復仇之子的第三連也被派過 ) 或小隊 ( DOW2：渾沌崛起的結局之一 )，另外DOW2代裡也有出現過單獨一人 ( 慟哭者戰團的Cappozius ) 被派去執行遠征的。

 另外我是沒看到記錄說帝國會不會幫助執行贖罪遠征的戰團，大家最熟知被判處遠征的戰團就是慟哭者、螳螂勇士和處刑者戰團，但是這三個戰團是被判刑的時候就說了不准招募新兵 ( 出自IA10 )，還真的不知道其他支援能不能補充，從其他我看到的戰後資料來看他們也是在帝國境內到處跑，所以其他帝國勢力可能還真的不知道贖罪遠征，戰團利用星際戰士的身分幫助其他帝國星球也很合理。

 順帶一提可能有人會問一個人怎麼打遠征，這個可以參考極限戰士四連長烏利爾文特里斯 ( Uriel Ventris ) 的經歷，他違反命令被判處死亡誓約 ( Death Oath，被戰團放逐執行任務 )，跟著星界軍的船艦離開，果然刷臉還是有用的。

 然後回到上面的問題，贖罪遠征戰團能不能躲，從IA13的資料來看這些戰團後方都有高領主的特務們正在監視，你敢躲就直接打成叛徒了，遠征也不用遠征了：

 M41.919－鋼鐵解縛（Steel Unbound）

 在巴達布戰爭期間與休倫結盟，並於戰後依照火蜥蜴戰團的監督許可，自願接受拘禁後，處刑者戰團終於獲准啟程，展開他們長達一百年的贖罪遠征，在贖罪遠征的第一個十年裡，劊子手戰團肅清了特拉蒙星雲中的十二個屢次叛亂的飛地，並徹底殲滅了盤據於卡里亞裂隙的三支小型異形族群。

 在遠征初期的眾多戰役中，最輝煌的一戰是討伐一個深藏於銀河核心、過去從未被帝國發現的袖珍帝國。該勢力完全臣服於毀滅諸神，並與至少三支叛徒軍團戰幫及一支叛徒泰坦軍團維持同盟關係，處刑者戰團在遠離帝國視線之外的法外虛空中建立了無數赫赫戰功贏得數不盡的榮譽，然而這些事蹟幾乎無人知曉，唯一的見證者只有那些奉泰拉高領主之命所派遣的特使，他們一路追蹤並記錄這支贖罪戰團在無法地帶執行遠征的歷程，以確認其是否忠實履行帝國所施加的百年贖罪使命。

 最後提一下有沒有成功執行贖罪遠征的戰團？

 不提巴達布戰爭裡活到現在的三個戰團，IA9裡面介紹星空之爪戰團時有提到M39前的紀錄該戰團曾經有執行過贖罪遠征的紀錄。

 灰騎士九版軍書裡有提到另一個名為黑檀哨兵 ( Ebon Sentinels ) 的戰團，該戰團過去曾經執行過長達一百零一年的贖罪遠征最後成功回歸，奧菲莉亞七號上有他們的紀念碑，基里曼時期還接受過火炬手艦隊的支援，最後被惡魔腐化附身後遭到灰騎士剿滅。

 總之大概是這樣，贖罪遠征的重點在於贖罪而非遠征，遠征過程能解決敵人最好，兩邊一同消失最棒 :P
