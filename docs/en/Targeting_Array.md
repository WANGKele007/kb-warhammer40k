A Targeting Array is a sophisticated computerised T'au target acquisition system that assists the aim of the user by adjusting for the target's range and speed, improving overall weapon accuracy. 

Primarily deployed as a T'au vehicle support system to assist the aim of the vehicle's gunners, a new application of Targeting Array technology has allowed it to be used as a T'au Battlesuit Support System.
