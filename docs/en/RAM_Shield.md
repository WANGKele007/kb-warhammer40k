A RAM Shield is a powerful protective shield attached to an exo-armour gauntlet that often contains an additional built-in Autoch Pattern Combi-bolter. It is a primary defensive weapon used by Leagues of Votann Einhyr Champions.

Sources

Codex: Leagues of Votann (9th Edition), pg. 90
