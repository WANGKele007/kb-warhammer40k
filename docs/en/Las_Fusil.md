The Las Fusil is a powerful, anti-personnel heavy Laser Weapon used by Space Marine Eliminator Squads. The weapon is so accurate that it can be used to replace the Eliminators' standard Mark III Shrike Bolt Sniper Rifle.

Sources

Codex: Space Marines (8th Edition) (Revised Codex), pp. 93, 150, 168
